# EP-85

## Problem Statement
Let $n\geq 4$ and $f(n)$ be minimal such that every graph on $n$ vertices with minimal degree $\geq f(n)$ contains a $C_4$. Is it true that, for all large $n$, $f(n+1)\geq f(n)$?

## Site Remarks
The function $f(n)$ is a reformulation of the Ramsey number $R(C_4,K_{1,n})$, in that\[R(C_4,K_{1,n})=\min\{ m : f(m)\leq m-n\}\]and\[f(n)=\min\{ m : m\geq R(C_4, K_{1,n-m})\}.\]The behaviour of this Ramsey number more generally is [552].

A weaker version of the conjecture asks for some constant $c$ such that $f(m)>f(n)-c$ for all $m>n$. This question can be asked for other graphs than $C_4$.

The bounds in [552] imply in particular that $f(n)<\sqrt{n}+1$ and\[f(n)=(1+o(1))\sqrt{n}.\]It is easy to check that $f(4)=2$.

  To see why $f(n) < \sqrt{n} + 1$ holds, let $\delta$ be the minimum degree of a graph with $n$ vertices that does not contain a $C_4$ and define, for every vertex $v$, the set $S_v$ of all unordered pairs of distinct neighbours of $v$.
  
  Now, if $S_v \cap S_w \neq \emptyset$ for some distinct vertices $v$ and $w$, say $(x,y) \in S_v \cap S_w$, then $v, x, w, y$ would be a $C_4$. In order words, to prevent the graph from containing a $C_4$, we need to have that all sets $S_v$ are disjoint. Now we note that, in total, there are $\frac{1}{2}n(n-1)$ unordered pairs of vertices, while $S_v$ contains at least $\frac{1}{2} \delta (\delta-1)$ pairs for every vertex $v$. We therefore get, assuming the sets $S_v$ are pairwise disjoint,
  \begin{align*}
  \frac{1}{2}n(n-1) &\ge \sum_v |S_v| \\
  &\ge \sum_v \frac{1}{2}\delta(\delta-1) \\
  &= \frac{1}{2}n\delta(\delta-1).
  \end{align*}In other words, $n-1 \ge \delta (\delta - 1)$, so that in particular $\delta < \sqrt{n} + \frac{1}{2}$. Note that this proof would have also worked for the average instead of minimum degree.
  
  As for the lower bound $f(n) > \big(1 - o(1)\big)\sqrt{n}$, the polarity graph induced by the projective plane (see Theorem $1$ in this (https://users.renyi.hu/~p_erdos/1966-06.pdf) $1966$ paper by Erdős, Rényi and Sós for a construction) has $n = q^2 + q + 1$ vertices and minimum degree $q = \big(1 - o(1)\big)\sqrt{n}$, while it does not contain a $C_4$.
