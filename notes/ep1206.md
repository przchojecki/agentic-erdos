# EP-1206

## Problem Statement
Does $\{1,2^3,\ldots,N^3\}$ contain a Sidon set of size $\gg N$?

Is there an infinite set $A\subset \mathbb{N}$ of positive density such that $\{a^3 : a\in A\}$ is a Sidon set?

## Site Remarks
This question may also be asked for higher powers, and [324] suggests that for fifth powers $\{n^5 :n\geq 1\}$ may itself be a Sidon set.

Gabdullin and Konyagin \cite{GaKo24} proved that there is a constant $c>0$ such that $\{ n^3 : N-cN^{1/2}\leq n\leq N\}$ is a Sidon set. Garaev, Garayev, and Konyagin \cite{GGK26} have proved that the exponent $1/2$ can be improved to $4/7-o(1)$ for infinitely many $N$, and to $3/5$ for all $N$ if we replace $n^3$ with $n^4$.

In \cite{Er80} Erd\H{o}s defines $g_k(A)$ to be the maximal size of a Sidon set of $\{a^k : a\in A\}$, and asks whether $g_k(A)\geq g_k(\{1,\ldots,N\})$ where $N=\lvert A\rvert$. (See [530] for the linear analogue.)

See also [773] for an analogous question about squares.

  Using A046881 (https://oeis.org/A046881) we can find small examples for which the inequality $g_k(A) \ge g_k(\{1, 2, \ldots, N \})$ is false for $k = 2, 3, 4$. E.g., using Ramanujan's famous $1729$, we have $g_3(\{1, 9, 10, 12\}) = 3$, while $g_3(\{1, 2, 3, 4\}) = 4$. For $k \ge 5$ on the other hand, we have the Lander, Parkin, and Selfridge conjecture (https://en.wikipedia.org/wiki/Lander,_Parkin,_and_Selfridge_conjecture) which -if true- would imply that there are no solutions to $a^k + b^k = c^k + d^k$ for any $k \ge 5$. Hence, this would trivially give $g_k(A) \ge g_k(\{1, 2, \ldots, N \})$ for $k \ge 5$, as both sides of the inequality are then always equal to $N$.
