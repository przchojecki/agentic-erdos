# EP-830

## Problem Statement
We say that $a,b\in \mathbb{N}$ are an amicable pair (https://en.wikipedia.org/wiki/Amicable_numbers) if $\sigma(a)=\sigma(b)=a+b$. Are there infinitely many amicable pairs? If $A(x)$ counts the number of amicable $1\leq a\leq b\leq x$ then is it true that\[A(x)>x^{1-o(1)}?\]

## Site Remarks
For example $220$ and $284$. Erd\H{o}s \cite{Er55b} proved that $A(x)=o(x)$, and Pomerance \cite{Po81} improved this to\[A(x) \leq x \exp(-(\log x)^{1/3})\]and later \cite{Po15} to\[A(x) \leq x \exp(-(\tfrac{1}{2}+o(1))(\log x\log\log x)^{1/2}).\]This is problem B4 in Guy's collection \cite{Gu04}.

## Local Computation
- Built a deeper exact finite scan up to $2\cdot 10^6$ using a divisor-sum sieve.
- Enumerated amicable pairs and profiled $A(x)$ across multiple scales.

- Found 55 amicable pairs with smaller member $a\le 2\cdot10^6$.
- The density proxy $A(x)/x$ decreases on this range (from $1.6\times10^{-4}$ at $x=5\cdot10^4$ to $2.75\times10^{-5}$ at $x=2\cdot10^6$).
- Finite data remains far from the near-linear growth target.

## Local Proof Attempts
The finite Pascal scan is meant to detect whether higher interior multiplicities start appearing at moderate heights. They do not: even up to row 1500 the largest observed multiplicity stays very small, so the computation reinforces the classical impression that large multiplicities are extremely rare, without resolving the existence question for general \(t\).
