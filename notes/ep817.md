# EP-817

## Problem Statement
Let $k\geq 3$ and define $g_k(n)$ to be the minimal $N$ such that $\{1,\ldots,N\}$ contains some $A$ of size $\lvert A\rvert=n$ such that\[\langle A\rangle = \left\{\sum_{a\in A}\epsilon_aa: \epsilon_a\in \{0,1\}\right\}\]contains no non-trivial $k$-term arithmetic progression. Estimate $g_k(n)$. In particular, is it true that\[g_3(n) \gg 3^n?\]

## Local Computation
- Implemented a deeper randomized-greedy finite search:
 - pick $A\subseteq [1,N]$;
 - compute all subset sums exactly;
 - reject if a nontrivial 3-term AP appears in $\Sigma(A)$.
- This yields finite constructive lower bounds for achievable $|A|$ at selected $N$.
- No asymptotic proof was obtained.

- Best found sizes were $|A|=5$ for $N=80,120,160$ and $|A|=6$ for $N=220,300$.
- The finite search confirms feasibility of sparse AP-free subset-sum behavior, but at scales far below asymptotic regime.

## Local Proof Attempts
The current approach is randomized-greedy construction: choose \(A\subseteq[1,N]\), compute all subset sums exactly, and discard candidates whose subset-sum set contains a nontrivial 3-term progression. This shows AP-free subset-sum behavior is achievable in finite experiments, but only at sizes far below the asymptotic regime relevant to \(g_3(n)\gg 3^n\).
