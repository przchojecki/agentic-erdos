# EP-875

## Problem Statement
Let $A=\{a_1<a_2<\cdots\}\subset \mathbb{N}$ be an infinite set such that the sets\[S_r = \{ a_1+\cdots +a_r : a_1<\cdots<a_r\in A\}\]are disjoint for distinct $r\geq 1$. How fast can such a sequence grow? How small can $a_{n+1}-a_n$ be? In particular, for which $c$ is it possible that $a_{n+1}-a_n\leq n^{c}$?

## Site Remarks
A problem of Deshouillers and Erd\H{o}s (an infinite version of [874]). Such sets are sometimes called admissible. Erd\H{o}s writes 'it [is not] completely trivial to find such a sequence for which $a_{n+1}/a_n\to 1$'. It is not clear from this whether Deshouillers and Erd\H{o}s knew of such a sequence.

  GPT-5.2 Thinking identifies the following additional references:
  
  1. Erdős–Nicolas–Sárközy, Sommes de sous-ensembles (J. Th'eor. Nombres Bordeaux 3 (1991), 55--72)
  
  Here, they construct an infinite admissible set with $A(x):=\#\{a\in A:a\le x \} \gg x^{5-2\sqrt6}$ (Thm. 2). In particular this implies polynomial growth $a_n\ll n^{1/(5-2\sqrt6)}$, hence $\liminf_{n\to\infty} a_{n+1}/a_n=1$. So admissible sets of polynomial growth are known in the literature (at least since 1991).
  
  2. Deshouillers--Freiman, On an additive problem of Erdős and Straus, 2 (Astérisque 258 (1999))
  
  Here, they prove the sharp finite extremal bound: for $N$ large, any admissible $A\subset[1,N]$ satisfies $|A|\le 2\sqrt N + O(1)$ (indeed $\le 2\sqrt{N+\tfrac14}-1$). Consequently any infinite admissible $A=\{a_n\}$ has $A(x)\le (2+o(1))\sqrt x$ and $a_n\ge (1+o(1))n^2/4$; so an eventual gap bound $a_{n+1}-a_n\le n^c$ forces $c\ge 1$ (although it is also possible that no such $c$ exists for some choices of $A$).
