# EP-36

## Problem Statement
Find the optimal constant $c>0$ such that the following holds.

For all sufficiently large $N$, if $A\sqcup B=\{1,\ldots,2N\}$ is a partition into two equal parts, so that $\lvert A\rvert=\lvert B\rvert=N$, then there is some $x$ such that the number of solutions to $a-b=x$ with $a\in A$ and $b\in B$ is at least $cN$.

## Site Remarks
The minimum overlap problem (https://en.wikipedia.org/wiki/Minimum_overlap_problem). The example (with $N$ even) $A=\{N/2+1,\ldots,3N/2\}$ shows that $c\leq 1/2$ (indeed, Erd\H{o}s initially conjectured that $c=1/2$). The lower bound of $c\geq 1/4$ is trivial, and Scherk improved this to $1-1/\sqrt{2}=0.29\cdots$. The current records are\[0.379005 < c < 0.380876,\]the lower bound due to White \cite{Wh22} and the upper bound due to the TTT-Discover LLM \cite{YKLBMWKCZGS26}, improving slightly on earlier bounds due to AlphaEvolve \cite{GGTW25} and Haugland \cite{Ha16}.

This is discussed in problem C17 of Guy's collection \cite{Gu04}.

## Local Proof Attempts
Target:
Pin down the constant-level extremal overlap parameter in EP-36 (suggested by
current best known upper/lower windows).
Step A: Extremal Partition Template
Classify near-optimal balanced partitions/configurations producing overlap ratio
within \(\varepsilon\) of the optimum.
Step B: Stability Inequality
Prove any configuration with overlap below \(c+\varepsilon\) must be
\(o(N)\)-edit-close to a template family.
Step C: Constant Extraction
Compute the exact asymptotic constant by optimizing over template parameters.
Concrete Blocking Lemma (Most Critical):
Need a sharp overlap stability lemma at constant precision:
small improvement below current bounds forces rigid global structure, excluding
all non-template candidates.

Let \(F_N\) be the extremal overlap parameter at size \(N\), and \(c^\star\) the
candidate constant.
Proposition E1 (Stability + template optimization => limit constant):
Assume:
1. (Upper stability) if \(F_N\le c^\star+\varepsilon\), then the configuration is
 \(o_\varepsilon(N)\)-close to a template family \(\mathcal T\);
2. (Template sharpness) \(\inf_{T\in\mathcal T} F_N(T)\to c^\star\).
Then
\[
F_N\to c^\star.
\]
\[
\textit{Proof.}
\]
Take near-extremizers \(X_N\) with \(F_N(X_N)\le \inf F_N+o(1)\). By (1), for
small \(\varepsilon\), \(X_N\) is close to some \(T_N\in\mathcal T\), hence
\[
F_N(X_N)\ge F_N(T_N)-o(1)\ge c^\star-o(1).
\]
By (2), there exist templates with value \(\le c^\star+o(1)\), so
\[
\inf F_N\le c^\star+o(1).
\]
Combine lower/upper bounds to get \(\inf F_N=c^\star+o(1)\), i.e. \(F_N\to c^\star\).
\(\square\)
Proposition E2 (Constant extraction once template family is finite-dimensional):
If \(\mathcal T\) is parametrized by compact parameter set and objective is
continuous, then the optimizing constant \(c^\star\) exists.
\[
\textit{Proof.}
\]
Direct Weierstrass theorem.
\(\square\)
So open work is the stability theorem in E1(1), not the implication chain.
