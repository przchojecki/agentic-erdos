# EP-43

## Problem Statement
If $A,B\subset \{1,\ldots,N\}$ are two Sidon sets such that $(A-A)\cap(B-B)=\{0\}$ then is it true that\[ \binom{\lvert A\rvert}{2}+\binom{\lvert B\rvert}{2}\leq\binom{f(N)}{2}+O(1),\]where $f(N)$ is the maximum possible size of a Sidon set in $\{1,\ldots,N\}$? If $\lvert A\rvert=\lvert B\rvert$ then can this bound be improved to\[\binom{\lvert A\rvert}{2}+\binom{\lvert B\rvert}{2}\leq (1-c+o(1))\binom{f(N)}{2}\]for some constant $c>0$?

## Site Remarks
In \cite{Er95} Erd\H{o}s offered \$100 for a proof or disproof of the first question. In \cite{Er82f} he notes that\[ \binom{\lvert A\rvert}{2}+\binom{\lvert B\rvert}{2}\leq(1+o(1))\frac{N}{2}\sim \binom{f(N)}{2},\]since $f(N)\sim N^{1/2}$. In \cite{Er82f} he notes that perhaps the $O(1)$ error term in the first question is too optimistic.

Since it is known that $f(N)\sim \sqrt{N}$ (see [30]) the latter question is equivalent to asking whether, if $\lvert A\rvert=\lvert B\rvert$,\[\lvert A\rvert \leq \left(\frac{1}{\sqrt{2}}-c+o(1)\right)\sqrt{N}\]for some constant $c>0$. In the comments Tao has given a proof of this upper bound without the $-c$.

In the comments Barreto has given a negative answer to the second question: for infinitely many $N$ there exist Sidon sets $A,B\subset \{1,\ldots,N\}$ with $\lvert A\rvert=\lvert B\rvert$ and $(A-A)\cap (B-B)=\{0\}$ and\[\binom{\lvert A\rvert}{2}+\binom{\lvert B\rvert}{2}\geq (1-o(1))\binom{f(N)}{2}.\]

  A proposed solution on the asymptotic form of #43, posted for community feedback.
  
  Unconditional. For Sidon sets $A, B \subseteq \{1, \ldots, N\}$ with $(A-A) \cap (B-B) = \{0\}$, a convolution-smoothing argument with parameter $H = \lfloor N^{3/4} \rfloor$ gives
  
  $$|A|^2 + |B|^2 \le N + O(N^{3/4}).$$
  
  Together with the elementary lower construction (singleton $B$, maximum Sidon $A$), this gives the asymptotic constant $c = 1$ in the squared-size normalization, which is an asymptotic form of the first question on this page.
  
  Conditional. Assuming the statement of #42 for every fixed $M$, the sharp $+O(1)$ form of #43 cannot hold: choose $M$ with $\binom{M}{2} > K$ and apply #42 to obtain a Sidon $B$ of size $M$ with disjoint nonzero differences from a maximum Sidon $A$. This uses only the existence statement, so it is independent of the status of the recent claimed proof of #42 by Harjas (currently under public discussion in thread/42).
  
  The note builds on T. Tao's earlier upper-bound observation in this thread and J. M. Barreto's negative answer to the equal-size second question. The lower-bound side of $c = 1$ is elementary and does not use Barreto's construction; both remain relevant for finer questions.

- 19:12 on 30 Apr 2026 - Thomas Bloom (reply depth 1):
  Thanks; the fact that the asymptotic form of the first question holds was already noted in [Er84f], as written in the remarks.
  
  The more quantitative upper bound you mention is an immediate generalisation of the Erdős-Turán bound (see e.g. [30]). I worked out the details in an old note, which I summarise below, but this argument was also implicitly in [Er82f] (and no doubt other places as well).
  
  More generally, if $A_1,\ldots,A_m$ are Sidon sets such that $A_i-A_i$ are all disjoint (except at $0$),\[\sum_i \lvert A_i\rvert^2 \leq N+O(m^{1/2}N^{3/4}).\]I will abuse notation slightly and write e.g. $1_M$ for $1_{[M]}$. We know that $\langle 1_{A_i}\ast 1_{M}, 1_{M+N}\rangle=\lvert A_i\rvert M$ for all $i$. By the Cauchy-Schwarz inequality,\[\lvert A_i\rvert^2M^2 \leq (M+N)E(A_i,[M]).\]Summing this over all $i$, and using the Sidon properties,\[\sum_i \lvert A_i\rvert^2 \leq \frac{M+N}{M}\left(\sum_i \lvert A_i\rvert+M\right)=N+O\left(M+\frac{N}{M}\sum_i \lvert A_i\rvert\right),\]and so using $\sum \lvert A_i\rvert \ll m N^{1/2}$ and choosing $M\asymp m^{1/2}N^{3/4}$ we get the result.
  
  The same argument proves\[\sum \lvert A_i\rvert \leq (mN)^{1/2}+O(mN^{1/4}).\]Improving this (at least for $m=O(1)$) seems difficult, probably as difficult as [30].
  
  Regarding the link to [42], the fact that a negative answer follows from [42] was already noted (not even implicitly) by Tao here; and Barreto is Kevin Barreto, not J. M. Barreto.

- 19:16 on 19 Dec 2025 - Kevin Barreto:
  We give a negative answer to the second question. We make use of the following result:
  
  $\textbf{Theorem}$ (Bose–Chowla (https://link.springer.com/article/10.1007/BF02566968)). Let $q$ be a prime power, then there exists a set $S\subseteq\{1,\,2,\dots,\,q^2-2\}$ of cardinality $|S|=q$ which is Sidon modulo $q^2-1$.
  
  Note that a set that is Sidon modulo $m$ is trivially Sidon in $\mathbb{Z}$. We will use such an $S$ with $q$ odd, so that $q^2-1$ is divisible by $2$. We also need a trivial lemma:
  
  $\textit{Lemma 1.}$ If $S$ is Sidon in an abelian group $G$, then for any $0\neq d\in G$, the equation $$s_1-s_2=d=s_3-s_4,\qquad s_i\in S,$$ implies $(s_1,s_2)=(s_3,s_4)$.
  $\textit{Proof.}$ From $s_1-s_2=s_3-s_4$, we obtain $s_1+s_4=s_3+s_2$. By the Sidon property, $\{s_1,s_4\}=\{s_3,s_2\}$. If the matching were $s_1=s_2$, it would force $d=0$, which is excluded. Hence, $s_1=s_3$ and $s_4=s_2$, i.e. $(s_1,s_2)=(s_3,s_4)$. $\square$
  
  When $S$ is Sidon modulo $m$, we may apply $\textit{Lemma 1}$ in $G=\mathbb{Z}/m\mathbb{Z}$. Now, fix an odd prime power $q$, and set $$M:=q^2-1,\qquad N:=\frac{M}{2}=\frac{q^2-1}{2},$$ and let $S\subseteq\{1,\,2,\,\dots,\,M-1\}$ be a Bose-Chowla Sidon set modulo $M$ with $|S|=q$. Furthermore, let $$S_{\mathrm{even}}:=S\cap 2\mathbb{Z},\qquad S_{\mathrm{odd}}:=S\cap(2\mathbb{Z}+1),$$ and write $a:=|S_{\mathrm{even}}|$, $b:=|S_{\mathrm{odd}}|$, so that $a+b=q$.
  
  $\textit{Lemma 2.}$ One has $$a(a-1)+b(b-1)\leq N-1,$$ and consequently, $$(a-b)^2\leq 2q-3,$$ giving $\min\{a,b\}=\frac{q}{2}-\mathcal{O}(\sqrt{q})$ as $q\to\infty$.
  $\textit{Proof.}$ Work in the cyclic group $\mathbb{Z}/M\mathbb{Z}$. Any difference of two even residues (or two odd residues) is an even residue. By $\textit{Lemma 1}$ applied to $S\subseteq\mathbb{Z}/M\mathbb{Z}$, the directed differences within $S_{\mathrm{even}}$ give $a(a-1)$ distinct non-zero residues in $\mathbb{Z}/M\mathbb{Z}$, all even. Likewise, the directed differences within $S_{\mathrm{odd}}$ give $b(b-1)$ distinct non-zero even residues. These two collections are disjoint, again by $\textit{Lemma 1}$, because they arise from disjoint collections of ordered pairs $(s,s')\in S\times S$ (one with both even, one with both odd). But, the set of non-zero even residues modulo $M=2N$ has size exactly $N-1$ (namely $\{2,\,4,\,\dots,\,2N-2\}$). Hence, $$a(a-1)+b(b-1)\leq N-1=\frac{q^2-3}{2}.$$ Now compute $$a(a-1)+b(b-1)=a^2+b^2-(a+b)=\frac{(a+b)^2+(a-b)^2}{2}-q=\frac{q^2+(a-b)^2}{2}-q.$$ Comparing with $(q^2-3)/2$ gives $(a-b)^2\leq 2q-3$. In particular, $$\min\{a,b\}=\frac{q-|a-b|}{2}\geq\frac{q-\sqrt{2q-3}}{2}=\frac{q}{2}-\mathcal{O}(\sqrt{q}),$$ as claimed. $\square$
  
  Now set $m:=\min\{a,b\}$, and choose subsets $E\subseteq S_{\mathrm{even}}$, $O\subseteq S_{\mathrm{odd}}$, with $|E|=|O|=m$, and define $$A_0:=\{e/2:e\in E\}\subset\{0,\,\dots,\,N-1\},\qquad B_0:=\{(o-1)/2:o\in O\}\subset\{0,\,\dots,\,N-1\}.$$ Write $A:=A_0+1$ and $B:=B_0+1$. Then, $A,B\subset[N]$ and $|A|=|B|=m$.
  
  $\textit{Lemma 3.}$ The sets $A$ and $B$ are Sidon with $(A-A)\cap (B-B)=\{0\}$.
  $\textit{Proof.}$ We prove $A$ is Sidon (the proof for $B$ is identical). It suffices to work with $A_0,B_0$ as shifts preserve the Sidon property. Suppose $$x_1+x_2=x_3+x_4,\qquad x_i\in A_0.$$ Write $x_i=e_i/2$ with $e_i\in E\subseteq S$. Then, $e_1+e_2=e_3+e_4$ in integers, hence also modulo $M$. Since $S$ is Sidon modulo $M$, we obtain $\{e_1,e_2\}=\{e_3,e_4\}$, and therefore $\{x_1,x_2\}=\{x_3,x_4\}$. Thus, $A_0$, and hence $A$, is Sidon. Moreover, suppose $d\in (A_0-A_0)\cap(B_0-B_0)$, then $\exists e_1,e_2\in E$ and $o_1,o_2\in O$ s.t. $$d=\frac{e_1-e_2}{2}=\frac{o_1-o_2}{2}.$$ Hence, $e_1-e_2=o_1-o_2$ as integers, and therefore also modulo $M$. By $\textit{Lemma 1}$ applied in $\mathbb{Z}/M\mathbb{Z}$, if this common residue is non-zero, then the ordered pairs must coincide, i.e. $(e_1,e_2)=(o_1,o_2)$, which is impossible because $e_i$ are even and $o_i$ are odd. Therefore, the common residue must be $0$, i.e. $e_1=e_2$ and $o_1=o_2$, so $d=0$. $\square$
  
  $\textbf{Theorem 1.}$ For infinitely many $N$ (namely $N=(q^2-1)/2$ with $q$ an odd prime power), there exist Sidon sets $A,B\subset [N]$, with $|A|=|B|$ and $(A-A)\cap (B-B)=\{0\}$, such that $$\binom{|A|}{2}+\binom{|B|}{2}\geq (1-o(1))\binom{f(N)}{2}.$$ In particular, there is $\textbf{no}$ choice of absolute constant $c>0$ for which the given inequality in question holds for all such Sidon sets $A,B$ as $N\to\infty$.
  $\textit{Proof.}$ We use our previously defined Sidon sets $A,B$. Since $|A|=|B|=m$, $$D(A,B):=\binom{|A|}{2}+\binom{|B|}{2}=2\binom{m}{2}=m(m-1).$$ By $\textit{Lemma 2}$ then, $$D(A,B)=\left(\frac{q}{2}-\mathcal{O}(\sqrt{q})\right)\left(\frac{q}{2}-\mathcal{O}(\sqrt{q})-1\right)=\frac{q^2}{4}+\mathcal{O}(q^{3/2}).$$ Recalling $q^2=2N+1$, this becomes $$D(A,B)=\frac{2N+1}{4}+\mathcal{O}((2N+1)^{3/4})=\frac{N}{2}+\mathcal{O}(N^{3/4}).$$ In particular, $D(A,B)=(1/2 + o(1))N$. On the other hand, $f(N)=(1+o(1))\sqrt{N}$, so $$\binom{f(N)}{2}=\frac{f(N)(f(N)-1)}{2}=\left(\frac{1}{2}+o(1)\right)N.$$ Combining these two results along the infinite sequence $N=(q^2-1)/2$ (with $q$ an odd prime power) yields $$\binom{|A|}{2}+\binom{|B|}{2}\geq (1-o(1))\binom{f(N)}{2}\text{ as }N\to\infty,$$ i.e. a failure to the inequality $$\binom{|A|}{2}+\binom{|B|}{2}\leq(1-c+o(1))\binom{f(N)}{2}$$ for any fixed $c>0$ for all sufficiently large $N$ in this sequence. $\square$

- 04:24 on 03 Dec 2025 - TerenceTao (reply depth 1):
  This does technically refute Erdos's assertion (that he wrote that he was "sure" of), but it is possible that he intended this claim only for large $N$.
  
  Asymptotically, it is known that $f(N) = (1+o(1)) \sqrt{N}$, so the claim here for large $N$ is equivalent to asking for $|A|= |B| \leq (\frac{1}{\sqrt{2}}-c+o(1)) \sqrt{N}$ for some $c>0$. Without the $c$, one can obtain this bound by the following standard argument. By hypothesis one has the pointwise bound
  $$ 1_A * 1_{-A}(n) + 1_B * 1_{-B}(n) \leq (|A|^2 + |B|^2) 1_{n=0} + 1$$
  for any $n$; summing against $1_{[1,H]} * 1_{-[1,H]}(n)$ for some shift $H$ we conclude that
  $$ \| 1_A * 1_{[1,H]} \|_{\ell^2}^2 + \| 1_B * 1_{[1,H]} \|_{\ell^2}^2 \leq (|A|^2+|B|^2) H + H^2.$$
  From Cauchy-Schwarz one has
  $$ \| 1_A * 1_{[1,H]} \|_{\ell^2}^2 \geq \| 1_A * 1_{[1,H]} \|_{\ell_1^2}/(N+H) = |A|^2 H^2 / (N+H)$$
  and similarly for $B$. We conclude that
  $$ (|A|^2+|B|^2) \frac{H^2}{N+H} \leq (|A|^2+|B|^2) H + H^2,$$
  and on choosing say $H = \lfloor N^{1/2} \rfloor$ one can arrive at $|A|^2+|B|^2 = N + O(\sqrt{N})$ which gives $|A|=|B| \leq \frac{1}{\sqrt{2}} \sqrt{N} + O(1)$.

## Local Proof Attempts
Setup:
Let m = |A|, n = |B|.
For each nonzero integer d, let
- r_A(d) = # { (a,a') in A^2: a-a' = d }
- r_B(d) = # { (b,b') in B^2: b-b' = d }.
For Sidon sets in integers, nonzero internal differences are unique, so r_A(d), r_B(d) in {0,1} for d != 0.
Condition (A-A) ∩ (B-B) = {0} implies r_A(d) r_B(d) = 0 for d != 0.

What we can prove cleanly:
1. Global difference-count bound
 sum_{d>0}(r_A(d)+r_B(d)) = C(m,2)+C(n,2) <= N-1.
 Reason: positive differences lie in {1,...,N-1} and are disjoint across A and B.
2. Cross-sum uniqueness
 If a1+b1 = a2+b2 with ai in A, bi in B, then a1-a2 = b2-b1 is in
 (A-A) ∩ (B-B), hence must be 0, so a1=a2, b1=b2.
 Therefore all A+B sums are distinct and |A+B| = mn <= 2N-1.
3. Cross-difference uniqueness
 If a1-b1 = a2-b2, then a1-a2 = b1-b2; same argument gives uniqueness.
 Hence |A-B| = mn <= 2N-1.
These are strong structural facts, but still far from the target ~ N/2 scale implied by C(f(N),2).

Why the direct routes stall:
- Fourier/energy identities with
 F(t) = |sum_{a in A} e^{iat}|^2 + |sum_{b in B} e^{ibt}|^2
 mostly collapse to identities already implied by Sidon + disjoint-difference support.
- Ruzsa-style inequalities using |A+B|=mn and Sidon energies do not currently force
 C(m,2)+C(n,2) down to C(f(N),2)+O(1).
- The remaining gap is essentially an extremal packing obstruction:
 proving a single-color Sidon extremizer controls two-color disjoint-difference packings up to constant error.

\textit{Proof.}
