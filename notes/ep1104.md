# EP-1104

## Problem Statement
Let $f(n)$ be the maximum possible chromatic number of a triangle-free graph on $n$ vertices. Estimate $f(n)$.

## Site Remarks
The best bounds available are\[(1-o(1))(n/\log n)^{1/2}\leq f(n) \leq (2+o(1))(n/\log n)^{1/2}.\]The upper bound is due to Davies and Illingworth \cite{DaIl22}, the lower bound follows from a construction of Hefty, Horn, King, and Pfender \cite{HHKP25}.

One can ask a similar question for the maximum possible chromatic number of a triangle-free graph on $m$ edges. Let this be $g(m)$. Davies and Illingworth \cite{DaIl22} prove\[g(m) \leq (3^{5/3}+o(1))\left(\frac{m}{(\log m)^2}\right)^{1/3}.\]Kim \cite{Ki95} gave a construction which implies $g(m) \gg (m/(\log m)^2)^{1/3}$.

The function $f(n)$ is the inverse to the function $h_3(k)$ considered in [1013].

A generalisation of $f(n)$ is considered in [920].

  Here's some further non-exhaustive context and speculation.
  
  Before the work of Davies and Illingworth, in this paper (https://doi.org/10.37236/8650) the same upper bounds were confirmed for the fractional chromatic number $\chi_f(G)$. And slightly worse bounds were given on the chromatic number $\chi(G)$, a factor $\sqrt{2}$ higher for the upper bound on $f(n)$, and a factor $2^{1/3}$ higher for the upper bound on $g(n)$.
  
  Moreover, it was shown that $\chi_f(G) \leq (\sqrt{2}+o(1)) \sqrt{\frac{n}{\log n}}$ and $\chi_f(G) \leq (18^{1/3}+o(1)) \frac{m^{1/3}}{(\log m)^{2/3}}$ hold for all $\textit{regular}$ triangle-free graphs $G$ on $n$ vertices and $m$ edges. This (and other evidence) motivated a conjecture that the condition of regularity could be dropped, which was later confirmed in a very nice paper of Martinsson and Steiner (https:// doi:10.1017/fms.2025.10112). Perhaps the same will be true for the chromatic number instead, thus improving the state of the art for Problem 1104.
  
  The vague intuition is that the largest independent set $\alpha(G)$ seems to govern the right answer; we know that $\chi(G)\geq \frac{n}{\alpha(G)}$, but for this type of problem it appears that also something like $\max_{|G|=n}\chi(G) \lessapprox \frac{n}{\min_{|G|=n}\alpha(G)}$ holds. Plugging in Shearer's lower bound $(1/\sqrt{2}+o(1)) \sqrt{n \log n}$ on the independence number leads to the guess that $\chi(G) \leq (\sqrt{2}+o(1)) \sqrt{\frac{n}{\log n}}$.
  
  Following the conjectures made in the latest breakthroughs papers on $R(3,t)$, one might even guess tight bounds $\alpha(G) \geq (1+o(1)) \sqrt{n \log n}$ and $\chi(G)\leq (1+o(1)) \sqrt{\frac{n}{\log n}}$.
  
  (And from there the heavy speculation continues; e.g. is the (list) chromatic number of a triangle-free graph with maximum degree $\Delta$ at most $(1/2+o(1)) \frac{\Delta}{\log \Delta} $ ? This would be tight. By the Johansson-Molloy theorem, it is currently known with $(1+o(1))$ instead, and this was used to prove some of the results mentioned above.)

## Local Computation
- deep random-search:
 - random triangle-free process generation,
 - DSATUR heuristic coloring to hunt high-$\chi$ samples,
 - exact/partial chromatic certification on best-found sample at each $n$.
- Certification step tries $k$-colorability for small $k$ with hard time limits, yielding exact values when solved and otherwise lower/upper bounds.

Deep run (DEPTH=4) used:
- $n\in\{30,40,50,60\}$,
- 25s random-search budget per $n$,
- exact-colorability attempt timeout 1.8s per tested $k$.
Sample counts were large (e.g. about $503{,}666$ graphs at $n=30$).
Best heuristic values found were $6,6,7,7$ for $n=30,40,50,60$.
Certification outcomes:
- $n=30$: exact $\chi=4$ (heuristic overestimated to 6).
- $n=40,50,60$: proved non-3-colorable; 4-colorability checks timed out, so current certified interval is
 - $4\le \chi \le 6$ for $n=40$,
 - $4\le \chi \le 7$ for $n=50,60$.
Interpretation:
- finite search confirms dense triangle-free samples with chromatic number at least 4,
- but heuristic best values alone are not reliable without exact certification,
- current run does not tighten asymptotic constants.

## Local Proof Attempts
Target:
Determine the sharp constant regime for
\[
f(n)=\max\{\chi(G): |V(G)|=n,\ G\ \text{triangle-free}\},
\]
known to be \(\Theta(\sqrt{n/\log n})\).
A. Concrete Blocking Lemma (Most Critical):
Prove a stability theorem: every near-extremal triangle-free high-\(\chi\) graph contains a large induced subgraph with pseudorandom neighborhood profile matching optimal probabilistic constructions.
This would convert existential bounds into sharper constants.
B. Reduction Lemmas (with proofs):
Lemma B1 (independence-number reduction):
For triangle-free \(G\), if \(\alpha(G)\ge a\), then
\[
\chi(G)\le \frac{n}{a}.
\]
Proof.
Greedy coloring repeatedly removes independent sets of size at least \(a\), using at most \(n/a\) colors. \(\square\)
Lemma B2 (target independence threshold):
To show \(\chi(G)\ll \sqrt{n/\log n}\), it suffices to prove
\[
\alpha(G)\gg \sqrt{n\log n}.
\]
Proof.
Insert this lower bound into Lemma B1. \(\square\)
Lemma B3 (A plus concentration implies constant refinement):
If near-extremal graphs are pseudorandom in the sense of A, then refined concentration estimates on \(\alpha(G)\) yield improved constant factors in \(\chi\)-bounds.
Proof.
Pseudorandom structure allows sharper probabilistic/entropy estimates for independent sets than in worst-case triangle-free graphs. \(\square\)
C. Main unresolved point:
The key missing piece is a robust structural description of extremal triangle-free high-chromatic graphs beyond current probabilistic lower-bound constructions.
