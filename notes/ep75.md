# EP-75

## Problem Statement
Is there a graph of chromatic number $\aleph_1$ with $\aleph_1$ vertices such that for all $\epsilon>0$ if $n$ is sufficiently large and $H$ is a subgraph on $n$ vertices then $H$ contains an independent set of size $>n^{1-\epsilon}$?

What about an independent set of size $\gg n$?

## Site Remarks
Conjectured by Erdős, Hajnal, and Szemerédi \cite{EHS82}.

In \cite{Er95} Erd\H{o}s asks this without the condition that the graph also have $\aleph_1$ vertices, but this is an oversight, since already in \cite{EHS82} they provide such a construction.

In \cite{Er95d} Erd\H{o}s offers \$1000 for a complete solution to all problems of this type (for example including also [74]), and a 'generous reward for any significant partial results'.

See also [750].

## Local Computation
- Implemented a per-problem to test the finite analogue of “large independent sets in all large finite subgraphs” on a canonical high-chromatic construction.
- In sampled induced subgraphs, the minimum independent-set ratio stayed around 0.42-0.50 for tested m, suggesting strong finite local independence persists in this model.
- Obstacle: EP-75 is about chromatic number \aleph_1 and asymptotic n^{1-\epsilon} behavior in all sufficiently large finite subgraphs; finite Mycielski evidence is suggestive but non-transferable without an infinite combinatorial lift.

## Local Proof Attempts
Route:
Interpreted the problem as constructing an uncountably chromatic graph with very large finite-subgraph independence numbers.

Hard point:
Need to reconcile two competing demands simultaneously:
- global chromatic number aleph_1,
- near-linear independent sets in every large finite subgraph.

Target:
Find \(G\) with \(\chi(G)=\aleph_1\) such that for every \(\varepsilon>0\),
every sufficiently large finite \(H\subseteq G\) has
\[
\alpha(H)\ge |V(H)|^{1-\varepsilon}.
\]
Step A: Sparse uncountably chromatic framework
Construct \(G\) via transfinite forcing/induction so finite neighborhoods remain
highly sparse while global coloring obstruction survives.
Step B: Quantitative extraction
Prove a hereditary estimate
\[
\alpha(H)\ge c_\varepsilon |V(H)|^{1-\varepsilon}
\]
for all sufficiently large finite \(H\subseteq G\).
Step C: Upgrade to full statement
Diagonalize in \(\varepsilon=1/m\) to get the asymptotic “for every
\(\varepsilon>0\)” conclusion.
Concrete Blocking Lemma (Most Critical):
Need a lemma converting local sparsity/control of short cycles in all finite
traces into near-linear independence uniformly over all induced subgraphs.

Proposition I1 (Diagonal epsilon-upgrade):
Assume that for each integer \(m\ge1\), there are \(N_m,c_m>0\) such that every
finite \(H\subseteq G\) with \(|V(H)|\ge N_m\) satisfies
\[
\alpha(H)\ge c_m |V(H)|^{1-1/m}.
\]
Then for every \(\varepsilon>0\), all sufficiently large \(H\subseteq G\) obey
\[
\alpha(H)\ge |V(H)|^{1-\varepsilon-o(1)}.
\]
\[
\textit{Proof.}
\]
Choose \(m\) with \(1/m<\varepsilon\). For \(|V(H)|\ge N_m\),
\[
\alpha(H)\ge c_m |V(H)|^{1-1/m}
=|V(H)|^{1-\varepsilon}\cdot c_m |V(H)|^{\varepsilon-1/m}.
\]
As \(|V(H)|\to\infty\), the factor \(c_m |V(H)|^{\varepsilon-1/m}\to\infty\),
giving the claimed exponent bound up to negligible loss.
\(\square\)
Proposition I2 (What remains):
If one constructs \(G\) with \(\chi(G)=\aleph_1\) and verifies the hypothesis of
Proposition I1, EP-75 follows.
\[
\textit{Proof.}
\]
Combine Proposition I1 with the chromatic requirement.
\(\square\)
