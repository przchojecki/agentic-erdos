# EP-1184

## Problem Statement
Let $f(n,k)$ count the number of $1\leq i\leq k$ such that $P(n+i)>k$ (where $P(m)$ is the largest prime divisor of $m$). Is it true that, if $\alpha>1$ is such that $n=k^{\alpha+o(1)}$, then\[f(n,k)=(1-\rho(\alpha)+o(1))k,\]where $\rho$ is the Dickman function (https://en.wikipedia.org/wiki/Dickman_function)?

## Site Remarks
Erd\H{o}s \cite{Er76e} proved that, for every $\alpha>1$, if $k$ is sufficiently large and $n>k^\alpha-k$ then\[f(n,k) > \left(1-\frac{1}{\alpha}+c_\alpha\right)k\]for some constant $c_\alpha>0$, and if $1<\alpha<2$ and $n\leq k^\alpha-k$ then\[f(n,k) < (\alpha-1+o(1))k.\]He knew of no non-trivial bounds when $\alpha \geq 2$.

Ramachandra, Shorey, and Tijdeman \cite{RST75b} proved that if $n>\exp(c(\log k)^2)$ for a constant $c>0$ then $f(n,k)\geq k-\pi(k)$.
