# EP-573

## Problem Statement
Is it true that\[\mathrm{ex}(n;\{C_3,C_4\})\sim (n/2)^{3/2}?\]

## Site Remarks
A problem of Erd\H{o}s and Simonovits, who proved that\[\mathrm{ex}(n;\{C_4,C_5\})=(n/2)^{3/2}+O(n).\]K\"{o}v\'{a}ri, S\'{o}s, and Tur\'{a}n \cite{KST54} proved that the extremal number of edges for containing either $C_4$ or an odd cycle of any length is $\sim (n/2)^{3/2}$. This problem is therefore asking whether the threshold is the same if we just forbid odd cycles of length $3$.

See also [574] for the general case, and [765] for $\mathrm{ex}(n;C_4)$.

This problem is #48 in Extremal Graph Theory (https://mathweb.ucsd.edu/~erdosproblems/erdos/newproblems/TuranC3C4.html) in the graphs problem collection.
