# EP-787

## Problem Statement
Let $g(n)$ be maximal such that given any set $A\subset \mathbb{R}$ with $\lvert A\rvert=n$ there exists some $B\subseteq A$ of size $\lvert B\rvert\geq g(n)$ such that $b_1+b_2\not\in A$ for all $b_1\neq b_2\in B$.

Estimate $g(n)$.

## Site Remarks
This function was considered by Erd\H{o}s and Moser. Choi observed that, without loss of generality, one can assume that $A\subset \mathbb{Z}$.

Klarner proved $g(n) \gg \log n$ (indeed, a greedy construction suffices). Choi \cite{Ch71} proved $g(n) \ll n^{2/5+o(1)}$. The current best bounds known are\[(\log n)^{1+c} \ll g(n) \ll \exp(\sqrt{\log n})\]for some constant $c>0$, the lower bound due to Sanders \cite{Sa21} and the upper bound due to Ruzsa \cite{Ru05}. Beker \cite{Be25} has proved\[(\log n)^{1+\tfrac{1}{68}+o(1)} \ll g(n).\]

## Local Computation
- Built deeper exact finite proxy:
 - for each sampled \(A\), construct conflict graph on indices \(i\neq j\) when \(a_i+a_j\in A\),
 - compute exact maximum independent set size \(\alpha(A)\), yielding a lower-bound proxy for \(g(n)\).
- Compared structured families (interval, odd interval, geometric-like) plus random sets.

- For \(n=20,28,36,44\), worst sampled family remained the interval \(\{1,\dots,n\}\).
- Worst ratios \(\alpha(A)/n\) were about 0.55, 0.536, 0.528, 0.523, showing gradual decline.
- Random and non-interval structured samples were generally less adversarial.

## Local Proof Attempts
The finite model converts the problem into an exact maximum independent-set computation in the conflict graph defined by pairwise sums landing back in \(A\). On sampled families the interval remains the worst case, which is useful guidance, but it does not determine the asymptotic order of \(g(n)\) or prove that intervals are extremal.
