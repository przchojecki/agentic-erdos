# EP-602

## Problem Statement
Let $(A_i)$ be a family of sets with $\lvert A_i\rvert=\aleph_0$ for all $i$, such that for any $i\neq j$ we have $\lvert A_i\cap A_j\rvert$ finite and $\neq 1$. Is there a $2$-colouring of $\cup A_i$ such that no $A_i$ is monochromatic?

- 20:13 on 20 Apr 2026 - AronBhalla:
  This page should probably record the following (located using GPT 5.4 Thinking):
  
  1. Lovász proved the finite analogue (https://www.renyi.hu/~elp/Splitting/Erdos-AoC99.pdf): if $H$ is a hypergraph on a finite set $X$, all edges have size at least $2$, and there are no edges $E,F$ with $|E\cap F|=1$, then $X$ has a $2$-partition such that every edge meets both classes.
  
  2. If the index set is countable, the answer is yes, and the intersection condition is unnecessary. This is Bernstein's Lemma (https://www.renyi.hu/~elp/Splitting/Erdos-AoC99.pdf): every countable system of infinite sets has Property B. In fact, the name “Property B” was given in honour of Bernstein’s result.
  
  3. If there is a fixed $n<\omega$ such that $|A_i\cap A_j|\leq n$ for all $i\neq j$, then the answer is yes. This is Miller’s theorem on strongly almost disjoint families. In fact, Komjáth later proved the stronger statement (https://doi.org/10.1007/BF01958019) that every such family of countable sets is essentially disjoint; after deleting finitely many points from each member, the remaining sets can be made pairwise disjoint. This immediately gives a splitting in which each $A_i$ meets both colour classes infinitely often.
  
  4. Pairwise finite intersections alone are not enough. Hajnal, Juhász and Shelah (https://shelah.logic.at/files/95149/249.pdf) record that there is an $\omega$-almost disjoint subfamily of $[\omega]^\omega$ which is not $2$-colourable, originally due to Miller. Thus the extra hypothesis $|A_i\cap A_j|\neq1$ is needed.
