# EP-858

## Problem Statement
Let $A\subseteq \{1,\ldots,N\}$ be such that there is no solution to $at=b$ with $a,b\in A$ and the smallest prime factor of $t$ is $>a$. Estimate the maximum of\[\frac{1}{\log N}\sum_{n\in A}\frac{1}{n}.\]

## Site Remarks
Alexander \cite{Al66} and Erd\H{o}s, S\'{a}rk\"{o}zi, and Szemer\'{e}di \cite{ESS68} proved that if $A$ is an infinite set with this property then\[\sum_{n\in A\cap [1,N]}\frac{1}{n}=o(\log N)\](at a rate which depends on $A$), and furthermore for any fixed large $N$ the supremum in this question is bounded away from $0$.

This condition on $A$ is a weaker form of the usual primitive condition. If $A$ is primitive then Behrend \cite{Be35} proved\[\frac{1}{\log N}\sum_{n\in A}\frac{1}{n}\ll \frac{1}{\sqrt{\log\log N}}.\]An example of such a set $A$ is the set of all integers in $[N^{1/2},N]$ divisible by some prime $>N^{1/2}$.

This has been solved (https://www.ulam.ai/research/erdos858-asymptotic.pdf) by Chojecki and GPT-5.4 Pro (see the comments), who show that for large $N$\[\max_A \sum_{n\in A}\frac{1}{n}=(c+o(1))\log N\]where the maximum is over all $A\subseteq \{1,\ldots,N\}$ with the stated property and $c\approx 0.618\cdots$ is an explicit constant.

See also [143].

- 22:07 on 23 Apr 2026 - TerenceTao (reply depth 1):
  Here is a summary of the argument. One places a flow network on $\{1,\dots,N\}$ by creating a flow $w( n p_1 \dots p_k \mapsto n ) = \frac{1}{n p_1 \dots p_k}$ if $n < p_1 \leq \dots \leq p_k$, but one does not have $n p_1 \dots p_{i-1} < p_i$ for any $1 < i \leq k$. Then the outflow at any $1 < n \leq N$ is exactly $1/n$ (with only one outgoing edge), and the downward flow from any $n \in A$ cannot hit any other element of $A$ by hypothesis. Because of this, one can use the discrete divergence theorem to express $\sum_{n \in A} \frac{1}{n}$ as the sum of divergences $\sum_{n \in U_A} \mathrm{div}(v)$, where $U_A$ is the upset associated to $A$ (all the elements of $\{1,\dots,N\}$ that flow down to an element of $A$).
  
  Routine Mertens' theorem calculations show that the divergence is positive (more outflow than inflow) for $n > N^{\alpha_2+o(1)}$ and negative (more inflow than outflow) for $n < N^{\alpha_2-o(1)}$ for a certain explicit constant $\alpha_2 = 0.28043830989\dots$. From this the optimal $A$ is essentially those elements above $N^{\alpha_2}$ that flow down to an element below $N^{\alpha_2}$. The total outflow $\sum_{n \in A} \frac{1}{n}$ can then be computed to be $(c_2+o(1)) \log N$ for an explicit constant $c_2 = 0.6187712111\dots$.

What they show is that if $A$ is an infinite set with the stated property then $\lim_{N \to \infty} \frac{1}{\log N} \sum_{n \in A: n \leq N} \frac{1}{n} = 0$, but the convergence is non-uniform in $A$, and indeed the supremum $\sup_A \frac{1}{\log N} \sum_{n \in A: n \leq N} \frac{1}{n}$ stays bounded away from zero.
