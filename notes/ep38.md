# EP-38

## Problem Statement
Does there exist $B\subset\mathbb{N}$ which is not an additive basis, but is such that for every set $A\subseteq\mathbb{N}$ of Schnirelmann density $\alpha$ and every $N$ there exists $b\in B$ such that\[\lvert (A\cup (A+b))\cap \{1,\ldots,N\}\rvert\geq (\alpha+f(\alpha))N\]where $f(\alpha)>0$ for $0<\alpha <1 $?

The Schnirelmann density is defined by\[d_s(A) = \inf_{N\geq 1}\frac{\lvert A\cap\{1,\ldots,N\}\rvert}{N}.\]

## Site Remarks
Erd\H{o}s \cite{Er36c} proved that if $B$ is an additive basis of order $k$ then, for any set $A$ of Schnirelmann density $\alpha$, for every $N$ there exists some integer $b\in B$ such that\[\lvert (A\cup (A+b))\cap \{1,\ldots,N\}\rvert\geq \left(\alpha+\frac{\alpha(1-\alpha)}{2k}\right)N.\]It seems an interesting question (not one that Erd\H{o}s appears to have asked directly, although see [35]) to improve the lower bound here, even in the case $B=\mathbb{N}$. Erd\H{o}s observed that a random set of density $\alpha$ shows that the factor of $\frac{\alpha(1-\alpha)}{2}$ in this case cannot be improved past $\alpha(1-\alpha)$.

This is a stronger property than $B$ being an essential component (see [37]). Linnik \cite{Li42} gave the first construction of an essential component which is not an additive basis.

A positive solution was given by GPT 5.5 Pro (prompted by gebyjaff) in the comments; in fact a sparse random set $B$ has this property, with $f(\alpha)\gg \alpha (1-\alpha)^2$.

  Thanks; here is an alternative sketch of the proof. (As usual, GPT favours excessively long descriptions and proofs, and it is hard to see what is new - the actual argument is quite short, and mostly classical.) It is very similar to Ruzsa's construction of thin essential components, which uses the same random choice of $B$, and argues via considering the Fourier transform as here.
  
  Let $B$ be a random set, where we include $n\in B$ with probability $p_n=\frac{(\log n)^\epsilon}{n}$. With high probability , $\lvert B\cap [1,x]\rvert \ll (\log x)^{1+O(\epsilon)}$, and hence trivially $B$ cannot be an additive basis.
  
  Now suppose $A\subseteq [1,N]$ and let $C=[1,N]\backslash A$ and let $B_N=B\cap (N/2,N]$. (I'll assume that $\alpha\leq 1/2$ for simplicity, the general proof is the same just with factors of $1-\alpha$ to track.) It suffices to find some $b\in B_N$ such that $\lvert (A+b)\cap C\rvert \gg_\alpha N$; note that\[\sum_{b\in B_N}\lvert (A+b)\cap C\rvert=\int_0^1\widehat{1_{A}}(\gamma)\widehat{1_{B_N}}(\gamma)\widehat{1_{C}}(-\gamma)\mathrm{d}\gamma.\]The key point is that, with positive probability, for all large $N$ and $\gamma\in [0,1]$, if $f(n)=p_n1_{N/2<n\leq N}$ then\[\lvert\widehat{1_{B_N}}(\gamma)-\widehat{f}(\gamma)\rvert =o(\lvert B_N\rvert).\](This is a classical fact in Fourier analysis, and goes back at least to the work of Salem and Zygmund on Fourier series with random coefficients; it is a standard application of e.g. Hoeffding's inequality.)
  
  Therefore\[\sum_{b\in B_N}\lvert (A+b)\cap C\rvert=\sum_{N/2<n\leq N}p_n \lvert (A+n)\cap C\rvert+o(\lvert B_N\rvert N).\]The first sum is, assuming $A$ grows regularly like $\lvert A\cap [1,m]\rvert \gg \alpha m$ for all $m$,\[\gg \frac{(\log N)^\epsilon}{N}\sum_{N/2<n\leq N}\lvert (A+n)\cap C\rvert\gg \alpha N(\log N)^\epsilon.\]Now again, by e.g. Hoeffding, $\lvert B_N\rvert \asymp (\log N)^\epsilon$ for all large $N$ (with high probability), and hence this is $\gg \alpha N$, and so by averaging there exists some $b\in B_N$ such that\[\lvert (A+b)\cap C\rvert \gg \alpha N\]as required.

## Local Computation
Finite exhaustive modeling was carried out: for each candidate shift-set B, and for each admissible finite set A\subseteq[1,N] with positive density floor, the quantity \max_{b\in B} ( |(A\cup(A+b))\cap[1,N]|-|A\cap[1,N]| )/N was computed and then minimized over A.

In this finite model, structured non-basis proxy families such as even shifts, multiples of 3, powers of 2, and prime shifts all admit near-zero worst-case gains at the tested scales, while allowing all shifts gives strictly stronger gains.

Turning these finite-window obstructions into a rigorous infinite Schnirelmann argument, or proving positivity for a non-basis B, still requires a structural theorem beyond computation.

## Local Proof Attempts
Background gives density increment when \(B\) is an additive basis of finite order \(k\), and it also notes the existence of essential components that are not additive bases.

The unresolved point is whether such a non-basis \(B\) can still satisfy the stronger uniform increment property.

Target:
Find a non-additive-basis set \(B\subset\mathbb N\) and \(c>0\) such that for
every \(A\subset\mathbb N\) with \(\sigma(A)>0\), some \(b\in B\) satisfies
\[
\sigma(A\cup(A+b))\ge (1+c)\sigma(A).
\]
Step A: Uniform Increment Hypothesis
Assume the above inequality with fixed \(c>0\) holds for all \(A\) of positive
Schnirelmann density.
Step B: Iterative Density Amplification
Iterate shifts from \(B\): define \(A_0=A\), \(A_{t+1}=A_t\cup(A_t+b_t)\) with
best choice \(b_t\in B\). Then
\[
\sigma(A_t)\ge (1+c)^t\sigma(A_0)\wedge 1.
\]
Step C: Finite-Term Coverage Consequence
For \(t\) large enough, \(\sigma(A_t)=1\), forcing eventual full coverage by a
finite iterated sum-difference expression in \(B\).
Concrete Blocking Lemma (Most Critical):
Need an iteration-to-structure theorem: if Step A holds uniformly, then finite
iterates of \(B\)-shifts must act like a finite-order basis operator despite \(B\)
not itself being an additive basis.

Proposition F1 (Iterative multiplicative growth):
Assume there is \(c>0\) such that for every set \(X\) with \(\sigma(X)>0\), one
can choose \(b\in B\) with
\[
\sigma(X\cup(X+b))\ge (1+c)\sigma(X).
\]
Then for the iterative process above,
\[
\sigma(A_t)\ge \min\{1,(1+c)^t\sigma(A_0)\}.
\]
\[
\textit{Proof.}
\]
Induct on \(t\). Base \(t=0\) is trivial. Inductive step uses the hypothesis on
\(X=A_t\):
\[
\sigma(A_{t+1})\ge (1+c)\sigma(A_t)\ge (1+c)\min\{1,(1+c)^t\sigma(A_0)\},
\]
and truncation at \(1\) gives the claim.
\(\square\)
Proposition F2 (Finite-time saturation):
Under Proposition F1 assumptions, if
\[
t\ge \left\lceil \frac{\log(1/\sigma(A_0))}{\log(1+c)}\right\rceil,
\]
then \(\sigma(A_t)=1\).
\[
\textit{Proof.}
\]
By Proposition F1, \(\sigma(A_t)\ge (1+c)^t\sigma(A_0)\ge 1\). Since
\(\sigma(\cdot)\le1\), equality follows.
\(\square\)
