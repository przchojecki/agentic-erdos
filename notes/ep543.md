# EP-543

## Problem Statement
Define $f(N)$ be the minimal $k$ such that the following holds: if $G$ is an abelian group of size $N$ and $A\subseteq G$ is a random set of size $k$ then, with probability $\geq 1/2$, all elements of $G$ can be written as $\sum_{x\in S}x$ for some $S\subseteq A$. Is\[f(N) \leq \log_2 N+o(\log\log N)?\]

## Site Remarks
Erd\H{o}s and R\'{e}nyi \cite{ErRe65} proved that\[f(N) \leq \log_2N+O(\log\log N).\]Erd\H{o}s believed improving this to $o(\log\log N)$ is impossible.

Erd\H{o}s and Hall \cite{ErHa78b} proved that it is not true that\[f(N) \leq \log_2N+o(\log\log\log N).\]ChatGPT and Tang have disproved this (https://github.com/QuanyuTang/erdos-problem-543/blob/main/On_Erdos_Problem_543_Revised_and_Verified.pdf), confirming Erd\H{o}s' belief, showing that if $f(N)\leq \log_2 N+o(\log\log N)$ then, for all large enough primes $p$, a random subset of $\mathbb{F}_p$ of size $\leq f(p)$ fails to generate $\mathbb{F}_p$ in this way.

See also [1179].

  There is Exercise 1.1.7 in my Additive Combinatorics book with Van Vu (https://terrytao.wordpress.com/books/additive-combinatorics/), which shows that one can cover any finite abelian group $G$ by a cube of dimension at most $\log_2 |G| + O(\log\log |G|)$ (actually the exercise as stated only requires the weaker bound $O(\log |G| + \log\log |G|)$, but if one goes through the proof carefully one gets the stronger bound). [EDIT: I now realize that this exercise in fact follows from the Erdos-Renyi result.] The basic idea is to think of the cube $Q$ as arising from an iterative process $Q \mapsto Q \cup (Q+\{x\})$, and if $Q$ is missing $\alpha |G|$ elements then by the pigeonhole principle one can ensure that $Q \cup (Q+\{x\})$ is missing at most $\alpha^2 |G|$ elements; this is what adds the additional overhead of $O(\log\log |G|)$ to the naive doubling heuristic as to the size of $Q$. But to my knowledge I don't know of literature lower bounding $Q$ in the case of a field of prime order. (Some hypothesis on the group must be imposed, of course: if one had a vector space over ${\bf F}_2$, then usually one gets complete doubling with each iteration, and the excess over $\log_2 |G|$ behaves more like an exponential distribution of mean $O(1)$.) One could conceivably also prove this lower bound using more classic additive combinatorics tools (I'm thinking in particular of Pollard and Green-Ruzsa's robust version of the Cauchy-Davenport inequality) but I haven't done the computations.

- 18:07 on 21 Jan 2026 - TerenceTao (reply depth 1):
  OK, I am tentatively assessing the argument as correct, although a human-generated proof or a Lean verification would still be desirable. It is basically a brute force validation of Poisson-type statistics (somewhat reminiscent of Gallagher's famous calculation that the prime tuples conjecture implies Poisson statistics for the number of primes in a short interval of logarithmic size) for pointwise or pairwise membership in the cube, which is strong enough to make the standard probabilistic heuristics rigorous with acceptable errors. I myself have done similar things for other problems (e.g., my conditional result on [15 (https://www.erdosproblems.com/15)]) but this method did not occur to me when I looked at it today; instead I settled on iterative methods similar to what Erdos and Renyi used, partly due to the fact that this is what I used for Exercise 1.1.7 in my textbook, although this approach would end up requiring quite a bit of inverse Littlewood-Offord theory and would ultimately be a more difficult approach than the one that the AI located. I think this speaks to one of the advantages of AI approaches, in that they can basically try all known methods to attack a problem (especially when applied at scale), whereas human experts will likely only try one or two such methods.
  
  Here is a summary of the strategy. Set $G = {\bf F}_p$ for a large prime $p$, take $k = f(p)$ and write $\lambda := 2^k/p$. If we had $k = f(p) \leq \log_2 p + o(\log\log p)$, then $\lambda \leq \log^{o(1)} p$. The goal is then to show that if $v_1,\dots,v_k$ are drawn uniformly at random from $G$ then the cube $\{0,1\}^k \cdot \{v_1,\dots,v_k\}$ will not cover all of $G$ with probability at least $1/2$. (There is a tiny issue that the $v_1,\dots,v_k$ might collide with each other, but $k = O(\log |G|)$ is so small that this event is negligible.)
  
  Heuristically, the cube consists of $2^k$ random elements of ${\bf F}_p$, so the number of times the cube hits a typical element $x$ of ${\bf F}_p$ should be something like $2^k/p = \lambda$ (the origin needs to be treated separately, but this is a negligible contribution); thus the cube, on average, should cover each element of ${\bf F}_p$ $\lambda$ times over on average. In fact we expect the distribution here to be approximately Poisson with mean $\lambda$, so in particular the probability that $x$ is to be avoided should be about $e^{-\lambda}$, giving a first moment estimate. Similarly, the probability that any two (non-zero) distinct elements $x,y$ of ${\bf F}_p$ should be avoided is about $e^{-2\lambda}$, giving a second moment estimate. Chebyshev's inequality then says that with probability at least $1/2$, the number of elements not hit by the cube should be comparable to $p e^{-\lambda}$, which suffices to solve the problem (after being more careful with quantifying the error terms, but the fact that $\lambda$ is much smaller than $\log p$ keeps things under control).
  
  So the main task is to prove the first and second moment bounds. I'll just focus on the first moment bound, as the second turns out to be similar. We have $2^k$ different events $\epsilon_1 v_1 + \dots + \epsilon_k v_k = x$ and want to understand the probability that none of them occur. Each one basically occurs with probability $1/p$, so if they were independent we would easily get the required Poisson-type statistics. Now the events are not quite independent due to possible linear relations between the vectors $(\epsilon_1,\dots,\epsilon_k)$, but it turns out (basically from some basic inverse Littlewood-Offord theory, although this theory is not explicitly mentioned in the text) that such relations are extremely rare as long as one only involves at most $R$ of these vectors, where $R = \lfloor \log^{1/3} p \rfloor$ say. (Here it is important that we are working in high characteristic; if we were in a vector space over ${\bf F}_2$ there would be a lot more relations and the proof would break down (and the result is indeed false in this setting). In the AI proof this key step is codified in Lemma 2.5.) The upshot of this is that the events $\epsilon_1 v_1 + \dots + \epsilon_k v_k = x$ are essentially $R$-wise independent. To get the desired Poisson prediction of $e^{-\lambda}$ for having all the events fail, standard Bonferroni inequality expansion suggests that one needs to have something like $O(\lambda)$-wise independence; but $R$ is much larger than $\lambda$, so we win. A similar argument handles the second moment.
  
  There is however a lot of careful bookkeeping that needs to be done to make the proof fully rigorous, so additional verification would be very good to have. As mentioned earlier, I think further literature searches are also needed.
