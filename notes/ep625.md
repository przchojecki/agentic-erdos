# EP-625

## Problem Statement
The cochromatic number of $G$, denoted by $\zeta(G)$, is the minimum number of colours needed to colour the vertices of $G$ such that each colour class induces either a complete graph or empty graph. Let $\chi(G)$ denote the chromatic number.

If $G$ is a random graph with $n$ vertices and each edge included independently with probability $1/2$ then is it true that almost surely\[\chi(G) - \zeta(G) \to \infty\]as $n\to \infty$?

## Site Remarks
A problem of Erd\H{o}s and Gimbel (see also \cite{Gi16}). At a conference on random graphs in Poznan, Poland (most likely in 1989) Erd\H{o}s offered \$100 for a proof that this is true, and \$1000 for a proof that this is false (although later told Gimbel that \$1000 was perhaps too much).

It is known that almost surely\[\frac{n}{2\log_2n}\leq \zeta(G)\leq \chi(G)\leq (1+o(1))\frac{n}{2\log_2n}.\](The final upper bound is due to Bollob\'{a}s \cite{Bo88}. The first inequality follows from the fact that almost surely $G$ has clique number and independence number $< 2\log_2n$.)

Heckel \cite{He24} and, independently, Steiner \cite{St24b} have shown that it is not the case that $\chi(G)-\zeta(G)$ is bounded with high probability, and in fact if $\chi(G)-\zeta(G) \leq f(n)$ with high probability then $f(n)\geq n^{1/2-o(1)}$ along an infinite sequence of $n$. Heckel conjectures that, with high probability,\[\chi(G)-\zeta(G) \asymp \frac{n}{(\log n)^3}.\]Heckel \cite{He24c} further proved that, for any $\epsilon>0$, we have\[\chi(G) -\zeta(G) \geq n^{1-\epsilon}\]for roughly $95\%$ of all $n$.

  imagine we instead sample $G_1,G_2\sim G(n,1/2)$ independently. let $X$ be the random variable for the smallest $k$ so that there exists a partition of $[n]$ into $k$ sets $I_1,\dots,I_k$ so that each $I_j$ is an independent set in either $G_1$ or $G_2$. then we couple $X$ so that it is always greater than $\zeta(G)$ for a random $G\sim G(n,1/2)$. the proof is a form of the "McDiarmid's coupling"-technique, which is a very slick trick I think more people should know!
  
  now, $\chi(G)$ concentrates inside an interval of length $n^{1/2+o(1)}$ around its expectation (by an old result of Noga). and a similar result should say $X$ should concentrate in an interval of length $n^{1/2+o(1)}$ around its mean too. thus it would suffice to compute $\mathbb{E}[X]$ to sufficient accuracy, or instead simply show that: $\mathbb{P}(\chi(G_1)-X>n^{1/2+\Omega(1)})>\Omega(1)$.

## Local Computation
- Ran deeper standalone random-graph experiments with significantly larger sizes and restart budgets than earlier quick scans.
- Used independent greedy upper-bound heuristics for \(\chi\) and \(\zeta\) to profile finite-\(n\) gap behavior.
- This is numerical evidence only; it does not prove asymptotic divergence.

- For \(n=120,180,240,320\), average observed heuristic gaps were about \(0.75\) to \(1.00\).
- Positive gaps appeared frequently (roughly \(60\%\) to \(86\%\) of trials).
- At \(n=180\), a rare negative heuristic gap occurred (\(-1\)), indicating finite-size/heuristic noise.
- Overall finite evidence is compatible with growth but not yet diagnostic of the true asymptotic scale.
