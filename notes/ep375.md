# EP-375

## Problem Statement
Is it true that for any $n,k\geq 1$, if $n+1,\ldots,n+k$ are all composite then there are distinct primes $p_1,\ldots,p_k$ such that $p_i\mid n+i$ for $1\leq i\leq k$?

## Site Remarks
Note this is trivial when $k\leq 2$. Originally conjectured by Grimm \cite{Gr69}. This is a very difficult problem, since it in particular implies $p_{n+1}-p_n <p_n^{1/2-c}$ for some constant $c>0$, in particular resolving Legendre's conjecture (https://en.wikipedia.org/wiki/Legendre%27s_conjecture).

Grimm proved that this is true if $k\ll \log n/\log\log n$. Erd\H{o}s and Selfridge improved this to $k\leq (1+o(1))\log n$. Ramachandra, Shorey, and Tijdeman \cite{RST75} have improved this to\[k\ll\left(\frac{\log n}{\log\log n}\right)^3.\]Laishram and Shorey \cite{LaSh06} have verified this is true, for all $k\geq 1$, for all $n\leq 1.9\times 10^{10}$.

This is problem B32 in Guy's collection \cite{Gu04}.

See also [860].

- 16:46 on 16 Jan 2026 - TerenceTao:
  The provenance of the claim that this conjecture implies $p_{n+1} - p_n < p_n^{1/2-c}$ is a little murky. Theorem 1 of the 1971 paper of Erdos and Selfridge (https://users.renyi.hu/~p_erdos/1971-24.pdf) gets the weaker bound $p_{n+1} -p_n \ll p_n^{1/2} / \log^{1/2} p_n$ (which is already enough to get Legendre's conjecture asymptotically) and assert without proof that the result of Ramachandra (https://londmathsoc.onlinelibrary.wiley.com/doi/10.1112/jlms/s2-1.1.303) concerning the existence of non-smooth numbers in short intervals gets the power saving, but on page 15 they write "we do not give the details here".
  
  Theorem 1 is proven by noting that if Grimm's conjecture held, then $\binom{n+k}{k}$ would have to be divisible by at least $k-\pi(k)$ primes larger than $k$, and this and standard prime number theorem and Stirling approximation estimates is enough to conclude. I guess Ramachandra's result would allow one to say that some of these primes are actually rather large, but the actual calculations seem to require some care (one needs a "positive density" version of Ramachandra's result, I think).
