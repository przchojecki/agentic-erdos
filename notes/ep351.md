# EP-351

## Problem Statement
Let $p(x)\in \mathbb{Q}[x]$. Is it true that\[A=\{ p(n)+1/n : n\in \mathbb{N}\}\]is strongly complete, in the sense that, for any finite set $B$,\[\left\{\sum_{n\in X}n : X\subseteq A\backslash B\textrm{ finite }\right\}\]contains all sufficiently large integers?

## Site Remarks
Graham \cite{Gr63} proved this is true when $p(n)=n$. Erd\H{o}s and Graham also ask which rational functions $r(x)\in\mathbb{Z}(x)$ force $\{ r(n) : n\in\mathbb{N}\}$ to be complete?

Graham \cite{Gr64f} gave a complete characterisation of which polynomials $r\in \mathbb{R}[x]$ are such that $\{ r(n) : n\in \mathbb{N}\}$ is complete.

In the comments van Doorn has noted that a positive solution for $p(n)=n^2$ follows from \cite{Gr63} together with result of Alekseyev \cite{Al19} mentioned in [283].

- 18:26 on 15 Sep 2025 - Woett:
  On their question about rational functions, observe that any function of the form $r(x) = \frac{p(x)q(x) + 1}{q(x)}$ with $p(x) \in \mathbb{Z}[x]$, $q(x) = x^n$ and $n \ge 2$ is hopeless, as any sum $$r(a_1) + \ldots + r(a_k) = \big(p(a_1) + \ldots + p(a_k)\big) + \left(\frac{1}{a_1^n} + \ldots + \frac{1}{a_k^n} \right)$$with $k > 1$ lies strictly between two integers, due to the fact that $\frac{1}{2^n} + \frac{1}{3^n} + \ldots < 1$. And this idea can be generalized to rule out many more $r(x)$ for which the remainder (when we divide $p(x)$ by $q(x)$) has degree at most $deg(q(x)) - 2$.

  Vjeko is right that it should be all sufficiently large integers. Moreover, the reference should instead be:

  which can be found here (https://mathweb.ucsd.edu/~ronspubs/63_02_partitions.pdf).
  
  In it, Graham proved that every integer $n \ge 78$ can be written as a sum $a_1 + \ldots + a_r$ of distinct positive integers with $\frac{1}{a_1} + \ldots + \frac{1}{a_r} = 1$, so that every $n \ge 79$ can be written as $(a_1 + \frac{1}{a_1}) + \ldots + (a_r + \frac{1}{a_r})$. He moreover proves that for every $m$ a positive integer $n_m$ exists such that all $n \ge n_m$ can be written as sum $a_1 + \ldots + a_r$ of distinct positive integers with $\frac{1}{a_1} + \ldots + \frac{1}{a_r} = 1$ and where $a_i \ge m$ for all $i$. This gives the strongly complete claim. And one could propose an OEIS sequence $s_1, s_2, \ldots$ for this as well, where $s_m$ is the smallest $n_m$ for which the above holds. It'll be annoying to calculate any $s_m$ for even moderate values of $m$, say $m = 10$, but Theorem $3$ in this (https://arxiv.org/pdf/2502.02200) recent paper of mine gives the asymptotic formula $(\frac{1}{2} + o(1))(e^2 - 1)m^2$.

- 06:29 on 15 Sep 2025 - Vjeko_Kovac:
  This problem's wording needs to be changed from "... contains all sufficiently large rational numbers?" to "... contains all sufficiently large integers?". The property of representing all sufficiently large rationals was rather called "$\mathbb{Q}$-completeness" by Erdős and Graham.
  In fact, the surrounding remarks make no sense in the present formulation, even the claim about $p(n)=n$. Namely, for arbitrarily large $N\in\mathbb{N}$, rational numbers in the interval $(N,N+1)$ can be represented only using the first $N$ terms of the sequence $(n+1/n)_{n=1}^{\infty}$. That way, at most $2^N$ rationals from $(N,N+1)$ can be represented, but there is infinitely many of them.

## Local Proof Attempts
Target:
Classify polynomials \(p\) for which subset sums of
\[
\left\{p(n)+\frac1n\right\}_{n\ge1}
\]
exhibit strong completeness / near-integer coverage behavior.
Step A: Integer-fraction split
Write subset sums as
\[
\sum_{n\in S}p(n) + \sum_{n\in S}\frac1n.
\]
Separate hard part (harmonic fractional control) from polynomial integer growth.
Step B: Fractional cancellation mechanism
Determine when reciprocal part can hit prescribed residues modulo \(1\) densely
enough to fill integer targets.
Step C: Degree-dependent criterion
Show low-degree \(p\) satisfy Step B robustly, while higher-degree need extra
structure.
Concrete Blocking Lemma (Most Critical):
Need a quantitative equidistribution/cancellation theorem for finite reciprocal
subsum residues compatible with polynomial integer shifts.

Lemma 1 (Integer shift invariance):
For integer-valued \(p\) on \(\mathbb N\), integrality of subset sum
\[
\sum_{n\in S}\left(p(n)+\frac1n\right)
\]
is equivalent to integrality of \(\sum_{n\in S}1/n\) shifted by an integer.
\[
\textit{Proof.}
\]
\(\sum_{n\in S}p(n)\in\mathbb Z\), so adding/removing it does not affect fractional
part.
\(\square\)
Lemma 2 (Finite-window transfer):
If in a window \(W\) the reciprocal subsums realize all fractions in an interval
of width \(\eta\) modulo \(1\), then adding integer polynomial part yields an
integer run of comparable length in total sums.
\[
\textit{Proof sketch.}
\]
Fix integer part from chosen polynomial indices; vary reciprocal part across dense
fractional grid to cross consecutive integer thresholds.
\(\square\)
Lemma 3 (Reduction):
EP-351 reduces to proving strong fractional coverage for reciprocal subsums
associated with admissible index families determined by \(p\).
\[
\textit{Proof.}
\]
By Lemma 1, integer component is neutral modulo \(1\); Lemma 2 converts
fractional coverage into integer-value coverage.
\(\square\)
