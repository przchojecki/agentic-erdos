# EP-376

## Problem Statement
Are there infinitely many $n$ such that $\binom{2n}{n}$ is coprime to $105$?

## Site Remarks
Erd\H{o}s, Graham, Ruzsa, and Straus \cite{EGRS75} have shown that, for any two odd primes $p$ and $q$, there are infinitely many $n$ such that $\binom{2n}{n}$ is coprime to $pq$.

This is equivalent (via Kummer's theorem (https://en.wikipedia.org/wiki/Kummer%27s_theorem)) to whether there are infinitely many $n$ which have only digits $0,1$ in base $3$, digits $0,1,2$ in base $5$, and digits $0,1,2,3$ in base $7$.

The sequence of such $n$ is A030979 (https://oeis.org/A030979) in the OEIS.

The best result in this direction is due to Bloom and Croot \cite{BlCr25}, who proved that, if $p_1,p_2,p_3$ are sufficiently large primes, then there are infinitely many $n$ such that almost all of the base $p_i$ digits are $<p_i/2$. In other words, for all $\epsilon>0$, there are infinitely many $n$ such that $\binom{2n}{n}$ is coprime to $p_1p_2p_3$, except for a factor of size $\leq n^\epsilon$.

This is mentioned in problem B33 of Guy's collection \cite{Gu04}. It is also discussed in an article of Pomerance \cite{Po15c}.

Graham offered \$1000 for a solution to this problem (as mentioned in \cite{Gu04} and \cite{BeHa98}).

- 21:55 on 08 Jan 2026 - Thomas Bloom (reply depth 1):
  Yes, apologies I should have also cited the Croot, Mousavi, and Schmidt paper (which my paper with Croot improves). For reference, here is what the two papers say in terms of this problem.
  
  Given a finite set of primes $P=\{p_1<\cdots<p_k\}$ let $f_P(n)$ be the $P$-divisible component of $\binom{2n}{n}$ (that is, the product of all maximal powers of $p_i\in P$ which divide $\binom{2n}{n}$). It is trivial that $f_P(n) \leq n^{O(k)}$.
  
  Croot, Mousavi, and Schmidt proved that, for any $\epsilon>0$, if $p_1$ is sufficiently large depending on $\epsilon$ and $k$, then there are infinitely many $n$ such that $f_P(n)\leq n^\epsilon$.
  
  Croot and I in [BlCr25] proved that, provided $p_1$ is sufficiently large depending only on $k$ (e.g. $\geq 10^{94}$ for $k=3$) then, for any $\epsilon>0$, there are infinitely many $n$ such that $f_P(n) \leq n^\epsilon$.
  
  So essentially we swapped the quantifiers round so that $\epsilon$ is now independent of the set of primes. We believe that a more careful version of our proof should allow one to prove that, if $p_1$ is large enough in terms of $k$, then there are infinitely many $n$ such that $f_p(n) \leq \exp(O(\sqrt{\log n}))$.
  
  (Of course the conjecture is that, generalising the problem of Graham mentioned here, that if $p_1$ is sufficiently large in terms of $k$ then $f_P(n)=1$ for infinitely many $n$.)

## Local Proof Attempts
Target:
Study infinitude/finitude of
\[
\mathcal N_{105}:=\{n\ge1:\ \gcd\!\binom{2n}{n},105=1\}.
\]
A. Concrete Blocking Lemma (Most Critical):
Prove a symbolic-dynamics criterion implying that the set of \(n\) whose base-\(p\) digits avoid carries for all \(p\in\{3,5,7\}\) is recognized by a finite automaton with spectral radius \(>1\) (for infinitude) or \(=1\) (for finiteness with eventual periodic constraints).
Either outcome would decisively resolve the qualitative question.
B. Reduction Lemmas (with proofs):
Lemma B1 (Kummer carry criterion):
For prime \(p\),
\[
p\nmid \binom{2n}{n}\iff \text{adding }n+n\text{ in base }p\text{ has no carry}.
\]
Proof.
Kummer’s theorem states \(v_p\!\binom{2n}{n}\) equals the number of base-\(p\) carries when adding \(n\) and \(n\). So valuation \(0\) is equivalent to no carry. \(\square\)
Lemma B2 (digit-set formulation):
\[
n\in\mathcal N_{105}
\iff
\bigl(\text{no carry in base }3\bigr)\land\bigl(\text{no carry in base }5\bigr)\land\bigl(\text{no carry in base }7\bigr).
\]
Proof.
\(\gcd(\binom{2n}{n},105)=1\) is equivalent to nondivisibility by each prime \(3,5,7\). Apply Lemma B1 separately for each prime. \(\square\)
Lemma B3 (closure under CRT digit lifting):
If one can realize infinitely many compatible finite carry-free digit prefixes simultaneously mod \(3^a,5^b,7^c\), then \(\mathcal N_{105}\) is infinite.
Proof.
Use CRT to combine compatible residues into a residue class mod \(3^a5^b7^c\). A nested construction of longer compatible prefixes gives infinitely many integers satisfying all three no-carry constraints, hence in \(\mathcal N_{105}\) by Lemma B2. \(\square\)
C. Main unresolved point:
The key difficulty is global compatibility of no-carry constraints across three incommensurate bases. Local constructions in one base are easy; synchronized infinite constructions across \((3,5,7)\) remain hard.
