# EP-919

## Problem Statement
Is there a graph $G$ with vertex set $\omega_2^2$ and chromatic number $\aleph_2$ such that every subgraph whose vertices have a lesser type has chromatic number $\leq \aleph_0$?

What if instead we ask for $G$ to have chromatic number $\aleph_1$?

## Site Remarks
This question was inspired by a theorem of Babai, that if $G$ is a graph on a well-ordered set with chromatic number $\geq \aleph_0$ there is a subgraph on vertices with order-type $\omega$ with chromatic number $\aleph_0$.

Erd\H{o}s and Hajnal showed this does not generalise to higher cardinals - they (see \cite{Er69b}) constructed a set on $\omega_1^2$ with chromatic number $\aleph_1$ such that every strictly smaller subgraph has chromatic number $\leq \aleph_0$ as follows: the vertices of $G$ are the pairs $(x_\alpha,y_\beta)$ for $1\leq \alpha,\beta <\omega_1$, ordered lexicographically. We connect $(x_{\alpha_1},y_{\beta_1})$ and $(x_{\alpha_2},y_{\beta_2})$ if and only if $\alpha_1<\alpha_2$ and $\beta_1<\beta_2$.

A similar construction produces a graph on $\omega_2^2$ with chromatic number $\aleph_2$ such that every smaller subgraph has chromatic number $\leq \aleph_1$.

## Local Computation
- Built finite analogue of the lex-square construction on $[m]\times[m]$ with lexicographic order and edge rule
$$
(a_1,b_1)\sim(a_2,b_2)\iff a_1<a_2\ \text{and}\ b_1<b_2.
$$
- Studied chromatic number of initial segments (finite proxy for “lesser type” substructures).
- Derived explicit prefix formula and verified it exactly by coloring computations for $m=4,\dots,10$.

- Exact checks for all tested prefixes matched the formula
$$
\chi(\text{prefix of size }t)=q+\mathbf 1_{r\ge q+1},
$$
where $t=(q)m+r$ in row-wise lex decomposition.
- In particular, in this finite model:
 - full graph has chromatic number $m$,
 - every proper initial segment has chromatic number at most $m-1$.
- Large-scale profile up to $m=400$ shows the largest proper initial segment has ratio $\chi/m=399/400$.

## Local Proof Attempts
The finite lex-square analogue is useful because it exactly models the kind of initial-segment behavior that appears in the classical \(\omega_1^2\) construction. It shows a very rigid gap between the full graph and its proper initial segments, but still falls short of the stronger local collapse sought at \(\omega_2^2\).
