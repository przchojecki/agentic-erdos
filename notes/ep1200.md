# EP-1200

## Problem Statement
There exists a constant $C$ such that for all large $x$ there is a collection of primes $p_1<\ldots<p_k<x$ with $\sum\frac{1}{p_i}<C$ together with a system of congruences $a_i\pmod{p_i}$ such that every integer $n<x$ satisfies at least one of these congruences.

## Site Remarks
A conjecture of Erd\H{o}s and Ruzsa which Erd\H{o}s described in \cite{Er80} as 'surprising'. He says that if this is correct then 'very likely' the $\epsilon_n$ in [688] is $\gg 1$ - certainly proving $\epsilon_n\geq c$ would prove this conjecture (taking $P$ to be all primes in $[x^c,x]$).

In \cite{ErRu80} this is asked as a question: if $p_1<\cdots<p_k<x$ are primes with $\sum \frac{1}{p_i}\leq C$ and $a_i\pmod{p_i}$ are any residue classes then must there always be $\gg_K x$ many integers $n<x$ avoiding all of them? (Of course is the answer is yes then this disproves the main conjecture.)

Erd\H{o}s and Ruzsa \cite{ErRu80} proved that for any $C>0$ there exists a set of primes $P$ such that $\sum_{p\in P}\frac{1}{p}\leq C$ and the number of integers $n\leq x$ divisible by at least one $p\in P$ is $\gg_C x$.

See also [783] and [784].
