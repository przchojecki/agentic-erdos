# EP-901

## Problem Statement
Let $m(n)$ be minimal such that there is an $n$-uniform hypergraph with $m(n)$ edges which is $3$-chromatic. Estimate $m(n)$.

## Site Remarks
In other words, the hypergraph does not have Property B (https://en.wikipedia.org/wiki/Property_B). Property B means that there is a set $S$ which intersects all edges and yet does not contain any edge.

It is known that $m(2)=3$, $m(3)=7$, and $m(4)=23$. Erd\H{o}s proved\[2^n \ll m(n) \ll n^2 2^n\](the lower bound in \cite{Er63b} and the upper bound in \cite{Er64e}). Erd\H{o}s conjectured that $m(n)/2^n\to \infty$, which was proved by Beck \cite{Be77}, who proved $m(n)\gg (\log n)2^n$, and later \cite{Be78} improved this to\[n^{1/3-o(1)}2^n \ll m(n).\]Radhakrishnan and Srinivasan \cite{RaSr00} improved this to\[\sqrt{\frac{n}{\log n}}2^n \ll m(n).\]Pluhar \cite{Pl09} gave a very short proof that $m(n) \gg n^{1/4}2^n$.

In \cite{ErLo75} Erd\H{o}s and Lov\'{a}sz speculate that $n2^n$ is the correct order of magnitude for $m(n)$.

## Local Computation
- Built a deeper multirestart greedy constructor for non-2-colorable $n$-uniform hypergraphs.
- For each $n\in\{4,5,6,7\}$, scanned several vertex counts $v$ and ran many randomized restarts with large candidate-edge sampling.
- Verified non-2-colorability by explicit elimination of all 2-colorings when a witness is found.

- Best witnesses found in this run:
 - $n=4$: $28$ edges (at $v=9$), improving earlier in-repo batch witness $30$.
 - $n=5$: $67$ edges (at $v=11$), improving earlier in-repo batch witness $92$.
 - $n=6$: $321$ edges (at $v=13$), slightly improving earlier in-repo batch witness $327$.
- For $n=7$, this run did not find a full witness under the current search budget (best remaining colorings still positive), so deeper search is still needed there.
- Ratios against $2^n$ in this run: about $1.75$ ($n=4$), $2.09$ ($n=5$), $5.02$ ($n=6$).

## Local Proof Attempts
The multirestart search builds explicit non-2-colorable \(n\)-uniform hypergraphs and then certifies them by exhaustive coloring elimination. This improves several small finite witnesses, but it is still purely constructive finite evidence and does not determine the asymptotic order of \(m(n)\).
