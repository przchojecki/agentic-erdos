# EP-130

## Problem Statement
Let $A\subset\mathbb{R}^2$ be an infinite set which contains no three points on a line and no four points on a circle. Consider the graph with vertices the points in $A$, where two vertices are joined by an edge if and only if they are an integer distance apart.

How large can the chromatic number and clique number of this graph be? In particular, can the chromatic number be infinite?

## Site Remarks
Asked by Andr\'{a}sfai and Erd\H{o}s. Erd\H{o}s \cite{Er97b} also asked where such a graph could contain an infinite complete graph, but this is impossible by an earlier result of Anning and Erd\H{o}s \cite{AnEr45}.

## Local Computation
- direct finite construction search enforcing no-three-collinear/no-four-cocircular constraints.
- Best found sample (10 points) had clique number 3 and chromatic number 3.
- Obstacle: finite examples cannot decide whether the chromatic number can be infinite in the infinite-setting EP; they only provide bounded local profiles.

## Local Proof Attempts
Route:
Separated clique-number and chromatic-number subquestions for the integer-distance graph under no-three-collinear/no-four-cocircular constraints.

Hard point:
The main remaining issue is whether the chromatic number can still be infinite despite bounded clique behavior.

Target:
Decide whether the chromatic number of the integer-distance graph under the
general-position constraints can be infinite.
Step A: Finite Radius Coloring Bound
For each radius/diameter scale \(R\), prove a uniform bound \(\chi_R\le C\) for
the induced finite graph class.
Step B: Scale-Compatibility (Compactness)
Show the colorings from Step A can be made consistent across growing scales
(inverse-limit / compactness argument).
Step C: Infinite Coloring
Deduce a global finite coloring of the full infinite graph.
Concrete Blocking Lemma (Most Critical):
Need a robust decomposition lemma: every such finite integer-distance graph in
general position admits bounded-degeneracy (or bounded arboricity) after removing
a controlled sparse exceptional set.
