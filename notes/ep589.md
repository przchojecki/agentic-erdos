# EP-589

## Problem Statement
Let $g(n)$ be maximal such that in any set of $n$ points in $\mathbb{R}^2$ with no four points on a line there exists a subset on $g(n)$ points with no three points on a line. Estimate $g(n)$.

## Site Remarks
The trivial greedy algorithm gives $g(n)\gg n^{1/2}$. A similar question can be asked for a set with no $k$ points on a line, searching for a subset with no $l$ points on a line, for any $3\leq l<k$.

Erd\H{o}s thought that $g(n) \gg n$, but in fact $g(n)=o(n)$, which follows from the density Hales-Jewett theorem proved by Furstenberg and Katznelson \cite{FuKa91} (see [185]).

F\"{u}eredi \cite{Fu91b} proved\[n^{1/2}\log n\ll g(n)=o(n).\]Balogh and Solymosi \cite{BaSo18} improved the upper bound to\[g(n) \ll n^{5/6+o(1)}.\]

## Local Computation
- Constructed no-4-collinear instances via iterative repair.
- From each instance, extracted large no-3-collinear subsets using a triple-hypergraph deletion heuristic.
- This provides finite lower-bound signals, not a proof of asymptotic order.

- Deep run outputs best subset ratios:
 - \(n=30: 0.93n\),
 - \(n=40: 0.875n\),
 - \(n=50: 0.82n\),
 - \(n=60: 0.767n\).
- Ratios decrease with \(n\), but remain large in this finite regime.
