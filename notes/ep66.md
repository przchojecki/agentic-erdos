# EP-66

## Problem Statement
Is there $A\subseteq \mathbb{N}$ such that\[\lim_{n\to \infty}\frac{1_A\ast 1_A(n)}{\log n}\]exists and is $\neq 0$?

## Site Remarks
A suitably constructed random set has this property if we are allowed to ignore an exceptional set of density zero. The challenge is obtaining this with no exceptional set. Erd\H{o}s believed the answer should be no. In \cite{Er80} he explicitly asked whether there exists such a set where the limit is $1$ (and did not believe there existed such a sequence).

Erd\H{o}s and S\'{a}rk\"{o}zy proved that\[\frac{\lvert 1_A\ast 1_A(n)-\log n\rvert}{\sqrt{\log n}}\to 0\]is impossible. Erd\H{o}s suggests it may even be true that the $\liminf$ and $\limsup$ of $1_A\ast 1_A(n)/\log n$ are always separated by some absolute constant.

Horv\'{a}th \cite{Ho07} proved that\[\lvert 1_A\ast 1_A(n)-\log n\rvert \leq (1-\epsilon)\sqrt{\log n}\]cannot hold for all large $n$.

## Local Computation
Finite compute signal:
 - Model sets give contrasting profiles for $1_A*1_A(n)/\log n$:
 - squares: about $0.49..0.55$ at sampled points,
 - primes: very large values,
 - powers of two: $0$ throughout sampled points.

 - Finite behavior is highly model-dependent; no pathway yet to a global nonzero limit (or to ruling it out).

## Local Proof Attempts
Target:
Resolve existence/nonexistence of nonzero limit behavior for
\[
\frac{(1_A*1_A)(n)}{\log n}
\]
in the EP-66 formulation.
Step A: Structural trichotomy
Partition candidate sets \(A\) into multiplicative-like, additive-like, and
lacunary classes with separate convolution asymptotics.
Step B: Class-wise asymptotic control
For each class prove either:
1. normalized convolution tends to \(0\),
2. stays bounded away from \(0\), or
3. oscillates.
Step C: Global criterion
Characterize exactly which structural class can satisfy the EP-66 target limit.
Concrete Blocking Lemma (Most Critical):
Need a uniform Tauberian bridge from counting function of \(A\) to asymptotics of
\((1_A*1_A)(n)\) at logarithmic scale, robust under sparse oscillatory sets.

Proposition S1 (Limsup/liminf criterion):
If there exist sequences \(n_j,m_j\to\infty\) with
\[
\frac{(1_A*1_A)(n_j)}{\log n_j}\to 0,\qquad
\frac{(1_A*1_A)(m_j)}{\log m_j}\to c>0,
\]
then the normalized quantity has no limit.
\[
\textit{Proof.}
\]
Different subsequential limits imply nonexistence of full limit.
\(\square\)
Proposition S2 (Uniform asymptotic envelope gives limit):
If
\[
\left|\frac{(1_A*1_A)(n)}{\log n}-L\right|\le \varepsilon_n,\quad \varepsilon_n\to0,
\]
then the limit exists and equals \(L\).
\[
\textit{Proof.}
\]
Direct squeeze.
\(\square\)
