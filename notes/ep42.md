# EP-42

## Problem Statement
Let $M\geq 1$ and $N$ be sufficiently large in terms of $M$. Is it true that for every Sidon set $A\subset \{1,\ldots,N\}$ there is another Sidon set $B\subset \{1,\ldots,N\}$ of size $M$ such that $(A-A)\cap(B-B)=\{0\}$?

  The 'key lemma' (at least, a special case which suffices for this application) is the following: let $F\subseteq \mathbb{F}_p$ be a symmetric set such that $\lvert F\rvert \leq p/2$ and $\widehat{1_F}(\gamma) \geq -o(p)$ for all characters $\gamma$. If we choose a random subset $B$ of size $M$ by sampling uniformly from $(0,p/4)$ then $F\cap(B-B)=\{0\}$ with probability $\gg_{M} 1$.
  
  With this lemma the proof is immediate: pick a prime slightly larger than $2N$ so that $A$ corresponds to a Sidon set in $\mathbb{F}_p$, then the Sidon property ensures that $\widehat{1_{A-A}}(\gamma)\geq -c\sqrt{p}$ for some constant $c$, and hence a random $B$ as above has $(A-A)\cap (B-B)=\{0\}$ with probability $\gg_M 1$. The probability that $B$ is not Sidon is like $\ll M^4/p$, so as long as $p\asymp N$ is large enough depending on $M$ with positive probability a random $B$ of size $M$ from $(0,p/4)$ is both Sidon and satisfies the required property.

- 19:57 on 29 Apr 2026 - WillSawin (reply depth 2):
  If we assume a bound on the Fourier coefficients of nontrivial characters from above and not just from below, the key lemma becomes a special case of a result of Green-Tao. Indeed, the set of linear forms $x_i -x_j$ for $1 \leq i < j \leq M$ in the variables $x_1,\dots,x_M$ has complexity at most $1$ in the sense of Green-Tao (i.e. Cauchy-Schwarz complexity at most 1 in IIRC the currently most common terminology) since the form $x_i-x_j$ is not in the linear span of the set of forms $x_{i'}-x_{j'}$ for $i' ,j'\neq i$ and also not in the linear span of the set of forms $x_{i'}-x_{j'}$ for $i' ,j'\neq j$ and these two sets cover the set of forms removing $x_i-x_j$. So by the generalized von Neumann theorem of Green and Tao, a set contains approximately the expected number of tuples of the form $x_i-x_j$ for all $1\leq i<j \leq M$ in $M$ as long as its Gowers $U_2$-norm is controlled. Apply this to the complement of $F$, whose $U_2$ norm is controlled by the strengthened assumption on the Fourier coefficients of $F$.
  
  From this perspective, the biggest subtlety is that to lower bound the probability that $F \cap (B-B)=\{0\}$ it suffices to lower bound the Fourier coefficients of $F$ and the upper bound is not needed.

- 21:24 on 29 Apr 2026 - TerenceTao (reply depth 2):
  The proof of the key lemma is phrased in a continuous limit in order to get rid of some epsilons (in particular, to make $f$ actually positive (semi-)definite rather than approximately positive definite), but if one prefers the finitary language, one can phrase the argument there as well.
  
  As you say, the setup is that one has an indicator function $1_F$ whose Fourier transform $\hat 1_F$ is mostly positive. Apply the arithmetic regularity lemma to model $1_F$ (in a $U^2$ type sense) by some model function $0 \leq f \leq 1$. The set $\{ f \geq 1-\varepsilon \}$ is basically the $(1-\varepsilon)$-Fourier spectrum of (the large Fourier coefficients of) $\hat 1_F$, due to the near-non-negativity of this function. Taking a few sumsets of this set still lands one in a 98%-type spectrum, so by Cauchy-Davenport the measure of this set $\{ f \geq 1-\varepsilon \}$ has to be pretty small. (Here it becomes key that one is working in a group of prime order, or more specifically a group without bounded index subgroups; the key lemma looks like it should fail when bounded index subgroups are present.) So, with high probability, $f(x)$ is noticeably less than $1$; in particular, for $M$ randomly chosen elements $x_1,\dots,x_M$, $f(x_i - x_j)$ is going to be somewhat less than $1$ for all $1 \leq i < j \leq M$ simultaneously. Because $f$ is a good Fourier model for $1_F$, a standard "counting lemma" then allows one to show that the $x_i-x_j$ all avoid $F$ with positive probability. (As Will noted, the pattern $(x_i-x_j)_{1 \leq i < j \leq M}$ is "complexity 1" and can be handled by Fourier methods.)
  
  The quantitative bounds here may range between poor and fantastically poor depending on what level of regularity lemma is actually needed in the argument. But no doubt there are more efficient ways to arrange the argument (in particular, I can imagine Croot-Sisask and/or Kelley-Meka type ideas being useful, but you are probably better placed than I to comment on that).
  
  The lemma reminds me somewhat of the Green-Sanders quantitative version of Cohen's idempotent theorem (https://arxiv.org/abs/math/0611286); it may also be worth exploring such connections further.

- 21:51 on 29 Apr 2026 - TerenceTao (reply depth 3):
  The purely continuous version of the key lemma is actually quite clean, to wit:
  
  Theorem (Continuous analogue of key lemma) Let $G$ be a connected compact abelian group, and let $f: G \to [0,1]$ be a measurable function which is positive definite (Fourier transform is non-negative) but not identically $1$. Then for almost every $x_1,\dots,x_M \in G$, one has $f(x_i-x_j) < 1$ for all $1 \leq i < j \leq M$.
  
  Proof: Writing $f$ as a Fourier series $f(x) = \sum_\xi \hat f(\xi) e(\xi \cdot x)$ (using appropriate normalizations for Fourier series), we see from the non-negativity of $\hat f$ that $f(x)$ attains its maximal value of $1$ precisely when $x$ is orthogonal to the support of $\hat f$: $\xi \cdot x = 0 \hbox{ mod } 1$ for all $\xi$ with $\hat f(\xi) \neq 0$. In particular, $\{x: f(x)=1\}$ is a closed subgroup of $G$, which is proper since $f$ is not identically $1$. It cannot be open since $G$ is connected, hence it has measure zero. Thus $f(x-y) < 1$ for almost all $x,y$, giving the claim. $\Box$
  
  In retrospect, once one sees that the indicator $1_{A-A}$ is essentially positive definite, and also positive density in a suitable ambient container group, passing to a continuous limit becomes natural, at which point the above continuous version of the key lemma emerges as the natural toy problem.
  
  (To relate the continuous problem to the discrete problem, think of $G$ as some medium dimensional torus ${\bf T}^d$, pick some random frequencies $\xi_1,\dots,\xi_d \in \hat{\mathbb F}_p$, and pick $F$ randomly by letting each $n$ lie in $F$ with an independent probability of $f(\xi_1 \cdot n, \dots, \xi_d \cdot n)$.)
  
  It is certainly known that Sidon sets have pretty good Fourier properties (see, e.g., this paper of Ortega-Prendiville (https://arxiv.org/abs/2110.13447)), and the near positive-definiteness is often exploited on the physical space side (though the underlying positive definite mechanism is sometimes obscured under layers of double-counting or Cauchy-Schwarz arguments), but I've not seen this positive definiteness exploited on the Fourier side much. It reminds me a bit of the Kelley-Meka argument where one of the key insights was to exploit the positive definiteness of $1_A * 1_{-A}$ to get stronger density increments than was available previously.

- 13:56 on 30 Apr 2026 - TerenceTao:
  It seems like one may be able to get a short solution, with rather good bounds, by combining various observations and literature results already mentioned in the discussion.
  
  Firstly, as I observed back in December, one can take the Sidon set $A$ to be maximal without loss of generality. This then gives us access to Corollary 1.4 of Ortega-Prendiville (https://arxiv.org/abs/2110.13447), which asserts that $1_A$ is close to a normalized version of $1_{[N]}$ in a Fourier sense, with a power saving in the error. Taking convolutions, $1_A * 1_{-A}$ is close in a Fourier sense to a normalized version of the tent function $1_{[N]} * 1_{-[N]}$, and so $1_{A-A}$ is also. (Informally: $A-A$ starts experiencing reduced density as one moves away from the origin towards $\pm N$, with the density dropping off at a constant linear rate.) As Will noted, the problem of counting how often $B-B$ avoids $A-A$ for a small random $B$ is a complexity $1$ problem and so one is now just averaging $1_{[N]} * 1_{-[N]}(b_i - b_j)$ for random $b_i,b_j \in [N]$ which can be explicitly computed (actually now it seems the probability of successfully avoiding $A-A$ is rather large, of the order of $\exp(-cM^2)$ if $N \gg \exp(CM^2)$ perhaps, if I did the back of envelope calculations correctly).
  
  Unfortunately I won't have much time to devote to this today, but perhaps others here might be able to push these ideas further.
  
  EDIT: It seems that, in the end, the proof strategy is actually rather simple:
   Reduce to $A$ being maximal
  
   Take $B$ to be random
  
   Estimate the probability of success using the Fourier transform (and the fact that $1_{A-A}$ is essentially $1_A * 1_{-A}$ up to a lower order delta spike at the origin)
  
   Use the best available literature bounds on the Fourier uniformity of maximal Sidon sets
  
  SECOND EDIT: I asked Gemini for some numerics (https://gemini.google.com/share/d44e78a3f1f9) to illustrate the tent function density dropoff in $A-A$ which creates plenty of "holes" for $B-B$ to live in, even when $B$ is selected randomly. In retrospect this (rather well known) tent function behavior (which comes from the (also well known) uniform distribution properties of large Sidon sets) should already have been a giant clue as to how to solve this problem.
