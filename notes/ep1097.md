# EP-1097

## Problem Statement
Let $A$ be a set of $n$ integers. How many distinct $d$ can occur as the common difference of a three-term arithmetic progression in $A$?

In particular, are there always $O(n^{3/2})$ many such $d$?

## Site Remarks
A problem Erd\H{o}s posed in the 1989 problem session (https://westcoastnumbertheory.org/wp-content/uploads/2018/02/wcnt-problems-1989.pdf) of Great Western Number Theory.

He states that Erd\H{o}s and Ruzsa gave an explicit construction which achieved $n^{1+c}$ for some $c>0$, and Erd\H{o}s and Spencer gave a probabilistic proof which achieved $n^{3/2}$, and speculated this may be the best possible.

In the comment section, Chan has noticed that this problem is exactly equivalent to a sums-differences question of Bourgain \cite{Bo99}, introduced as an arithmetic path towards the Kakeya conjecture: find the smallest $c\in [1,2]$ such that, for any finite sets of integers $A$ and $B$ and $G\subseteq A\times B$ we have\[\lvert A\overset{G}{-}B\rvert \ll \max(\lvert A\rvert,\lvert B\rvert, \lvert A\overset{G}{+}B\rvert)^c\](where, for example, $A\overset{G}{+}B$ denotes the set of $a+b$ with $(a,b)\in G$).

This is equivalent in the sense that the greatest exponent $c$ achievable for the main problem here is equal to the smallest constant achievable for the sums-differences question. The current best bounds known are thus\[1.77898\cdots \leq c \leq 11/6 \approx 1.833.\]The upper bound is due to Katz and Tao \cite{KaTa99}. The lower bound is due to Lemm \cite{Le15} (with a very small improvement found by AlphaEvolve \cite{GGTW25}).

This resolves the second part of the question negatively, but the general question of the correct order of magnitude remains open.

- 03:27 on 02 Dec 2025 - KoishiChan:
  There seems to be a mysterious connection between this problem and the sum / difference set problem.
  
  To motivate the discussion, we first provide a explicit construction of the $\Omega(n^{3/2})$ bound. Take $X$ to be a finite set with no non-trivial solution to $x + y = z + w$, and set $A = (X - X) \cup \frac{1}{2} \cdot (X - X)$. Then $|A| = \Theta(|X - X|) = \Theta(|X|^2)$. Let $D(A)$ denote the set of common differences. Note that for any $x, y, z \in X$, the sequence $x - y, \frac{1}{2}(x - z), y - z$ forms an AP in $A$ with common difference $\frac{1}{2}(x + z - 2y)$. Hence, we have
  $$|D(A)| \geq |X + X - 2\cdot X| = \Omega(|X|^3) = \Omega(|A|^{3/2}).$$
  Now, how do we improve this? Well, we can use the construction above except with any $X$, and we win if
  $$|X + X - 2 \cdot X| \geq |X - X|^{3/2 + \epsilon}.$$
  A standard tensor power argument shows that we win if
  $$|X + X - 2 \cdot X| > |X - X|^{3/2}.$$
  However, I searched over subsets of $[1,...17]$ and found no counterexample.
  
  Another strategy is to introduce more arguments. Here let me choose sets $U$ and $Y$ with elements of $Y$ spaced sufficiently far apart compared to $U$, and set
  $$A = (U + Y) \cup (-U - Y) \cup \frac{1}{2}\cdot (U + U).$$
  For any $u_1, u_2 \in U$ and $y \in Y$, the following is an AP in $A$:
  $$u_1 + y, \frac{1}{2}(u_1 + u_2), -u_2 - y, $$
  with common difference $\frac{1}{2} (u_2 - u_1) - y$. Hence, we have
  $$|D(A)| \geq |U - U - 2 \cdot Y|.$$
  By our choice of $Y$, we have
  $$|A| = 2|U||Y| + |U + U|, |D(A)| \geq |U - U||Y|.$$
  Taking $|Y|$ appropriately, we have
  $$|A| = \Theta(|U + U|), |D(A)| = \Omega(|U + U||U - U||U|^{-1}).$$
  Now the connection with sum / difference becomes obvious!

## Local Proof Attempts
Target:
For \(A\subset\mathbb Z\), \(|A|=n\), bound
\[
|D(A)|,\quad D(A):=\{d>0:\exists x,\ x,x+d,x+2d\in A\},
\]
ideally by \(O(n^{3/2})\).
A. Concrete Blocking Lemma (Most Critical):
Prove an incidence-energy inequality:
\[
|D(A)|^{2}\ll E_+(A)\,n^{-1}
\]
with \(E_+(A)=|\{a+b=c+d\}|\), together with a universal bound \(E_+(A)\ll n^{4-\delta}\) in the extremal regime forcing \(|D(A)|\ll n^{3/2-\delta/2}\).
B. Reduction Lemmas (with proofs):
Lemma B1 (3-AP count decomposition):
Let \(T_d=\#\{x:\ x,x+d,x+2d\in A\}\). Then
\[
\sum_{d>0} T_d = \#\{\text{3-APs in }A\}.
\]
Proof.
Each nontrivial 3-AP has unique positive common difference \(d\), so summing over \(d\) partitions all 3-APs. \(\square\)
Lemma B2 (support-size inequality):
If \(S=\{d:T_d>0\}=D(A)\), then
\[
|D(A)|\le \frac{\left(\sum_d T_d\right)^2}{\sum_d T_d^2}.
\]
Proof.
Cauchy-Schwarz on \((T_d)_{d\in S}\): \((\sum_d T_d)^2\le |S|\sum_d T_d^2\). Rearrangement gives the claim. \(\square\)
Lemma B3 (A plus additive-energy control implies target):
If \(\sum_d T_d^2\) admits a lower bound in terms of \(\sum_d T_d\) and additive energy as in A, then \(|D(A)|=O(n^{3/2})\) follows.
Proof.
Insert the structural lower bound for \(\sum_d T_d^2\) into Lemma B2 and simplify exponents. \(\square\)
C. Main unresolved point:
The key obstacle is a sharp universal relation between 3-AP difference multiplicities \(T_d\) and additive energy in the worst-case extremal sets.
