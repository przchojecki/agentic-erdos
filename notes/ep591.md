# EP-591

## Problem Statement
Let $\alpha$ be the infinite ordinal $\omega^{\omega^2}$. Is it true that in any red/blue colouring of the edges of $K_\alpha$ there is either a red $K_\alpha$ or a blue $K_3$?

## Site Remarks
In other words, is it true that\[\alpha \to (\alpha, 3)^2?\]For comparison, Specker \cite{Sp57} proved this property holds when $\alpha=\omega^2$ and false when $\alpha=\omega^n$ for $3\leq n<\omega$. Chang proved this property holds when $\alpha=\omega^\omega$ (see [590]).

This is true and was proved independently by Schipperus \cite{Sc10} and Darby.

See also [118], and [592] for the general case.

## Local Computation
- Implemented exact exhaustive finite proxy via 2-color triangle Ramsey counting.
- Computed exact counts of colorings of \(K_n\) with no monochromatic triangle for \(n=3,4,5,6\).

- Counts are \(6,18,12,0\), so the first zero occurs at \(n=6\), recovering \(R(3,3)=6\).
- This is consistent with known finite partition behavior and serves as a toy consistency check only.
