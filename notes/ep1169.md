# EP-1169

## Problem Statement
Is it true that, for all finite $k<\omega$,\[\omega_1^2 \not\to (\omega_1^2, 3)^2?\]

## Site Remarks
A problem of Erd\H{o}s and Hajnal. Hajnal \cite{Ha71} proved this is true assuming the continuum hypothesis.

See also [592] for a similar problem concerning countable ordinals.

## Site References
