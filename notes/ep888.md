# EP-888

## Problem Statement
What is the size of the largest $A\subseteq \{1,\ldots,n\}$ such that if $a\leq b\leq c\leq d\in A$ are such that $abcd$ is a square then $ad=bc$?

## Site Remarks
A question of Erd\H{o}s, S\'{a}rk\"{o}zy, and S\'{o}s. Erd\H{o}s claims that S\'{a}rk\"{o}zy proved that $\lvert A\rvert =o(n)$ (a proof of this bound is provided by Tao in the comments).

The primes show that $\lvert A\rvert \gg n/\log n$ is possible. Cambie and Weisenberg have noted in the comments that the set of semiprimes also works, showing\[(1+o(1))\frac{\log\log n}{\log n}n \leq \lvert A\rvert\]is achievable.

See also [121].

  With GPT-5.5 Pro I've got\[
   F(n)\asymp \frac{n\log\log n}{\log n}.
  \]The lower bound is supplied by all primes and squarefree semiprimes (as noted in the comments too). The upper bound is the main point. After reducing to squarefree sets, we write each element with at least two prime factors as\[
   a=c p q,
  \]where $p<q$ are the two largest prime factors of $a$. For dyadic prime intervals $p\in(X,2X]$, $q\in(Y,2Y]$, and for each core $c$, the elements $c p q$ form a bipartite graph in the variables $p,q$. The rigidity hypothesis forbids a $2\times2$ rectangle from being complete in two different colors $c,d$. This converts the problem into a weighted colored graph problem. The main term in the graph estimate is exactly of size $n\log\log n/\log n$; the remaining terms are smaller because the core $c$ has all prime factors below the lower graph coordinate.

  Thanks; it's interesting to compare this to Erdős' argument for (the weaker version of) [425] in [Er68] (https://combinatorica.hu/~p_erdos/1968-09.pdf), in which he proves in particular that if $A\subseteq \{1,\ldots,N\}$ has no non-trivial solutions to $ab=cd$ then\[\lvert A\rvert \leq (1+o(1))\pi(N).\]He did this by factorising every element of $A$ as $uv$ with $u,v$ from some suitable sets, so that elements of $A$ correspond to edges in a bipartite graph, and then noting that a $C_4$ in this graph on $u_1v_1u_2v_2$ would give a non-trivial solution, since\[(u_1v_1)(u_2v_2)=(u_1v_2)(u_2v_2),\]and that a simple Cauchy-Schwarz argument gives an upper bound on the number of edges in a bipartite graph with no $C_4$. (He was, I think, quite fond of this trick; it seems that first noted some form of this argument as early as 1936.)
  
  The property in this question can be viewed as a weakening of this Sidon-type property: there are may now be non-trivial solutions to $ab=cd$, but not to $abcd$ being a square.
  
  This argument GPT gives is a (in hindsight) natural generalisation of this idea: consider not just one, but a lot of overlapping bipartite graphs, where we put an edge with 'colour' $c$ between $u$ and $v$ if $uvc\in A$. Now if $u_1v_1u_2v_2$ is a cycle in both the $c_1$ and $c_2$ colours then letting $a=u_1v_1c_1$, $b=u_1v_2c_2$, $c=u_2v_1c_2$, $d=u_2v_2c_1$, we see that $abcd$ is a square, and yet $ad=bc$ would force $c_1=c_2$. (One also has to rule out other potential solutions like $ab=cd$, but this is easily arranged if the $u_i,v_i$ are always prime.)
  
  So if $A$ has the property in this problem, no $C_4$ can appear in more than one of the $c$-coloured bipartite graphs. Via a similar Cauchy-Schwarz argument this implies an upper bound on the total number of edges across all these graphs, and hence an upper bound on $\lvert A\rvert$.
  
  It's not that surprising that now that we get the bound $\lvert A\rvert \ll \frac{n\log\log n}{\log n}$, the number of semiprimes, which would roughly correspond to the number of edges in the complete bipartite graph on primes (where the corresponding product is $\leq n$).
  
  The final bounds are a little tedious to work through, but now just an elementary calculation (and I'm sure, as usual, can be done in a much more compact way than GPT's writeup).
  
  (Interestingly, it seems that GPT was maybe heavily influenced by [Er68], using many similar phrases and language such as 'rectangles' rather than the more common nowadays $C_4$. It's possible that its chain of thought was 'this seems like a weaker variant of the multiplicative Sidon property, and it's a question of Erdős, so let me look at a paper of Erdős addressing the other multiplicative Sidon question and see if that technique can be adapted to work here' - and it was right!

- 02:29 on 22 Jan 2026 - TerenceTao:
  Here is a proof of Sarkozy's result $|A|=o(n)$. The main input is Turan-Kubilius inequality (anatomy of integers) to separate the role of smooth and rough numbers, and the multiplication table bound that only $o(n^2)$ numbers are the product of two numbers of size $O(n)$. (Much better bounds (https://en.wikipedia.org/wiki/Erd%C5%91s%E2%80%93Tenenbaum%E2%80%93Ford_constant) are known than this, but weaker estimate (which follows for instance from the Hardy-Ramanujan law) suffices for Sarkozy's $|A|=o(n)$ bound.) The basic point is that the small number of values of the multiplication table creates a large number of unwanted collisions.
  
  Let $0 < \delta < 1$, and introduce parameters
  $$ 1 < \frac{1}{\delta} \ll C \ll z \ll n$$
  with each parameter in this sequence assumed sufficiently large compared to the previous parameters, e.g., $z$ is sufficiently large depending on $\frac{1}{\delta}$ and $C$.
  
  Suppose for contradiction that we have a set $A \subset \{1,\dots,n\}$ of density $\geq \delta$ with the stated property. Any element $a$ of $A$ can then be factored as $a = a_{\leq z} a_{>z}$ where $a_{\leq z}$ is the $z$-smooth part (product of primes up to $z$) and $a_{>z}$ is the $z$-rough part (product of primes larger than $z$).
  
  By Turan-Kubilius, for $z$ large enough, we have $C \leq a_{\leq z} \ll_z 1$ for all but at most $\delta n /2$ of the natural numbers up to $n$, hence for $\gg \delta n$ of the $a \in A$. By pigeonholing, we can then find a dyadic scale $C < L \ll_z 1$ such that out of all the numbers of the form $a_{\leq z} a_{>z}$ with $a_{\leq z} \sim L$ $z$-smooth and $a_{>z} \lesssim n/L$ $z$-rough, $\gg \delta$ of these products will lie in $A$.
  
  If we let $S$ be the set of $z$-smooth numbers of size $\sim L$ and $R$ the set of $z$-rough numbers of size $\lesssim n/L$, the set $A$ is now occupying $\gg \delta |S| |R|$ of the products of $S$ and $R$. Note that $S$ and $R$ are large compared with $1/\delta$, and $R$ is in fact quite large: $|R| \gg_{L,z} n$. By Cauchy-Schwarz, we now have $\gg \delta^2 |S| |R|^2$ pairs $a_{\leq z} a_{>z}, a_{\leq z} a'_{>z}$ that both lie in $A$. By another Cauchy-Schwarz and the multiplication table bound, there are $\gg \delta^4 |S|^2 |R|^4 / |R \cdot R|$ quadruples
  $$a_{\leq z} a_{>z}, a_{\leq z} a'_{>z}, b_{\leq z} b_{>z}, b_{\leq z} b'_{>z}$$
   such that
  $$ a_{\leq z} \neq b_{\leq z}$$
  and
  $$ a_{>z} a'_{>z} = b_{>z} b'_{>z}.$$
  These four elements of $A$ multiply to a square, so the product of two of them must equal the other two. Some case analysis then reveals that this forces $a_{>z}, a'_{>z}$ to be a permutation of $b_{>z}, b'_{>z}$, thus the four elements here basically form a "rectangle" in $S \times R$, so there are only $O(|S|^2 |R|^2)$ possible such quadruples. This gives
  $$ \delta^4 |S|^2 |R|^4 / |R \cdot R| \ll |S|^2 |R|^2$$
  which leads to a contradiction since $|R| \gg_{L,z} n$ and $|R \cdot R| = o(n^2)$ by the multiplication table bound.

  Generate the proposed solution using GPT 5.2 Thinking, Opus 4.5 and Gemini 3 Pro, share here for verification.
  
  Document (https://docs.google.com/document/d/1gx9Ankr1qQOoFTR7Xj4u6Nc8SWkgEPe6/edit?usp=sharing&ouid=103837779541880341884&rtpof=true&sd=true)
  
  Summary:
  We want the largest \(A\subseteq\{1,\dots,n\}\) such that for all \(a\le b\le c\le d\in A\), if \(abcd\) is a square then \(ad=bc\) (allowing repeats).
  
  Step 1 (kernel reduction). Write \(x=\kappa(x)t^2\) with \(\kappa(x)\) squarefree.
  If \(A\) contains two distinct numbers with the same \(\kappa\), then \((x,x,x,y)\) gives a square product but forces \(xy=x^2\), impossible. Hence at most one element per kernel. Moreover, if \(A\) is good then the kernel-set \(K=\{\kappa(x):x\in A\}\) is also good, so it suffices to work with squarefree sets.
  
  Step 2 (candidate). Let \(L(n)\) be all squarefree numbers \(\le n\) with at most two prime factors (primes and squarefree semiprimes), and include \(1\) only when \(n\le 14\). This set is good: with supports of size \(\le2\), any square-trigger quadruple must have the "rectangle'' parity pattern, which forces \(ad=bc\).
  
  Step 3 (compression / maximality). Suppose \(K\) is a maximum good squarefree set but misses some "light'' element (first a prime, then a semiprime). Add the missing light element. If the new set becomes bad, one can classify the obstruction: adding a prime \(p\) creates a violation iff there exist \(b,c\in K\) with \(p\nmid b,c\) and \(d=p\cdot bc/\gcd(b,c)^2\in K\); the quadruple \((p,b,c,d)\) is then forced and violates \(pd=bc\). So we delete the witness \(d\) and keep \(p\). This preserves size and strictly decreases the total number of prime factors \(\sum_{x\in K}\omega(x)\). Iterating forces all primes (and then all semiprimes) into the set, eliminating all \(\omega\ge3\) elements.
  
  Step 4 (the \(1\) cutoff). If \(1\in K\) and \(pq,pr,qr\in K\), then \(1\cdot pq\cdot pr\cdot qr\) is a square but \(1\cdot qr\ne (pq)(pr)\). The first such triangle is \(\{6,10,15\}\), so \(1\) is compatible only for \(n\le14\).
  
  Conclusion. The maximum size is\[
  M(n)=\pi(n)+\#\{pq\le n:\ p<q\text{ primes}\}+\mathbf{1}_{n\le14},
  \]achieved by taking all primes and all squarefree semiprimes (and also \(1\) only when \(n\le14\)).

  I have an interesting lemma that may or may not be useful. Say a set $A \subseteq \mathbb{N}$ has Property P if for all $a \leq b \leq c \leq d \in A$ with $abcd$ square, we have $ad = bc$. Then this problem is asking how large a subset of $\{1,...,n\}$ can be if it has Property P. Say $A$ has Property Q if for all $a \leq b \leq c \leq d \in A$ with $abcd$ square, we have $a = b$ and $c = d$. Then every set with Property Q also has Property P. (The converse isn't true, though; a counterexample is $\{2,3,4,6\}$.)
  
  A nice fact is that if $U$ and $V$ have Property Q and $\gcd(u,v) = 1$ for all $u \in U, v \in V$, then the product set $UV$ has Property P. This is not too hard to verify.
  
  Unfortunately, the two stronger statements that you might have wondered about when reading this are false. The set $UV$ need not have Property Q; for example, $U = \{1,2\}$ and $V = \{1,3\}$ have Property Q but $UV = \{1,2,3,6\}$ does not have Property Q. Also, if we weaken the hypotheses so that $U$ only needs to have Property P, then $UV$ need not have Property P; for example, $U = \{2,3,4,6\}$ has Property P and $V = \{1,5\}$ has Property Q, but $UV$ contains $\{2,6,15,20\}$ and so it does not have Property P.

## Local Proof Attempts
The exact small-\(n\) and greedy larger-\(n\) profiles show that quite dense sets can satisfy the square-product rigidity condition in finite windows. That confirms the condition is much weaker than Sidonicity at small scales, but it does not clarify the true asymptotic order between the known lower and upper bounds.
