# EP-770

## Problem Statement
Let $h(n)$ be minimal such that $2^n-1,3^n-1,\ldots,h(n)^n-1$ are mutually coprime.

Does, for every prime $p$, the density $\delta_p$ of integers with $h(n)=p$ exist? Does $\liminf h(n)=\infty$? Is it true that if $p$ is the greatest prime such that $p-1\mid n$ and $p>n^\epsilon$ then $h(n)=p$?

## Site Remarks
It is easy to see that $h(n)=n+1$ if and only if $n+1$ is prime, and that $h(n)$ is unbounded for odd $n$.

It is probably true that $h(n)=3$ for infinitely many $n$.

See also [820].

  The following has been checked (a sanity check on the intuition below with data): among the smallest $20000$ primes $p$, there are $1278$ for which $\gcd(2^p-1,3^p-1)>1.$
  So for $18722$ of them, we have $h(p)=3.$
  
  Heuristically, the larger $p$ the larger the probability that $h(p)=1.$
  This is since $\gcd(2^p-1,3^p-1)>1$ implies there is a prime $q=kp+1$ dividing both. There are fewer values of (even) $k$ for which these are prime (behaves like one over $\log(k)+\log(p)$...), and so fewer chances that both $2$ and $3$ are $k^{th}$ powers modulo $kp+1$.
  
  Actually, the density of primes for which $h(p)=3$ should be one.
  (the probability of failing can be estimated above by $\frac{1}{\log p} \left( 1- \frac{\pi^2}{24}\right)$ for every $p$)
  
  Anyone who thinks this can be made rigourous?

- 20:31 on 21 Sep 2025 - StijnC:
  General thoughts on the last problem:
  for fixed $\epsilon>0$, $n$ large and $p<n^\epsilon$ the largest prime such that $p-1 \mid n$.
  Assume that $2^n-1,3^n-1 \ldots, p^n-1$ are all multiples of a prime $r>p$.
  
  Now $2,3,\ldots, p$ are all $k^{th}$ powers modulo $r$, where $k=\frac{r-1}{\gcd(r-1,n)}>2$.
  
  If $r \le 2n$, this should be impossible since one expects only $\Theta(\log(n))<n^{\epsilon}$ many consecutive $k^{th}$ powers modulo $r$.
  (see also the discussion and links at [stackexchange] (https://math.stackexchange.com/questions/4513213/is-there-any-way-to-predict-the-largest-number-of-consecutive-quadratic-or-cubic))
  
  If $r>2n$, then $\log_k(r) \le \log_k(kn+1)<\log_2(n+1)+1$ and the same estimate implies we do not expect this to happen.
  
  (observation: We can exclude $k$ large, in terms of $\epsilon$, by considering the number of $n^{\epsilon}$ smooth numbers up to $n$.)
  
  $\textbf{note about small values}$
  for $n=4044, h(n)=17>13$ (largest prime such that $p-1 \mid 4044$)
  Here $\log_{4044}{13}>0.3$ is reasonable big.
  (but so we have to think as $n$ to be sufficiently large for every $\epsilon$)

- 10:08 on 19 Sep 2025 - StijnC:
  Some thoughts on non-conditional proofs:
  $\gcd(2^p-1,3^p-1) \not=1$ is possible when $2^p-1$ is not a prime, e.g. when $p=11.$
  One may expect on the other hand that the chance that the gcd is not $1$ is somewhat small. A prime factor $kp+1$, where $k$ is even, can only occur if both $2$ and $3$ are perfect $k^{th}$ powers. ($\sum_{ 2 \mid k} 1/k^2 <1$).
  
  Proving it for prime powers also looked an option.
  E.g., if $n=5^k$, then $\gcd(2^n-1,3^n-1)=1$ whenever $k\le 10.$
  
  Nevertheless, this fails for $k \ge 42$, since in that case $72*5^{42}+1$ is a divisor of both $2^n-1$ and $3^n-1$.
  
  So there is likely no argument why it should work for all prime powers of another prime, e.g. $n=3^k$ for all k.
  
  Showing that a certain pattern/ infinite subset among the many solutions exists, see [oeis/A263647] (https://oeis.org/A263647) for the first $10000$ values, may be hard or even impossible.

- 09:41 on 19 Sep 2025 - StijnC:
  For the second question: so it is conjectured that $h(n)=3$ infinitely often.
  Conditional on the assumption that there are infinitely many Mersenne primes, which seems to be widely believed meanwhile (see e.g. [wiki:Lenstra-Pomerance-Wagstaff] (https://en.wikipedia.org/wiki/Mersenne_conjectures#Lenstra.E2.80.93Pomerance.E2.80.93Wagstaff_conjecture) and links for some conjecture on the counting function), this can be confirmed.
  
  Let $q=2^p-1$ be a Mersenne prime.
  Here $q=kp+1$ for some integer $k$.
  We have that $q \mid 3^p-1$ if $3$ is a $k^{th}$ power modulo $q.$
  But the $k^{th}$ powers modulo $q$ are exactly $1,2,2^2,2^3, \ldots,2^{p-1}$.
  So $3$ is not among them.
  We conclude that $\gcd(2^p-1,3^p-1)=1.$
