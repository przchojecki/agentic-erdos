# EP-945

## Problem Statement
Let $F(x)$ be the maximal $k$ such that there exist $n+1,\ldots,n+k\leq x$ with $\tau(n+1),\ldots,\tau(n+k)$ all distinct (where $\tau(m)$ counts the divisors of $m$). Estimate $F(x)$. In particular, is it true that\[F(x) \leq (\log x)^{O(1)}?\]In other words, is there a constant $C>0$ such that, for all large $x$, every interval $[x,x+(\log x)^C]$ contains two integers with the same number of divisors?

## Site Remarks
A problem of Erd\H{o}s and Mirsky \cite{ErMi52}, who proved that\[\frac{(\log x)^{1/2}}{\log\log x}\ll F(x) \ll \exp\left(O\left(\frac{(\log x)^{1/2}}{\log\log x}\right)\right).\]Erd\H{o}s \cite{Er85e} claimed that the lower bound could be improved via their method 'with some more work' to $(\log x)^{1-o(1)}$. Beker has improved (https://drive.google.com/file/d/1dPzHQw08tetxr-OwIlWddELunW0DXvxJ/view) the upper bound to\[F(x) \ll \exp\left(O\left((\log x)^{1/3+o(1)}\right)\right).\]Cambie has observed that Cram\'{e (https://en.wikipedia.org/wiki/Cram%C3%A9r%27s_conjecture)r's conjecture} implies that $F(x) \ll (\log x)^2$, and furthermore if every interval in $[x,2x]$ of length $\gg \log x$ contains a squarefree number (see [208]) then every interval of length $\gg (\log x)^2$ contains two numbers with the same number of divisors, whence\[F(x) \ll (\log x)^2.\]See [1004] for the analogous problem with the Euler totient function.

This problem is discussed in problem B18 of Guy's collection \cite{Gu04}.

  This is very nice Adrian! A few comments that may or may not be fruitful:
  
  0) Where you write $\le (\log x)^{1/3}$ in the middle of page $2$, I think this should actually be equality.
  1) For the number of possibilities for $f(n)$ you take $v_p(n) \le \log_2(n)$, presumably for simplicity. You are certainly aware of this, but here we could use the fact that $p > |I|/6$ so that $v_p(n) \le \log_{|I|/6}(n) \le (\log x)^{2/3}$. In the end this only changes the implicit constant in the exponent, but it seemed worth mentioning.
  2) For the number of possibilities for $g(n)$ you similarly note that $n$ has at most $\log_2(n)$ prime factors. Perhaps using some version of Erdős-Kac in short intervals, an analogue of Lemma $2.1$ still holds where $S$ only contains integers with approximately $\log \log n$ prime factors. Again, this only marginally impacts the final bound (if it even works). But again, I still wanted to point it out ;)
