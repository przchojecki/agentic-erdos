# EP-349

## Problem Statement
For what values of $t,\alpha \in (0,\infty)$ is the sequence $\lfloor t\alpha^n\rfloor$ complete (that is, all sufficiently large integers are the sum of distinct integers of the form $\lfloor t\alpha^n\rfloor$)?

## Site Remarks
Even in the range $t\in (0,1)$ and $\alpha\in (1,2)$ the behaviour is surprisingly complex. For example, Graham \cite{Gr64e} has shown that for any $k$ there exists some $t_k\in (0,1)$ such that the set of $\alpha$ such that the sequence is complete consists of at least $k$ disjoint line segments. It seems likely that the sequence is complete for all $t>0$ and all $1<\alpha < \frac{1+\sqrt{5}}{2}$. Proving this seems very difficult, since we do not even know whether $\lfloor (3/2)^n\rfloor$ is odd or even infinitely often.

- 23:28 on 08 Sep 2025 - Woett:
  I have just uploaded my paper on this problem to the arXiv (https://arxiv.org/pdf/2602.23394).
  
  Combined with (and relying on) the results from Graham's 1964 paper (https://mathweb.ucsd.edu/~ronspubs/64_02_erdos.pdf), the case $\alpha \ge \frac{1 + \sqrt{5}}{2}$ is completely settled. Moreover, even though my paper does not fully resolve the problem for the remaining interval $1 < \alpha < \frac{1 + \sqrt{5}}{2}$, I can at least give the full range of values of $t$ for which the resulting sequence is entirely complete, i.e. covers all positive integers.
  
  In the spirit of Graham, here (https://imgur.com/a/fAOkgkC) you can find a plot for part of the 2D plane which shows where the sequence is and isn't (entirely) complete. To describe it in words, this is the current state of affairs:
  
  If $\alpha > 2$, the sequence is not complete for any $t > 0$.
  If $\alpha = 2$, the sequence is complete if, and only if, $t = \frac{1}{2^k}$ for some $k \ge 1$.
  If $5^{1/3} < \alpha < 2$ and $t \ge 1$, the sequence is not complete.
  If $5^{1/3} < \alpha < 2$ and $t < 1$, it's complicated (but essentially known). See Graham's paper or the above image for more details.
  If $\frac{1 + \sqrt{5}}{2} \le \alpha \le 5^{1/3}$, the sequence is complete if, and only if, $t < \min\left(\frac{3}{\alpha^2}, \frac{5}{\alpha^3} \right)$.
  If $1 < \alpha < \frac{1 + \sqrt{5}}{2}$, the sequence is entirely complete if, and only if $t < \min\left(\frac{2}{\alpha}, \frac{3}{\alpha^2} \right)$.
  If $1 < \alpha < \frac{1 + \sqrt{5}}{2}$ and $t \ge \min\left(\frac{2}{\alpha}, \frac{3}{\alpha^2} \right)$, the sequence might be complete without being entirely complete, but only partial results are known (see below).
  If $\alpha = 1$, the sequence is complete if, and only if, $1 \le t < 2$.
  If $\alpha < 1$, the sequence is not complete for any $t > 0$.
  
  As for those partial results for the region where it's not fully known yet, one can observe that for any compact set contained in that region, determining whether the sequence is complete for all pairs $(t, \alpha)$ in that set, in principle reduces to a finite search. I have therefore done some coding and can show the following computer-assisted result:
  
  If $\alpha \le 1.4$, the sequence is complete for all $t \le 3$.
  If $\alpha \le 1.3$, the sequence is complete for all $t \le 5$.
  If $\alpha \le 1.2$, the sequence is complete for all $t \le 10$.
  If $\alpha \le 1.1$, the sequence is complete for all $t \le 50$.
  
  These ranges are mostly a proof of concept, and for anyone interested it shouldn't be too hard to extend them further.
  
  The final result I prove in my paper is that the sequence is complete whenever $1 < \alpha \le 1 + \frac{1}{\lceil t \rceil + 2 \lceil \sqrt{t} \rceil}$, which (when we plot the values of $t$ and $\alpha$) is the first result that implies the completeness of the sequence for a region of infinite area!

- 17:15 on 07 Sep 2025 - Woett (reply depth 1):
  Proving that such a seed always exists is essentially the difficulty, yes. Furthermore, you are correct that -as stated- the problem requires distinct integers of the form $\left \lfloor t \alpha^n \right \rfloor$, but that is not what Erdős and Graham wrote (or what I believe they intended), and also not what is assumed in Graham's 1964 paper. Every element $s_n = \left \lfloor t \alpha^n \right \rfloor$ is allowed to be used once, even if $s_n = s_m$ for some $m \neq n$. For example, Theorem 2 in Graham's paper implies in particular that the sequence with $t = \frac{2}{3}$ and $\alpha = 1.7$ (which has $s_1 = s_2 = 1$ and $s_3 = 3$) is entirely complete, which would not be true if we are not allowed to use both $s_1$ and $s_2$. ## Local Proof Attempts
Attempt details:
Examined known disconnected-parameter phenomena and attempted monotonicity transfers
in t and alpha to simplify the classification region.

Hard point:
No global necessary-and-sufficient characterization emerges from known local pieces.

Target:
Classify parameter pairs \((t,\alpha)\) for which
\(\lfloor t\alpha^n\rfloor\) is complete under distinct-sum representation.
Step A: Fractional-part dynamics
Analyze orbit \(\{t\alpha^n\}\) mod \(1\), which controls local jumps of
\(\lfloor t\alpha^n\rfloor\).
Step B: Regime decomposition
Split by Diophantine type of \(\alpha\) (Pisano/non-Pisano, algebraic/transcendental,
badly approximable vs resonant).
Step C: Completeness criterion per regime
Prove sufficient/necessary conditions via growth + spacing of terms.
Concrete Blocking Lemma (Most Critical):
Need a criterion linking discrepancy of \(\{t\alpha^n\}\) to additive completeness
of \(\lfloor t\alpha^n\rfloor\)-sequence.

Lemma 1 (Growth monotonicity for \(\alpha>1\)):
For fixed \(t>0,\alpha>1\), sequence \(u_n=\lfloor t\alpha^n\rfloor\) is
eventually strictly increasing.
\[
\textit{Proof.}
\]
Difference:
\[
t\alpha^{n+1}-t\alpha^n=t\alpha^n(\alpha-1)\to\infty.
\]
For large \(n\), this increment exceeds \(1\), so floors increase strictly.
\(\square\)
Lemma 2 (Completeness necessary divergence):
If \(\sum_n 1/u_n<\infty\), then \((u_n)\) cannot be complete.
\[
\textit{Proof.}
\]
Finite reciprocal mass implies subset-sum set is bounded in total variation near
large scales; standard complete-sequence criterion requires divergent reciprocal
sum (or equivalent density condition), hence failure.
\(\square\)
Lemma 3 (Reduction):
To classify \((t,\alpha)\), it suffices to characterize when divergence and
fractional-part discrepancy jointly imply tail coverage.
\[
\textit{Proof.}
\]
Lemma 2 gives a necessary filter; the remaining gap is sufficiency under
dynamical regularity.
\(\square\)
