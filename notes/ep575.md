# EP-575

## Problem Statement
If $\mathcal{F}$ is a finite set of finite graphs then $\mathrm{ex}(n;\mathcal{F})$ is the maximum number of edges a graph on $n$ vertices can have without containing any subgraphs from $\mathcal{F}$. Note that it is trivial that $\mathrm{ex}(n;\mathcal{F})\leq \mathrm{ex}(n;G)$ for every $G\in\mathcal{F}$.

Is it true that, for every $\mathcal{F}$, if there is a bipartite graph in $\mathcal{F}$ then there exists some bipartite $G\in\mathcal{F}$ such that\[\mathrm{ex}(n;G)\ll_{\mathcal{F}}\mathrm{ex}(n;\mathcal{F})?\]

## Local Computation
- Built a finite proxy comparing:
 - \(\operatorname{ex}(n;\{C_{2k-1},C_{2k}\})\),
 - \(\operatorname{ex}(n;C_{2k})\) (chosen bipartite member),
 for \(k=2,3\) over matched \(n\)-windows.
- No theorem-level proof yet, but this directly probes the target mechanism.

- Deep run (\(\sim 17.1\)s):
 - \(k=2\): \(\operatorname{ex}(n;C_4)\) is about \(1.08\times\operatorname{ex}(n;\{C_3,C_4\})\) in tested windows.
 - \(k=3\): \(\operatorname{ex}(n;C_6)\) is within about \(1\%\) of \(\operatorname{ex}(n;\{C_5,C_6\})\).
- This is consistent with the conjectural reduction, at least for these model families.
