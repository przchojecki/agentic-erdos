# EP-357

## Problem Statement
Let $1\leq a_1<\cdots <a_k\leq n$ be integers such that all sums of the shape $\sum_{u\leq i\leq v}a_i$ are distinct. Let $f(n)$ be the maximal such $k$.

How does $f(n)$ grow? Is $f(n)=o(n)$?

## Site Remarks
Asked by Erd\H{o}s and Harzheim. In \cite{Er77c} Erd\H{o}s asks about an infinite such set of integers, and whether such a set must have density $0$. He notes that a simple averaging process implies $a_k \gg k\log k$ for infinitely many $k$, and so the lower density is $0$. He also asks whether $\sum\frac{1}{a_k}$ must converge.

Weisenberg in the comments observes that any set which satisfies [874] also has this property, which implies $f(n)\geq (2+o(1))n^{1/2}$.

If $g(n)$ is the maximal $k$ such that there are $1\leq a_1,\ldots,a_k\leq n$ with all consecutive sums distinct (i.e. we drop the monotonicity assumption in the definition of $f$) then Hegyv\'{a}ri \cite{He86} has proved that\[\left(\frac{1}{3}+o(1)\right) n\leq g(n)\leq \left(\frac{2}{3}+o(1)\right)n.\]The upper bound of Coppersmith and Phillips in [867] implies\[g(n) \leq \left(\frac{2}{3}-\frac{1}{512}+o(1)\right)n.\]A similar question can be asked if we replace strict monotonicity with weak monotonicity (i.e. we allow $a_i=a_j$).

Erd\H{o}s and Harzheim also ask what is the least $m$ which is not a sum of the given form? Can it be much larger than $n$? Erd\H{o}s and Harzheim can show that $\sum_{x<a_i<x^2}\frac{1}{a_i}\ll 1$. Is it true that $\sum_i \frac{1}{a_i}\ll 1$?

See also [34], [356], [670], and [867]. The multiplicative analogue is [421].

  As a remark, Beker's work on [356] gives a nontrivial upper bound for $f(n)$. Define\[
  S(a) = \left\{ \sum_{i=u}^v a_i : 1 \le u \le v \le k \right\}.
  \]By [Be23b, Proposition 1.5], for any strictly increasing sequence \(1 \le a_1 < \cdots < a_k \le n\) one has\[
  |S(a)| \le (c_4 + o(1)) n^2,
  \qquad
  c_4 = \frac{e^2 - 1}{2(e^2 + 1)}.
  \]Now take an extremal configuration for $f(n)$: there exists some $k = f(n)$ and a strictly increasing subset \(1 \le a_1 < \cdots < a_k \le n\) such that all consecutive sums are distinct. In this case\[
  |S(a)| = \frac{k(k+1)}{2}.
  \]Combining the two bounds, we obtain \(\frac{k(k+1)}{2} \le (c_4 + o(1)) n^2\), and hence\[
  f(n) \le \left(\sqrt{2c_4} + o(1)\right) n
  = \left( \sqrt{\frac{e^2 - 1}{e^2 + 1}} + o(1) \right) n
  \approx (0.8727 + o(1))\,n.
  \][Be23b] Beker, A., On a problem of Erdős and Graham about consecutive sums in strictly increasing sequences. arXiv:2311.10087 (2023).

Hard point:
Finite lower bounds do not settle asymptotic growth or the question f(n)=o(n).

Target:
Determine asymptotics of \(f(n)\), the largest size of a set with all consecutive
interval sums distinct.
Step A: Conflict hypergraph formulation
Vertices are chosen indices; hyperedges encode equal consecutive-sum constraints.
Step B: Upper bound via conflict counting
Bound maximal independent-set size in this hypergraph.
Step C: Lower construction
Build near-optimal families with provably distinct interval sums.
Concrete Blocking Lemma (Most Critical):
Need a sharp counting lemma for number of interval-sum collisions induced by a set
of size \(k\), with explicit dependence on \(n,k\).

Lemma 1 (Collision characterization):
Distinctness of all consecutive sums fails iff there exist two intervals
\([i,j],[u,v]\) with
\[
\sum_{t=i}^j a_t=\sum_{t=u}^v a_t,\quad (i,j)\ne(u,v).
\]
\[
\textit{Proof.}
\]
This is direct restatement of distinctness condition.
\(\square\)
Lemma 2 (Prefix-sum reformulation):
Let \(P_r=\sum_{t\le r} a_t\). Then
\[
\sum_{t=i}^j a_t=P_j-P_{i-1},
\]
so interval-sum collisions are equivalent to repeated differences \(P_x-P_y\).
\[
\textit{Proof.}
\]
Standard telescoping identity.
\(\square\)
Lemma 3 (Reduction):
To bound \(f(n)\), it suffices to control how large a subset of prefix sums can be
chosen so that all pairwise differences are distinct.
\[
\textit{Proof.}
\]
By Lemma 2 the problem is exactly a distinct-differences (Golomb-ruler type)
constraint on prefix-sum indices.
\(\square\)
