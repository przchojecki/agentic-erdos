# EP-279

## Problem Statement
Let $k\geq 3$. Is there a choice of congruence classes $a_p\pmod{p}$ for every prime $p$ such that all sufficiently large integers can be written as $a_p+tp$ for some prime $p$ and integer $t\geq k$?

## Site Remarks
Even the case $k=3$ seems difficult. This may be true with the primes replaced by any set $A\subseteq \mathbb{N}$ such that\[\lvert A\cap [1,N]\rvert \gg N/\log N\]and\[\sum_{\substack{n\in A\\ n\leq N}}\frac{1}{n} -\log\log N\to \infty\]as $N\to \infty$.

If we weaken the question to ask for only almost all integers to be represented in this fashion then, for any $k\geq 2$, any set $A$ such that $\sum_{n\in A}\frac{1}{n}=\infty$ has this property.

## Local Proof Attempts
The background says that analogous covering behavior is known for \(k=1\) and \(k=2\) under a divergent harmonic-sum condition on the underlying set.

The genuinely difficult regime is fixed \(k\ge 3\), which remains open in the cited text.

The key missing ingredient is a residue-class covering theorem for prime moduli with the depth constraint \(t\ge k\), strong enough to guarantee eventual full tail coverage or to show a genuine obstruction.

Target:
For fixed \(k\ge3\), prove eventual full tail cover by one residue class per prime with shift depth \(t\ge k\).
Step A: Weighted Sieve Coverability Criterion
Formulate an explicit criterion in terms of weighted uncovered density after processing primes up to \(P\), with the depth constraint tracked.
Step B: Entropy Decay of Uncovered Set
Show the criterion implies multiplicative decay
\[
U_{P'}\le U_P \exp\!\left(-c\sum_{p\in(P,P']} \frac1p\right)+\text{error},
\]
with error summable despite the \(t\ge k\) restriction.
Step C: Tail Vanishing
Deduce that the uncovered density tends to zero beyond some threshold, implying eventual coverage.
Concrete Blocking Lemma (Most Critical):
Need a depth-constrained residue selection lemma: for each prime \(p\), one can choose \(a_p\) so that the progression with \(t\ge k\) removes a proportion at least \(c_k/p\) of the currently uncovered mass, uniformly enough to iterate.
