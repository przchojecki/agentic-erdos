# EP-112

## Problem Statement
Let $k=k(n,m)$ be minimal such that any directed graph on $k$ vertices must contain either an independent set of size $n$ or a transitive tournament of size $m$. Determine $k(n,m)$.

## Site Remarks
A problem of Erd\H{o}s and Rado \cite{ErRa67}, who showed $k(n,m) \ll_m n^{m-1}$, or more precisely,\[k(n,m) \leq \frac{2^{m-1}(n-1)^m+n-2}{2n-3}.\]Larson and Mitchell \cite{LaMi97} improved the dependence on $m$, establishing in particular that $k(n,3)\leq n^{2}$. Zach Hunter has observed that\[R(n,m) \leq k(n,m)\leq R(n,m,m),\]which in particular proves the upper bound $k(n,m)\leq 3^{n+2m}$.

See also the entry in the graphs problem collection (https://mathweb.ucsd.edu/~erdosproblems/erdos/newproblems/DirectedPaths.html) - on this site the problem replaces transitive tournament with directed path, but Zach Hunter and Raphael Steiner have a simple argument that proves, for this alternative definition, that $k(n,m)=(n-1)(m-1)$.

## Local Computation
A random digraph search checked both obstructions simultaneously: the absence of an independent set of size \(n\) and the absence of a transitive tournament of size \(m\).

It produced empirical lower-bound signals for small targets; for example, when \((n,m)=(4,4)\), counterexamples were found up to the scanned value \(k=9\).

These are only probabilistic lower bounds on small parameters; exact asymptotics for \(k(n,m)\) require rigorous constructions and matching upper bounds.

## Local Proof Attempts
Route:
Positioned k(n,m) between classical Ramsey-type quantities and examined what is already known for fixed small m.

Hard point:
Bridging broad Ramsey-type bounds to sharp asymptotics for directed transitivity/independence tradeoff is unresolved.

Target:
Determine sharp asymptotics of \(k(n,m)\): the least \(k\) such that every
tournament on \(k\) vertices has an independent set of size \(n\) or a transitive
subtournament of size \(m\).
Step A: Entropy lower constructions
Build explicit/random tournaments avoiding both structures up to large \(k\),
giving lower bounds on \(k(n,m)\).
Step B: Container/regularity upper mechanism
Show any larger tournament must contain one forbidden structure via iterative
density increment.
Step C: Match scales
Align lower and upper formulas to pin the correct growth in \(n,m\).
Concrete Blocking Lemma (Most Critical):
Need a two-parameter container theorem simultaneously controlling large
independent sets and large transitive subtournaments.

Proposition AF1 (Monotonicity):
The function \(k(n,m)\) is nondecreasing in each argument:
\[
n_1\le n_2,\ m_1\le m_2 \implies k(n_1,m_1)\le k(n_2,m_2).
\]
\[
\textit{Proof.}
\]
If a tournament forces an independent set of size \(n_2\) or transitive set of
size \(m_2\), it certainly forces one of size \(n_1\) or \(m_1\).
\(\square\)
Proposition AF2 (Reduction to matching bounds):
If functions \(L(n,m)\), \(U(n,m)\) satisfy
\[
L(n,m)\le k(n,m)\le U(n,m),
\]
and \(\log U-\log L=o(1)\cdot \log L\) in a regime, then \(k(n,m)\) is
asymptotically determined there up to \(1+o(1)\) multiplicative factor.
\[
\textit{Proof.}
\]
Take logarithms and compare relative error.
\(\square\)
