# EP-786

## Problem Statement
Let $\epsilon>0$. Is there some set $A\subset \mathbb{N}$ of density $>1-\epsilon$ such that $a_1\cdots a_r=b_1\cdots b_s$ with $a_i,b_j\in A$ can only hold when $r=s$?

Similarly, can one always find a set $A\subset\{1,\ldots,N\}$ with this property of size $\geq (1-o(1))N$?

## Site Remarks
An example of such a set with density $1/4$ is given by the integers $\equiv 2\pmod{4}$.

Selfridge constructed such a set with density $1/e-\epsilon$ for any $\epsilon>0$: let $p_1<\cdots<p_k$ be a sequence of large consecutive primes such that\[\sum_{i=1}^k\frac{1}{p_i}<1<\sum_{i=1}^{k+1}\frac{1}{p_i},\]and let $A$ be those integers divisible by exactly one of $p_1,\ldots,p_k$.

For the second question the set of integers with a prime factor $>N^{1/2}$ give an example of a set with size $\geq (\log 2)N$. Erd\H{o}s could improve this constant slightly. Such an improvement is given by Tao in the comments, taking $A$ to be the set of all integers with exactly one prime factor $>N^{\frac{1}{1+\sqrt{e}}}$, which has size $\approx 0.8285 N$.

In \cite{Er65} Erd\H{o}s reports that Ruzsa proved the maximal size of such an $A$ is $\leq (1-c)N$ for some constant $c>0$ for large $N$, but the proof 'is not yet published'. It is presumably the following.

For any such $A$ we can define an associated additive function $f$ by letting $f(a_1\cdots a_r)=r$, and then $A=\{ n: f(n)=1\}$. A result of Erd\H{o}s, Ruzsa, and S\'{a}rkz\"{o}zy \cite{ERS73} then implies that there exists a constant $c>0$ such that, for all sufficiently large $N$, $\lvert A\rvert\leq (1-c)N$. In \cite{ERS73} they indicate that their method should be able to obtain this with $c=1/10$. In the comments Tao explains how a result of Granville and Soundararajan \cite{GrSo01} implies\[\lvert A\rvert\leq (1-c+o(1))N\]for an explicit constant $c\approx 0.1715$, and this is the best possible (see also [121]).

Theorem 2 from \cite{ERS73} also implies a negative answer to the first question, in that the density is at most $1/2$.

The above all assumes that repetition is allowed amongst the $a_i$ and $b_i$ in this condition. It is ambiguous in the original sources cited whether this was intended or not. If we insist the products are of distinct elements then this is a weaker condition on $A$, and the above questions are still open.

The formulation in \cite{Er80} is clear that repetitions are not allowed, but also claims that Ruzsa had shown the answer to both questions is no in this case (and that Ruzsa had shown that the upper density of $A$ is $<1/e$ if $A$ is infinite with this property); it is possible that Erd\H{o}s was mistakenly thinking of the above results, in which repetitions are allowed.

See also [421] and [795].

  If one takes $A$ to be the set of $n$ with exactly one prime factor greater than $N^{1/(1+\sqrt{e})}$, one gets a set of density $1-c+o(1)$ where
  $$c = 1 - \log(1+\sqrt{e}) + 2 \int_1^{\sqrt{e}} \frac{\log t}{t+1}\ dt = 0.171500\dots$$
  is the Hall-Montgomery constant (https://oeis.org/A143301); this is presumably what the "slight improvement of the constant $\log 2=1-0.3086\dots$" by Erdos optimizes to (see Theorem 9 of this recent paper of Fleiner et al. (https://arxiv.org/abs/2405.12088) for a closely related calculation; Erdos's own calculation likely closely follows that in page 585 of this paper of Erdos, Sarkozy, and Sos (https://users.renyi.hu/~sos/1995_On_Product_Representations_of_Powers.pdf)). $A$ can also be defined as the set $\{ n \leq N: f(n)=-1\}$, where $f$ is the completely multiplicative function with $f(p)=-1$ if $p > N^{1/(1+\sqrt{e})}$ and $f(p)=+1$ otherwise. Corollary 1 of this paper of Granville and Soundararajan (https://arxiv.org/abs/math/9909190) shows that this is the best density one can get from such a completely multiplicative construction, and one can tentatively conjecture that this is in fact the optimal density for the second part of this problem. (A similar line of reasoning would lead to a predicted upper bound of 1/2 for the density in the first part of the problem, but I doubt that this would be sharp, as I do not think that constructions arising from completely multiplicative functions are the most important case here.)
  
  A recent paper of mine (https://arxiv.org/abs/2405.11610) has a similar conjecture relating to #121. In the spirit of that paper, one might try to recover Ruzsa's result (i.e., answer the second part of this problem in the negative) by constructing some reasonably uniform probability measure on $\{1,\dots,N\}$ with the property that the probability of a collision $a_1 \dots a_r = b_1 \dots b_s$ for some suitable distinct $r,s$ is non-zero (with $a_1,\dots,a_r,b_1,\dots,b_s$ drawn independently using this probability measure), and also does not change much if one fixes any one of the $a_1,\dots,a_r,b_1,\dots,b_s$, so that one still gets collisions even if one conditions to an event of probability $1-o(1)$. As long as the probability measure is contiguous (https://en.wikipedia.org/wiki/Contiguity_(probability_theory)) with the uniform measure in the sense that events that occur with probability $1-o(1)$ in one measure, also occur with probability $1-o(1)$ in the other, this should recover Ruzsa's result.
  
  Based on the above literature, it may also be worth considering as model problems variants of the problem in which density is not measure with respect to the uniform measure on $\{1,\dots,N\}$, but instead with the logarithmic measure (with each $1 \leq n \leq N$ having a density proportional to $1/n$), or a zeta distribution (with $n$ ranging over all natural numbers, but with density proportional to $1/n^s$ for some $s>1$). The limiting distribution of products such as $a_1 \dots a_r$ may be easier to analyze for such distributions, though the threshold densities will likely be different from the ones predicted above.

## Local Proof Attempts
The current progress is only constructive finite evidence: build dense sets greedily while enforcing exact consistency of prime-exponent relations so that multiplicative equalities cannot change the number of factors. This yields surprisingly dense examples on moderate intervals, but it is still far from an asymptotic statement such as density \(1-\varepsilon\) or a proof of impossibility.
