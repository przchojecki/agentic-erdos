# EP-282

## Problem Statement
Let $A\subseteq \mathbb{N}$ be an infinite set and consider the following greedy algorithm for a rational $x\in (0,1)$: choose the minimal $n\in A$ such that $n\geq 1/x$ and repeat with $x$ replaced by $x-\frac{1}{n}$. If this terminates after finitely many steps then this produces a representation of $x$ as the sum of distinct unit fractions with denominators from $A$.

Does this process always terminate if $x$ has odd denominator and $A$ is the set of odd numbers? More generally, for which pairs $x$ and $A$ does this process terminate?

## Site Remarks
In 1202 Fibonacci observed that this process terminates for any $x$ when $A=\mathbb{N}$. The problem when $A$ is the set of odd numbers is due to Stein.

Graham \cite{Gr64b} has shown that $\frac{m}{n}$ is the sum of distinct unit fractions with denominators $\equiv a\pmod{d}$ if and only if\[\left(\frac{n}{(n,(a,d))},\frac{d}{(a,d)}\right)=1.\]Does the greedy algorithm always terminate in such cases?

Graham \cite{Gr64c} has also shown that $x$ is the sum of distinct unit fractions with square denominators if and only if $x\in [0,\pi^2/6-1)\cup [1,\pi^2/6)$. Does the greedy algorithm for this always terminate? Erd\H{o}s and Graham believe not - indeed, perhaps it fails to terminate almost always.

See also [206].

  Enumerate the set $A$ in the increasing order as $a(1),a(2),a(3),\ldots$. Quite obviously, the greedy algorithm converges but never terminates precisely for the numbers $x\in(0,\infty)$ in the set
  \begin{align*} G = \Big\{ \sum_{k=1}^{\infty} \frac{1}{a(n_k)} : &\ n_k\in\mathbb{N},\ (n_k) \text{ strictly increasing}, \\
  &\ \sum_{l=k+1}^{\infty} \frac{1}{a(n_l)} < \frac{1}{a(n_k-1)} - \frac{1}{a(n_k)} \text{ for } k\in\mathbb{N} \Big\}.
  \end{align*}
  (Here, $a(0)=0$, $1/0=\infty$.)
  Thus, for instance, the "question on squares" is equivalent to the possibility of writing a rational number $x\in(0,1)$ as\[ x=\sum_{k=1}^{\infty} \frac{1}{n_k^2}, \text{ where } \sum_{l=k+1}^{\infty} \frac{1}{n_l^2} < \frac{2n_k-1}{(n_k-1)^2 n_k^2}. \]This "abstract nonsense" argument at least places the problem in the realm of irrationality questions. For instance, one can, rather cheaply, just apply the simple observation by Terry and myself under [263] to prove (non-constructively) that there exist $A$ asymptotically equal to the sequence of squares with a negative answer to the greedy algorithm termination.
  Moreover, one can even consider a Cantor-type set $G’\subset G$,\[ G' := \Big\{ \sum_{k=1}^{\infty} \frac{1}{a(n_k)} : n_k\in[M_k,N_k] \text{ for } k\in\mathbb{N} \Big\} \]for carefully chosen $M_1,N_1,M_2,N_2,\ldots$, and try to find a rational number inside $G'$, which makes the problem look similar to [257]. In fact, this problem and many other irrationality problems would follow if we had a way of finding rational numbers in (sufficiently thick) Cantor-type sets. Of course, if the set $G’$ in question is "extremely" thick, then basic Diophantine approximations easily give (many) rational numbers inside $G'$. This can give a negative answer to the greedy algorithm termination also for some concrete $A$.
  In short, something could be done, but I am still undecided if this can help with any of the concrete questions stated above.
  Added note: Junnosuke Koizumi recently (https://arxiv.org/abs/2504.05933) creatively used the connection between an irrationality problem and a greedy-type approximation.

## Local Proof Attempts
Target:
Prove termination of odd-denominator greedy algorithm for all reduced \(m/n\) with
odd \(n\).
Step A: Invariant extraction
Identify a strictly decreasing potential under one odd-greedy step (for example a
lexicographic pair involving denominator and adjusted numerator).
Step B: Descent theorem
Show potential cannot decrease infinitely in \(\mathbb N^2\), forcing
termination.
Step C: Classification of hard cases
Control near-critical fractions where denominator growth is slowest.
Concrete Blocking Lemma (Most Critical):
Need an odd-step denominator inequality proving each greedy move decreases a
well-founded measure uniformly, without parity failures.

Lemma 1 (Single-step identity):
Given \(0<m<n\) with odd \(n\), choose odd \(q\) by odd-greedy rule and write
\[
\frac{m}{n}=\frac1q+\frac{m'}{n'}.
\]
Then
\[
m' q n = mqn-n = n(mq-1),\qquad n'=nq.
\]
\[
\textit{Proof.}
\]
Subtract \(1/q\):
\[
\frac{m}{n}-\frac1q=\frac{mq-n}{nq}.
\]
Set \(m'=mq-n\), \(n'=nq\) and reduce if needed.
\(\square\)
Lemma 2 (Numerator decrease in proper step):
If \(q=\left\lceil n/m\right\rceil_{\text{odd}}\) and \(m<n\), then
\[
0\le m'<m.
\]
\[
\textit{Proof.}
\]
By choice of \(q\), \(mq\ge n\), so \(m'\ge0\). Also \(q< n/m+2\), hence
\[
m'=mq-n < m\left(\frac{n}{m}+2\right)-n =2m.
\]
For proper odd-greedy steps, refinement of ceiling bound gives \(q\le n/m+1\) in
the parity-compatible branch, implying \(m'<m\). (This is the key place where the
full proof needs the missing parity-control lemma below.)
\(\square\)
Lemma 3 (Reduction to parity-control lemma):
If one proves the parity-control statement guaranteeing the \(q\le n/m+1\) branch
infinitely often cannot fail, termination follows by repeated numerator descent.
\[
\textit{Proof.}
\]
Apply Lemma 2 iteratively: numerator is a nonnegative integer strictly
decreasing, so process stops.
\(\square\)
