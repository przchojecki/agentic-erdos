# EP-373

## Problem Statement
Show that the equation\[n! = a_1!a_2!\cdots a_k!,\]with $n-1>a_1\geq a_2\geq \cdots \geq a_k\geq 2$, has only finitely many solutions.

## Site Remarks
This would follow if $P(n(n+1))/\log n\to \infty$, where $P(m)$ denotes the largest prime factor of $m$ (see Problem [368]). Erd\H{o}s \cite{Er76d} proved that this problem would also follow from showing that $P(n(n-1))>4\log n$.

The condition $a_1<n-1$ is necessary to rule out the trivial solutions when $n=a_2!\cdots a_k!$.

Sur\'{a}nyi was the first to conjecture that the only non-trivial solution to $a!b!=n!$ is $6!7!=10!$. More generally, Hickerson (as reported in \cite{Er76d}) conjectured that the only non-trivial solutions to the equation in the problem statement are\[9!=2!3!3!7!,\]\[10!=6!7!,\]\[10!=3!5!7!,\]and\[16!=14!5!2!.\]Luca \cite{Lu07b} has shown that there are only finitely many solutions, conditional on the ABC conjecture (https://en.wikipedia.org/wiki/Abc_conjecture), and proved unconditionally that the number of $n\leq x$ which admit a non-trivial solution is\[\leq \exp \bigg(f(x)\frac{\log (x)}{\log\log (x)}\bigg)\]for any function $f(x)$ which tends to infinity.

This is discussed in problem B23 of Guy's collection \cite{Gu04}.

In the case when $k=2$, Erd\H{o}s \cite{Er93} proved that if $n!=a_1!a_2!$ with $n-1>a_1\geq a_2$ then\[a_1\geq n-5\log\log n,\]and says it 'would be nice' to prove $a_1\geq n-o(\log\log n)$. Bhat and Ramachandra \cite{BhRa10} replace the $5$ with $(1+o(1))\frac{1}{\log 2}$, and also prove that the same bound holds for arbitrary $k\geq 2$.

Numerical investigations on solutions to $n!=a_1!a_2!$ have been carried out by Caldwell \cite{Ca94} and Habsieger \cite{Ha19}, and it is known that there are no solutions aside from $10!=6!7!$ for $n\leq 10^{3000}$.

## Local Proof Attempts
Target:
Classify solutions to
\[
n! = \prod_{j=1}^k a_j!,\qquad 2\le a_j < n,
\]
and in particular prove finiteness (or complete list) for fixed \(k\).
A. Concrete Blocking Lemma (Most Critical):
For each fixed \(k\ge2\), prove an effective inequality
\[
\max_j a_j \le n - c_k \log n
\]
for all sufficiently large nontrivial solutions, with \(c_k>0\).
Combined with Stirling-expansion balancing, this would force an explicit contradiction for large \(n\), yielding finiteness.
B. Reduction Lemmas (with proofs):
Lemma B1 (largest-factor normalization):
If \(a_k=\max_j a_j\), then \(a_k\le n-1\), and equality \(a_k=n-1\) forces
\[
n=\prod_{j<k} a_j!.
\]
Proof.
Each \(a_j<n\) by nontriviality. If \(a_k=n-1\), divide the identity by \((n-1)!\) to get \(n=\prod_{j<k}a_j!\). \(\square\)
Lemma B2 (prime-support constraint):
Let \(p\in (n/2,n]\) be prime. Then \(v_p(n!)=1\), hence exactly one factor \(a_j!\) has \(a_j\ge p\).
Proof.
Since \(p>n/2\), only one multiple of \(p\) lies in \([1,n]\), namely \(p\), so \(v_p(n!)=1\). In the product of factorials, this means exactly one factor contributes this single \(p\)-valuation. \(\square\)
Lemma B3 (effective finite search once A is known):
Assume Lemma A. Then for fixed \(k\), only finitely many \(n\) can satisfy the equation.
Proof.
Lemma A bounds all \(a_j\) away from \(n\) by at least \(c_k\log n\). Applying Stirling to both sides gives
\[
n\log n - n = \sum_j (a_j\log a_j-a_j)+O_k(\log n),
\]
and the right side misses enough top mass to violate equality for large \(n\). Hence only bounded \(n\) remain, thus finitely many solutions. \(\square\)
C. Main unresolved point:
The hard step is quantitative control of how close several \(a_j\) can simultaneously sit to \(n\) while matching all prime valuations of \(n!\). This is the exact point where known arguments lose uniformity.
