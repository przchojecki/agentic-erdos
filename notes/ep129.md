# EP-129

## Problem Statement
Let $R(n;k,r)$ be the smallest $N$ such that if the edges of $K_N$ are $r$-coloured then there is a set of $n$ vertices which does not contain a copy of $K_k$ in at least one of the $r$ colours. Prove that there is a constant $C=C(r)>1$ such that\[R(n;3,r) < C^{\sqrt{n}}.\]

## Site Remarks
Conjectured by Erd\H{o}s and Gy\'{a}rf\'{a}s, who proved the existence of some $C>1$ such that $R(n;3,r)>C^{\sqrt{n}}$. Note that when $r=k=2$ we recover the classic Ramsey numbers. Erd\H{o}s thought it likely that for all $r,k\geq 2$ there exists some $C_1,C_2>1$ (depending only on $r$) such that\[ C_1^{n^{1/k-1}}< R(n;k,r) < C_2^{n^{1/k-1}}.\]Antonio Girao has pointed out that this problem as written is easily disproved, and indeed $R(n;3,2) \geq C^{n}$:

The obvious probabilistic construction (randomly colour the edges red/blue independently uniformly at random) yields a 2-colouring of the edges of $K_N$ such every set on $n$ vertices contains a red triangle and a blue triangle (using that every set of $n$ vertices contains $\gg n^2$ edge-disjoint triangles), provided $N \leq C^n$ for some absolute constant $C>1$. This implies $R(n;3,2) \geq C^{n}$, contradicting the conjecture.

Perhaps Erd\H{o}s had a different problem in mind, but it is not clear what that might be. It would presumably be one where the natural probabilistic argument would deliver a bound like $C^{\sqrt{n}}$ as Erd\H{o}s and Gy\'{a}rf\'{a}s claim to have achieved via the probabilistic method.

  Fix an integer $r\ge 2$. For infinitely many $n$ (namely $n\equiv 1$ or $3 \pmod 6$) there exists a Steiner triple system on $n$ points, equivalently a decomposition of the edges of $K_n$ into edge-disjoint triangles. Fix such an $n$, and write\[
  t=\frac{\binom{n}{2}}{3}=\frac{n(n-1)}6
  \]for the number of triangles in this decomposition. Let $N$ be a parameter and consider the complete graph $K_N$ on vertex set $[N]:=\{1,\dots,N\}$. Colour each edge of $K_N$ independently and uniformly at random with one of the colours $1,\dots,r$.
  
  Fix an $n$-subset $S\subseteq [N]$ and a colour $c\in[r]$. Let $A_{S,c}$ be the event that $S$ contains no copy of $K_3$ in colour $c$ (i.e. the colour-$c$ subgraph induced by $S$ is triangle-free). Identifying $S$ with $\{1,\dots,n\}$, let $T_1,\dots,T_t$ be the $t$ edge-disjoint triangles given by the Steiner triple system. If $A_{S,c}$ holds then, in particular, none of the triangles $T_i$ is monochromatic of colour $c$. Since the $T_i$ are edge-disjoint and edge colours are independent, the events “$T_i$ is monochromatic of colour $c$” are independent, and for each $i$,\[
  \mathbb P(T_i\text{ is monochromatic of colour }c)=r^{-3}.
  \]Hence\[
  \mathbb P(A_{S,c})
  \le \mathbb P(\forall i,\ T_i \text{ is not monochromatic of colour }c)
  =(1-r^{-3})^{\,t}.
  \]Call $S$ bad if $A_{S,c}$ holds for at least one colour $c\in[r]$; this is exactly the kind of $n$-set whose existence the definition of $R(n;3,r)$ would force. By a union bound over $c$,\[
  \mathbb P(S\text{ is bad})\le \sum_{c=1}^r \mathbb P(A_{S,c})\le r(1-r^{-3})^{\,t}.
  \]Let $B$ be the number of bad $n$-subsets of $[N]$. By linearity of expectation and $\binom{N}{n}\le (eN/n)^n$,\[
  \mathbb E[B]\le \binom{N}{n}\, r(1-r^{-3})^{\,t}\le \Bigl(\frac{eN}{n}\Bigr)^n\, r(1-r^{-3})^{\,t}.
  \]Choose $N=\lfloor e^{\gamma n}\rfloor$ with $\gamma<\frac16\log\!\bigl(\frac1{1-r^{-3}}\bigr)$. Then\[
  \log \mathbb E[B]\le n\log\Bigl(\frac{eN}{n}\Bigr)+\log r+t\log(1-r^{-3})
  =\Bigl(\gamma-\frac16\log\!\Bigl(\frac1{1-r^{-3}}\Bigr)\Bigr)n^2+o(n^2),
  \]so $\mathbb E[B]<1$ for all sufficiently large admissible $n$. Therefore there exists an $r$-colouring of $E(K_N)$ with $B=0$, i.e. every $n$-subset $S$ contains a monochromatic triangle in every colour.
  
  For these $n$ we have $R(n;3,r)>N\ge e^{c_r n}$ for some constant $c_r>0$ (e.g. any $c_r<\frac16\log(\frac1{1-r^{-3}})$). This contradicts any asserted upper bound $R(n;3,r)<C(r)^{\sqrt n}$, since $\exp(c_r n)$ eventually dominates $\exp((\log C(r))\sqrt n)$ as $n\to\infty$. Thus, under the stated definition of $R(n;3,r)$, the inequality $R(n;3,r)<C(r)^{\sqrt n}$ is false as written.

## Local Proof Attempts
Counterexample route:
Fix any integer r >= 2.
For infinitely many n (n ≡ 1 or 3 mod 6), K_n decomposes into edge-disjoint triangles
(Steiner triple system), with
t = n(n-1)/6.
Fix such an n, and color edges of K_N independently and uniformly with r colors.
For a fixed n-subset S of vertices:
- The induced graph is K_n.
- Using the t edge-disjoint triangles of K_n, the events
 "triangle i is monochromatic in color c" are independent (for each fixed color c).
- Therefore
 P(S has no triangle of color c) <= (1 - r^{-3})^t.
- So
 P(S is bad) <= r(1-r^{-3})^t
 by union bound over colors c=1,...,r.
Let B be the number of bad n-subsets. Then
E[B] <= C(N,n) * r(1-r^{-3})^t.
Using C(N,n) <= (eN/n)^n, choose
N = floor(exp(gamma n)), with
gamma < (1/6) log(1/(1-r^{-3})).
Then
log E[B] <= n log(eN/n) + log r - t log(1/(1-r^{-3}))
has leading term
(gamma - (1/6)log(1/(1-r^{-3}))) n^2 < 0,
so E[B] < 1 for all sufficiently large admissible n.
Hence there exists an r-coloring of K_N with no bad n-subset, i.e.
every n-subset contains a monochromatic triangle in every color.
Therefore
R(n;3,r) > N >= exp(c_r n) (for some c_r>0, infinitely many admissible n).

Contradiction to the claimed upper bound:
If R(n;3,r) < C(r)^{sqrt(n)} held (for all large n, or all n), then for large admissible n we would have
exp(c_r n) <= R(n;3,r) < C(r)^{sqrt(n)},
impossible since c_r n >> sqrt(n).
So the EP-129 statement is false as written.
