# EP-1068

## Problem Statement
Does every graph with chromatic number $\aleph_1$ contain a countable subgraph which is infinitely vertex-connected?

## Site Remarks
This is described in \cite{BoPi24} as a 'version of the Erd\H{o}s-Hajnal problem' (which is [1067]), but it does not seem to appear in \cite{ErHa66}.

We say a graph is infinitely (vertex) connected if any two vertices are connected by infinitely many pairwise vertex-disjoint paths.

Soukup \cite{So15} constructed a graph with uncountable chromatic number in which every uncountable set is finitely vertex-connected. A simpler construction was given by Bowler and Pitz \cite{BoPi24}.

See also [1067].

- 12:13 on 18 Jan 2026 - ebarschkis:
  I think it would be worth noting that the answer to this problem depends heavily on the definition of connectivity. If interpreted as edge-connectivity, this problem is solved. Thomassen (2016 paper (https://backend.orbit.dtu.dk/ws/files/124108162/Erdos_Hajnal_final.pdf)) proved that every graph with uncountable chromatic number contains a subgraph of infinite edge-connectivity.
  
  However, the problem remains open for vertex-connectivity. I suggest updating the problem statement to explicitly specify "infinitely vertex-connected" to avoid ambiguity.
  
  Another important detail is that it is known that such a graph does not need to contain an uncountable infinitely vertex-connected subgraph (arXiv paper (https://arxiv.org/pdf/2402.05984v1)).

## Local Computation
- finite proxy experiment:
 - built the family $C_5, M(C_5), M^2(C_5), M^3(C_5)$,
 - exact DSATUR chromatic computation on family members,
 - k-core and random-cut connectivity-lower probes,
 - heavy induced-subgraph campaign on $M^3(C_5)$ with exact bounded DSATUR runs.
- Deep run scale:
 - $2800$ induced samples for each of five sizes (total $14{,}000$ exact coloring runs),
 - full-family exact checks up to $n=47$.

- Family chromatic numbers increase as expected: $3,4,5,6$.
- On $M^3(C_5)$, induced-sample chromatic proxies tighten with size; by $n=46$, sampled subgraphs were consistently near maximal chromatic load in this model.
- These finite signals reflect strong high-chromatic/connected tension, but do not imply the infinite theorem.

## Local Proof Attempts
The Mycielski-family experiments show a strong finite tension between chromatic load and connectivity-style proxies, but they do not address the genuine infinite statement. What remains open is whether this finite high-chromatic behavior can be promoted to the required countable or infinite graph setting.
