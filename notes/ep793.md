# EP-793

## Problem Statement
Let $F(n)$ be the maximum possible size of a subset $A\subseteq\{1,\ldots,n\}$ such that $a\nmid bc$ whenever $a,b,c\in A$ with $a\neq b$ and $a\neq c$. Is there a constant $C$ such that\[F(n)=\pi(n)+(C+o(1))n^{2/3}(\log n)^{-2}?\]

## Site Remarks
Erd\H{o}s \cite{Er38} proved there exist constants $0<c_1\leq c_2$ such that\[\pi(n)+c_1n^{2/3}(\log n)^{-2}\leq F(n) \leq \pi(n)+c_2n^{2/3}(\log n)^{-2}.\]Erd\H{o}s \cite{Er69} gave a simple proof that $F(n) \leq \pi(n)+n^{2/3}$: define a graph with vertex set the union of those integers in $[1,n^{2/3}]$ with all primes $p\in (n^{2/3},n]$. We have an edge $u\sim v$ if and only if $uv\in A$. It is easy to see that every $m\leq n$ can be written as $uv$ where $u\leq n^{2/3}$ and $v$ is either prime or $\leq n^{2/3}$, and hence there are $\geq \lvert A\rvert$ many edges. This graph contains no path of length $3$ and hence must be a tree and have fewer edges than vertices, and we are done. This can be improved to give the upper bound mentioned by using a subset of integers in $[1,n^{2/3}]$.

More generally, one can ask for such an asymptotic for the size of sets such that no $a\in A$ divides the product of $r$ distinct other elements of $A$, with the exponent $2/3$ replaced by $\frac{2}{r+1}$.

For further discussion and references concerning this generalisation to $r\geq 3$ see the comment by Wouter van Doorn.

See also [425].

  There seems to be some missing details in the argument proving $F(n)\leq \pi(n)+n^{2/3}$ given in the description.
  The statement "It is easy to see that every $m\leq n$ can be written as $uv$ where $u\leq n^{2/3}$ and $v$
   is either prime or $\leq n^{2/3}$," only holds for $n^{2/3} < p^2 \leq n$ if we can take $u=v$. However that would imply that we can take self-loops in the graph. Then the graph being a tree does not immediately imply that the number of edges is less than the number of vertices.
  
  EDIT: I realise that if a vertex has a self loop, then it cannot have an edge with any other vertex. If $u$ has a loop and $uv$ is an edge in the graph then $u^2$ and $uv$ are in $A$, in which case $u^2|(uv)^2$. So the graph is a forest, where there may be isolated vertices with loops. Therefore the number of edges is less than the number of vertices.

  For a sufficiently large integer $n$, let $F_k(n)$ be the size of the largest set $A \subset \{1, 2, \ldots, n\}$ with the property that no $a \in A$ divides the product of $k$ others. Consider the bounds $$\pi(n) + \frac{c_k n^{2/(k+1)}}{\log^2 n} \le F_k(n) \le \pi(n) + \frac{C_k n^{2/(k+1)}}{\log^2 n}. \hspace{20pt} (1)$$Then Erdős stated in [Er69, p. 78] that even though he only had proved $(1)$ in [Er38] for $k = 2$, his method does extend to prove both inequalities for all fixed $k \ge 2$. No further details were given though. These general bounds were repeated in Problem E4 of Guy's collection [Gu04].
  
  Skipping ahead to 2010, Chan, Győri and Sárközy (see here (https://www.sciencedirect.com/science/article/pii/S0195669809000614)) did not seem aware of Erdős' claim that his proof also works for larger $k$, and prove themselves that for all large enough $n$ and all $k$ with $2 \le k \le \frac{\log n}{6 \log \log n}$ the lower bound in $(1)$ holds with $c_k = \frac{1}{8k^2}$. They moreover show that the upper bound holds when $k = 3$, for some unspecified constant $C_3$. But they could not show the upper bound in $(1)$ in full generality.
  
  A year later still, Chan (see here (https://www.sciencedirect.com/science/article/pii/S0195669810001721?via%3Dihub)) did prove that the upper bound in $(1)$ holds more generally, for all large enough $n$ and all $k$ with $2 \le k \le \frac{\log n}{6 \log \log n}$ where $C_k = ck^2$ for some absolute $c$.

## Local Computation
Exact finite result proved in this attempt:
I reduced the condition to a 3-uniform hypergraph independence problem and solved it exactly
for 6<=n<=50.
Sample exact values:
- F(30)=11
- F(50)=16

This is a rigorous finite table, not an asymptotic proof of
F(n)=pi(n)+(C+o(1)) n^(2/3)/(log n)^2.
