# EP-217

## Problem Statement
For which $n$ are there $n$ points in $\mathbb{R}^2$, no three on a line and no four on a circle, which determine $n-1$ distinct distances and so that (in some ordering of the distances) the $i$th distance occurs $i$ times?

## Site Remarks
An example with $n=4$ is an isosceles triangle with the point in the centre. Erd\H{o}s originally believed this was impossible for $n\geq 5$, but Pomerance constructed a set with $n=5$ (see \cite{Er83c} for a description).

Pal\'{a}sti \cite{Pa87} constructed such a set with $n=7$. According to \cite{Pa89} when Erd\H{o}s saw this he asked whether there exists such a set of $5$ points with no equilateral triangles; Pal\'{a}sti \cite{Pa89} {IMAGE=217a,constructed a set} of $n=6$ points, satisfying these restrictions, with no equilateral triangles.

Pal\'{a}sti \cite{Pa89b} has {IMAGE=217b,constructed a set} with $n=8$.

Erd\H{o}s believed this is impossible for all sufficiently large $n$. This would follow from $h(n)\geq n$ for sufficiently large $n$, where $h(n)$ is as in [98].

## Local Computation
Route:
Ran randomized geometric search on integer grids under the explicit constraints (no 3 collinear, no 4 concyclic), checking the exact multiplicity pattern 1,2,...,n-1.

## Local Proof Attempts
Evidence from this batch:
- (for n=6,7,8,9) found no witness in tested random windows.

Hard point:
Lattice random search is a narrow finite model and does not capture full Euclidean configuration space or prove nonexistence for large n.

Target:
Decide existence for large \(n\) of point sets whose distance multiplicities are
exactly \(1,2,\dots,n-1\) under the stated general-position constraints.
Step A: Multiplicity-sum consistency
Use total pair count and multiplicity profile identities to derive necessary
arithmetic conditions.
Step B: Geometric realizability filters
Impose no-3-collinear/no-4-cocircular constraints and show they conflict with
high-multiplicity requirements beyond some scale.
Step C: Construction or obstruction
Either build an infinite family meeting all constraints or prove finite cutoff.
Concrete Blocking Lemma (Most Critical):
Need a realizability theorem showing prescribed full multiplicity spectrum is
incompatible with general position past a threshold.
