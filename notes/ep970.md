# EP-970

## Problem Statement
Let $h(k)$ be Jacobsthal's function, defined to as the minimal $m$ such that, if $n$ has at most $k$ prime factors, then in any set of $m$ consecutive integers there exists an integer coprime to $n$. Determine the order of magnitude of $h(k)$. In particular, is it true that\[h(k) \ll k^2?\]

## Site Remarks
That $h(k)\ll k^2$ is a conjecture of Jacobsthal. Iwaniec \cite{Iw78} proved\[h(k) \ll (k\log k)^2.\]The best lower bound known is\[h(k) \gg \frac{(\log k)(\log\log\log k)}{(\log\log k)^2}k,\]due to Ford, Green, Konyagin, Maynard, and Tao \cite{FGKMT18}.

This is a more general form of the function considered in [687].

## Local Computation
- exact Jacobsthal computations for squarefree moduli:
 - primorial baseline rows,
 - exhaustive scan over all squarefree products of selected small primes with fixed factor count $k$ and modulus cap $n\le 2\times10^6$.
- For each modulus, computed $j(n)$ exactly via periodic blocked-residue runs.

- In exhaustive capped scans for $k=2\dots 7$, best observed moduli were primorials:
 - e.g. $k=6$: best $j(n)=22$ at $n=30030$,
 - $k=7$: best $j(n)=26$ at $n=510510$.
- Observed ratio $j(n)/k^2$ for these best examples sits around $0.53$-$0.67$ in tested range.
- Finite profile supports moderate growth but does not resolve $k^2$ versus $(k\log k)^2$ asymptotics.

## Local Proof Attempts
In the capped exact search, primorials remained the extremal examples for each tested \(k\), which is consistent with the standard heuristic that they drive large Jacobsthal gaps. The asymptotic issue is still open: the data does not distinguish whether the true scale is \(k^2\), \((k\log k)^2\), or something in between.
