# EP-533

## Problem Statement
Let $\delta>0$. If $n$ is sufficiently large and $G$ is a graph on $n$ vertices with no $K_5$ and at least $\delta n^2$ edges then $G$ contains a set of $\gg_\delta n$ vertices containing no triangle.

## Site Remarks
In other words, is it true that\[\delta_3(5)=\lim_{\epsilon \to 0}\lim_{n\to \infty}\frac{\mathrm{RT}_3(n,K_5,\epsilon n)}{n^2}=0,\]where $\mathrm{RT}$ is the Ramsey-Tur\'{a}n number.

A problem of Erd\H{o}s, Hajnal, Simonovits, S\'{o}s, and Szemer\'{e}di, who could prove that $\delta_3(5) \leq 1/12$ (with $\delta$ defined above), and could further prove that the analogous $\delta_3(4)=0$.

They further observed that $\delta_3(7)\geq 1/4$: by a construction of Erd\H{o}s and Rogers \cite{ErRo62} (see [620]) there exists some constant $c>0$ such that, for all large $n$, there is a graph on $n$ vertices which contains no $K_4$ and every set of at least $n^{1-c}$ vertices contains a triangle. If we take two vertex disjoint copies of this graph and add all edges between the two copies then this yields a graph on $2n$ vertices with $\geq n^2$ edges, which contains no $K_7$, yet every set of at least $2n^{1-c}$ vertices contains a triangle.

This is false, and disproved by Balogh and Lenz \cite{BaLe13}, who showed $\delta_3(5)>0$. The correct threshold is $\delta_3(5)=1/12$, the remaining lower bound of $\delta_3(5)\geq 1/12$ due to a construction of Liu, Reiher, Sharifzadeh, and Staden \cite{LRSS21}.

See also [579] and the entry in the graphs problem collection (https://mathweb.ucsd.edu/~erdosproblems/erdos/newproblems/RamseyTuran5.html).

- 19:21 on 10 Sep 2025 - TerenceTao:
  Here is a near-miss: if $G$ has $\gg n^2$ edges and no $K_5$, then there is a set of $n^{1-o(1)}$ vertices that has no triangles. In fact we can even weaken the "no $K_5$" hypothesis to "no $K_6$"! (As discussed in the commentary, this cannot be further weakened to "no $K_7$".)
  
  For sake of notation we will just produce a set of $n^{0.9}$ vertices that has no triangles, but it will be clear that one can replace $0.9$ by any other constant less than $1$, and hence some quantity converging sufficiently slowly to $1$. Suppose for contradiction that this is not the case, thus every set of $n^{0.9}$ vertices has a triangle. For $n$ large enough, we will construct a $K_6$ to create the contradiction.
  
  We use the method of dependent random choice (cf. Gowers' proof of the Balog-Szemeredi-Gowers lemma). By Holder's inequality, the number of stars $a_1,\dots,a_{100},b$ in which $a_1,\dots,a_{100}$ are all adjacent to $b$ is $\gg n^{101}$. Thus, if one picks $a_1,\dots,a_{100}$ at random, the common neighborhood $B$ of $b$'s adjacent to all of the $a_i$ will have size $\gg n$ with probability $\gg 1$.
  
  Suppose $b_1,b_2,b_3$ be vertices such that there are fewer than $n^{0.9}$ vertices incident to all three of $b_1,b_2,b_3$. Then the probability that $b_1,b_2,b_3$ are all selected to be in $B$ is only $O(n^{-0.1})^{100} = O(n^{-10})$. Thus, by the union bound, the probability that $B$ has any such triple is only $O(n^{-7})$.
  
  Thus, for $n$ large enough, we can choose $a_1,\dots,a_{100}$ so that $B$ has size $\gg n$, and such that any three elements of $B$ have a joint neighborhood of size at least $n^{0.9}$. By hypothesis, $B$ contains a triangle; and the joint neighborhood of that triangle also contains a triangle. This creates the desired $K_6$.
  
  A back of the envelope calculation suggests that one can optimize $n^{1-o(1)}$ to $n^{1-O(1/\sqrt{\log n})}$, but I have not checked this carefully.
  
  The same argument shows that the original question would have a positive answer if we had the following strong form of the Balog-Szemeredi-Gowers lemma: if $G$ has $\gg n^2$ edges then there exists a set $A$ of $\gg n$ vertices such that any pair of vertices in $A$ is jointly connected to $\gg n$ vertices. This strong version is false, as was shown by Kostochka and Sudakov (https://kostochk.web.illinois.edu/docs/2004/cpc03s.pdf) using a construction based on the Hamming cube; one may need to understand the precise failure modes of this too-strong lemma better in order to solve the original problem.
