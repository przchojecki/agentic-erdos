# EP-912

## Problem Statement
If\[n! = \prod_i p_i^{k_i}\]is the factorisation into distinct primes then let $h(n)$ count the number of distinct exponents $k_i$.

Prove that there exists some $c>0$ such that\[h(n) \sim c \left(\frac{n}{\log n}\right)^{1/2}\]as $n\to \infty$.

## Site Remarks
A problem of Erd\H{o}s and Selfridge, who proved (see \cite{Er82c})\[h(n) \asymp \left(\frac{n}{\log n}\right)^{1/2}.\]A heuristic of Tao using the Cram\'{e}r model for the primes (detailed in the comments) suggests this is true with\[c=\sqrt{2\pi}=2.506\cdots.\]

- 15:12 on 31 Aug 2025 - TerenceTao:
  One can predict the value of $c$ using the Cramer random model for the primes. Firstly some reductions. Legendre's formula states that
  $$k_i = \lfloor n/p_i \rfloor + \lfloor n/p_i^2 \rfloor + \dots.$$
  Both the main term $\lfloor n/p_i \rfloor$ and the tail $\lfloor n/p_i^2 \rfloor + \dots$ are non-increasing in $i$; but the latter only changes value $O(n^{1/3})$ times (consider the cases $p_i \leq n^{1/3}$ and $p_i \geq n^{1/3}$ separately). Thus, deleting this term only modifies $h$ by a lower order error, and the problem is equivalent to that of counting the number of distinct values of $\lfloor n/p_i \rfloor$.
  
  For any $\varepsilon$, the primes less than $\varepsilon \sqrt{n \log n}$ are only $O(\varepsilon (n/\log n)^{1/2})$ in number, and for the primes $p_i$ larger than $\varepsilon^{-1} \sqrt{n \log n}$ the value of $\lfloor n/p_i\rfloor$ is $O(\varepsilon (n/\log n)^{1/2})$. So up to lower order error we can restrict attention to the primes $p_i \asymp \sqrt{n \log n}$, for which $k_i \asymp (n/\log n)^{1/2}$.
  
  A given $k \asymp (n/\log n)^{1/2}$ will be of the form $\lfloor n/p_i \rfloor$ iff there is a prime in the interval $(n/(k+1),n/k]$. If $k = t (n/\log n)^{1/2}$, this is an interval of length approximately $t^{-2} \log n$ of numbers of size $\asymp \sqrt{n \log n}$ - so the prime density here is approximately $2/\log n$. The Cramer random model then predicts a prime to be present with probability approximately $1-e^{-2t^{-2}}$. So this leads to the prediction
  
  $$ c = \int_0^\infty 1 - e^{-2t^{-2}}\ dt = \sqrt{2\pi} = 2.50663\dots$$
  
  (the value here was provided by an LLM and verified by Wolfram alpha; it can be derived from the usual gaussian integral identities by a routine substitution and the Feynman trick of replacing $2$ by a parameter that one then differentiates in.) A quick AI request to plot the ratio between $h(n)$ and $\sqrt{2\pi} (n/\log n)^{1/2}$ seems to back up this prediction (https://terrytao.wordpress.com/output-2/).
  
  Proving this claim unconditionally, even on average in $n$, would likely require information about the distribution of prime gaps that currently is only available under strong hypotheses such as the prime tuples conjecture.
  
  EDIT: By plugging in the AI-provided values of $h$ into the OEIS, I discovered that the function $h(n)$ is OEIS A071626 (https://oeis.org/A071626). As observed in the paper linked there, the deletion of the tail in fact does not affect $h$ at all (basically because the tail only jumps when the main term does).

## Local Computation
- Implemented exact incremental computation of $h(n)$ from $n=2$ up to $N=5\cdot 10^7$.
- Maintained exact prime-exponent profile of $n!$ and tracked the number of distinct exponent values at sampled checkpoints.
- Computed normalized ratio
$$
\frac{h(n)}{\sqrt{n/\log n}}
$$
to estimate finite-range constant behavior.

- Final sample at $n=50{,}000{,}000$ gives
$$
\frac{h(n)}{\sqrt{n/\log n}}\approx 2.6485.
$$
- Over tail samples in this run, the ratio stays in a narrow band about $2.639$ to $2.666$, with mean about $2.6519$.
- Finite evidence strongly supports the known $\sqrt{n/\log n}$ scale and suggests stable constant-like behavior in this range.

## Local Proof Attempts
The exact large-range computation makes the known order of growth very concrete and suggests that the normalized ratio \(h(n)/\sqrt{n/\log n}\) is stabilizing. That is strong evidence for the existence of a genuine leading constant, but it does not identify or prove the constant.
