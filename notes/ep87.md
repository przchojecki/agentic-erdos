# EP-87

## Problem Statement
Let $\epsilon >0$. Is it true that, if $k$ is sufficiently large, then\[R(G)>(1-\epsilon)^kR(k)\]for every graph $G$ with chromatic number $\chi(G)=k$?

Even stronger, is there some $c>0$ such that, for all large $k$, $R(G)>cR(k)$ for every graph $G$ with chromatic number $\chi(G)=k$?

## Site Remarks
Erd\H{o}s originally conjectured that $R(G)\geq R(k)$, which is trivial for $k=3$, but fails already for $k=4$, as Faudree and McKay \cite{FaMc93} showed that $R(W)=17$ for the pentagonal wheel $W$.

Since $R(k)\leq 4^k$ this is trivial for $\epsilon\geq 3/4$. Yuval Wigderson points out that $R(G)\gg 2^{k/2}$ for any $G$ with chromatic number $k$ (via a random colouring), which asymptotically matches the best-known lower bounds for $R(k)$.

This problem is #12 (https://mathweb.ucsd.edu/~erdosproblems/erdos/newproblems/RGLowerBoundByChromaticNumber1.html) and #13 (https://mathweb.ucsd.edu/~erdosproblems/erdos/newproblems/RGLowerBoundByChromaticNumber2.html) in Ramsey Theory in the graphs problem collection.

## Local Computation
A finite search sampled graphs with fixed \(\chi(G)=k\), computed \((v,e)\), and then derived guaranteed lower bounds \(R(G)>N\) from the first-moment inequality \(\mathbb{E}[\#\text{monochromatic }G] < 1\).

The best sampled lower bounds in this run reached about \(0.72R(4)\) for \(k=4\) and about \(0.35R(5)\) for \(k=5\), using the exact known values of \(R(4)\) and \(R(5)\) as finite references.

This probabilistic bound is still too coarse to approach the target scale \(cR(k)\) uniformly for all \(\chi(G)=k\); sharper graph-structure-dependent bounds are needed.

## Local Proof Attempts
Route:
Compared what can be forced from generic Ramsey lower-bound methods for graphs with chromatic number k against the target comparison to R(k).

Hard point:
To prove R(G) > c R(k) (or (1-eps)^k R(k)), one needs control relative to the true scale of R(k), not just absolute 2^{k/2}-type lower bounds.

Target:
For every \(k\)-chromatic graph \(G\), prove a uniform lower comparison
\[
R(G)\ge c\,R(k)
\]
or the stronger \((1-\varepsilon)^k R(k)\)-type inequality.
Step A: Core extraction
From \(G\), extract a \(k\)-critical core \(G^\star\) with controlled size-growth
relative to \(k\).
Step B: Embedding-resistant coloring model
Construct 2-colorings on \(N\) vertices that simultaneously avoid monochromatic
copies of all graphs in a complexity-bounded family containing \(G^\star\).
Step C: Transfer to \(R(k)\)-scale
Show admissible \(N\) is a fixed proportion of the diagonal Ramsey threshold
scale for \(K_k\), yielding the desired comparison.
Concrete Blocking Lemma (Most Critical):
Need a universal container/entropy lemma for monochromatic embeddings of
\(k\)-critical graphs that is sharp enough to compare to \(K_k\) thresholds.

Proposition Q1 (Critical-core reduction):
Let \(G\) be \(k\)-chromatic and \(G^\star\subseteq G\) a \(k\)-critical
subgraph. Then
\[
R(G)\ge R(G^\star).
\]
\[
\textit{Proof.}
\]
Any monochromatic copy of \(G\) contains a monochromatic copy of \(G^\star\).
Hence avoiding monochromatic \(G^\star\) implies avoiding monochromatic \(G\),
so the Ramsey threshold for \(G\) is at least that for \(G^\star\).
\(\square\)
Proposition Q2 (Scale-transfer criterion):
Assume there exists \(c>0\) such that for every \(k\)-critical \(H\), one has
\[
R(H)\ge c\,R(k).
\]
Then for every \(k\)-chromatic \(G\),
\[
R(G)\ge c\,R(k).
\]
\[
\textit{Proof.}
\]
Apply Proposition Q1 to \(G^\star\subseteq G\), then use the hypothesis on
\(G^\star\).
\(\square\)
