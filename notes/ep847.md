# EP-847

## Problem Statement
Let $A\subset \mathbb{N}$ be an infinite set for which there exists some $\epsilon>0$ such that in any subset of $A$ of size $n$ there is a subset of size at least $\epsilon n$ which contains no three-term arithmetic progression.

Is it true that $A$ is the union of a finite number of sets which contain no three-term arithmetic progression?

## Site Remarks
A problem of Erd\H{o}s, Ne\v{s}et\v{r}il, and R\"{o}dl.

A negative answer was given by Reiher, R\"{o}dl, and Sales \cite{RRS24}, who proved that, for any $0<\mu<1/2$, there exists $A\subseteq \mathbb{N}$ such that every finite colouring of $A$ contains a three-term arithmetic progression, and yet every subset of $A$ of size $n$ contains a subset of size $\geq \mu n$ without a three-term arithmetic progression.

See also [774] and [846].

## Local Computation
- Built finite exact analog on $[1..N]$ using 3-AP hypergraph.
- Computed exactly:
 - $\alpha_{3\text{AP}}(N)$, maximum 3AP-free subset size;
 - minimum color count partitioning $[1..N]$ into 3AP-free classes.

- For $N=9,12,15,18$, computed ratios $\alpha_{3\text{AP}}(N)/N$ in the range about $0.44$-$0.56$.
- In all tested cases, 3 colors suffice to partition into 3AP-free classes.
- Finite exact behavior is consistent with nontrivial local extraction plus bounded finite coloring, but does not imply the infinite theorem.

## Local Proof Attempts
The finite optimization keeps the multiplicative exclusion constraint and tries to maximize the normalized harmonic sum directly. The observed values stay quite substantial on accessible ranges, which is compatible with very slow decay, but it does not contradict the known \(o(1)\) asymptotic or identify the true rate.
