# EP-863

## Problem Statement
Let $r\geq 2$ and let $A\subseteq \{1,\ldots,N\}$ be a set of maximal size such that there are at most $r$ solutions to $n=a+b$ with $a\leq b$ for any $n$. (That is, $A$ is a $B_2[r]$ set.)

Similarly, let $B\subseteq \{1,\ldots,N\}$ be a set of maximal size such that there are at most $r$ solutions to $n=a-b$ for any $n\geq 1$.

If $\lvert A\rvert\sim c_rN^{1/2}$ as $N\to \infty$ and $\lvert B\rvert \sim c_r'N^{1/2}$ as $N\to \infty$ then is it true that $c_r\neq c_r'$ for $r\geq 2$? Is it true that $c_r'<c_r$?

## Site Remarks
According to Erd\H{o}s, first formulated in conversation with Berend, and later independently reformulated with Freud.

It is true that $c_1=c_1'$, and the classical bound on the size of Sidon sets (see [30]) implies $c_1=c_1'=1$.

Ho and GPT-5.4 Pro have noted (https://boonsuan.github.io/erdos863.pdf) that a positive solution follows from arguments in the literature. Indeed, a routine adaptation of the Erd\H{o}s-Tu\'{a}n bound for Sidon sets proves that\[\lvert B\rvert\leq (\sqrt{r}+o(1))N^{1/2},\]while Cilleruelo, Ruzsa, and Trujilo \cite{CRT02} have constructed $A$ with\[\lvert A\rvert \geq \left(\frac{r+\lfloor r/2\rfloor}{\sqrt{r+2\lfloor r/2\rfloor}}\right) N^{1/2}.\]Therefore, provided $r\geq 2$,\[c_r'\leq \sqrt{r}<\frac{r+\lfloor r/2\rfloor}{\sqrt{r+2\lfloor r/2\rfloor}}\leq c_r.\](For example, when $r=2$ these give $c_r'\leq \sqrt{2}\approx 1.41$ and $c_r\geq 3/2=1.5$.)

## Site References

## Local Computation
- Built finite random-greedy proxy searches on $[1..N]$ for both constraints:
 - sum constraint: each sum has at most $r$ representations,
 - difference proxy: each positive difference has at most $r$ representations.
- Compared best and average sizes across repeated runs.

- In tested ranges ($N=80$ to $240$, $r=2,3$), sum-constrained best sizes are consistently larger than difference-constrained best sizes.
- Example at $N=240$:
 - $r=2$: best sum size 26 vs best diff size 22,
 - $r=3$: best sum size 33 vs best diff size 27.
- This finite evidence points in the conjectural direction $c'_r<c_r$, but is not asymptotic proof.

## Local Proof Attempts
The finite-horizon greedy constructions show that forcing disjointness of all sum-level sets \(S_r\) quickly drives the sequence toward near-doubling growth. This is strong evidence that the true infinite objects must be very sparse, but it does not determine the optimal growth law.
