# EP-369

## Problem Statement
Let $\epsilon>0$ and $k\geq 2$. Is it true that, for all sufficiently large $n$, there is a sequence of $k$ consecutive integers in $\{1,\ldots,n\}$ all of which are $n^\epsilon$-smooth?

## Site Remarks
Erd\H{o}s and Graham state that this is open even for $k=2$ and 'the answer should be affirmative but the problem seems very hard'. These remarks are puzzling, since in 1976 Eggleton and Selfridge \cite{EgSe76} had already shown that, for any $\epsilon>0$, there exist infinitely many sets of $5$ consecutive integers $\{n,\ldots,n+4\}$, each of which is $n^\epsilon$-smooth.

The problem is trivially true as written (simply taking $\{1,\ldots,k\}$ and $n>k^{1/\epsilon}$). There are (at least) two possible variants which are non-trivial, and it is not clear which Erd\H{o}s and Graham meant. Let $P$ be the sequence of $k$ consecutive integers sought for. Some potential strengthenings which make this non-trivial are:
{UL}
{LI}Each $m\in P$ must be $m^\epsilon$-smooth. If this is the problem then the answer is yes, which follows from a result of Balog and Wooley \cite{BaWo98}: for any $\epsilon>0$ and $k\geq 2$ there exist infinitely many $m$ such that $m+1,\ldots,m+k$ are all $m^\epsilon$-smooth.{/LI}
{LI}Each $m\in P$ must be in $[n/2,n]$ (say). In this case a positive answer also follows directly from the result of Balog and Wooley \cite{BaWo98} for infinitely many $n$. Proving this is true for all large $n$ does not follow immediately from \cite{BaWo98}, but can be deduced using a similar construction, as shown by SkyYang.

A stronger result can be deduced from the main result of Bober, Fretwell, Martin, and Wooley \cite{BFMW20}; as discussed in the comments, this shows that, for any $\epsilon>0$ and $k\geq 2$, there exists a constant $c<1$ (depending on $k$ and $\epsilon$) such that, for all large $n$, there exists a sequence of $k$ consecutive integers, all $n^\epsilon$-smooth, in $[n-n^{c},n]$.{/LI}
{/UL}

See also [370] and [928].

  He also points out that Theorem 2.1 in this paper (https://www.math.purdue.edu/~twooley/publ/20171004smoothpoly.pdf) of Bober, Fretwell, Martin, and Wooley (which itself is a generalisation of the [BaWo98] argument) is another way to settle this problem in the affirmative, and in fact proves something stronger.
  
  Namely, that theorem states that if $f(t)$ is a product of $k$ linear factors then there are polynomials $g$ of arbitrarily large degree $d$ such that $f(g(t))$ factors as a product of polynomials of degree $\ll d/(\log\log d)^{1/k}$. In particular, for any $\epsilon>0$, there exists a polynomial $g$ of degree $d=O_{k,\epsilon}(1)$ such that all prime divisors of\[(g(n)+1)\cdots (g(n)+k)\]are at most $\lvert g(n)\rvert^{\epsilon}$. Taking $n$ large and close to $(N/a)^{1/d}$, where $a$ is the leading coefficient of $g$, one deduces that, for all large $N$, there is an interval of $k$ consecutive integers in\[[N-O(N^{1-1/d}),N]\]all of which are $N^\epsilon$-smooth.

## Local Proof Attempts
Nontrivial Variant Split (Balog-Wooley Framing):
The literal statement is trivial. The meaningful variants are:
1. Local smoothness variant:
 each term in the block is required to be m^epsilon-smooth (term-wise).
 This is positive by Balog-Wooley (1998): for any epsilon>0 and k>=2,
 infinitely many m have m+1,...,m+k all m^epsilon-smooth.
2. Near-top-window variant:
 require the block to lie near the top, e.g. inside [n/2,n].
 Balog-Wooley gives positivity for infinitely many scales, but the
 “all sufficiently large n” form is open.

Formal Proof Closure (As Written):
Fix \(\varepsilon>0\) and \(k\ge2\). Consider the consecutive block
\[
1,2,\dots,k.
\]
If \(n>k^{1/\varepsilon}\), then \(n^\varepsilon>k\). For each \(m\in\{1,\dots,k\}\),
every prime divisor of \(m\) is at most \(m\le k<n^\varepsilon\), so \(m\) is
\(n^\varepsilon\)-smooth. Thus for all sufficiently large \(n\), this fixed
block is a valid run of \(k\) consecutive \(n^\varepsilon\)-smooth integers in
\(\{1,\dots,n\}\).
Therefore EP-369 is resolved affirmatively as written.
Only corrected variants (local \(m^\varepsilon\)-smoothness, top-window
placement, etc.) remain genuinely nontrivial.

Deeper Proof Program for Corrected Variants (A => B => C):
Scope:
The original statement is solved. The real work is on corrected forms:
1. Local variant: \(k\) consecutive \(m^\varepsilon\)-smooth integers.
2. Near-top variant: a run of \(k\) consecutive \(N^\varepsilon\)-smooth integers inside \([N/2,N]\) (or comparable top window).
A. Concrete Blocking Lemma (Most Critical):
For fixed \(\varepsilon\in(0,1)\) and \(k\ge 2\), prove a quantitative lower bound of the form
\[
\#\{m\le x:\ m,m+1,\dots,m+k-1\ \text{are all}\ m^\varepsilon\text{-smooth}\}\ge x^{\eta(\varepsilon,k)}
\]
for some \(\eta(\varepsilon,k)>0\).
This would already force infinitely many local smooth runs and provide a platform for density/placement refinements.
B. Reduction Lemmas (with proofs):
Lemma B1 (as-written triviality threshold):
For fixed \(\varepsilon>0\), \(k\ge2\), if \(N>k^{1/\varepsilon}\), then \(1,\dots,k\) are all \(N^\varepsilon\)-smooth.
Proof.
For \(m\le k\), each prime dividing \(m\) is at most \(m\le k<N^\varepsilon\). Hence every \(m\in\{1,\dots,k\}\) is \(N^\varepsilon\)-smooth. \(\square\)
Lemma B2 (local variant strictly stronger than as-written variant):
If there are infinitely many \(m\) such that \(m,\dots,m+k-1\) are all \(m^\varepsilon\)-smooth, then for infinitely many \(N\) there exists a run of \(k\) consecutive \(N^\varepsilon\)-smooth integers in \([1,N]\).
Proof.
Take \(N=m+k-1\). Then each \(m+j\le N\) and, since \(\varepsilon>0\), \(m^\varepsilon\le N^\varepsilon\), so \(m,\dots,m+k-1\) are \(N^\varepsilon\)-smooth. \(\square\)
Lemma B3 (top-window implication):
If for all sufficiently large \(N\) there is \(m\in[N/2,N]\) such that \(m,\dots,m+k-1\) are all \(m^\varepsilon\)-smooth, then for all sufficiently large \(N\) there is such a run in \([N/2,N+k]\) with \(N^\varepsilon\)-smoothness.
Proof.
For \(m\in[N/2,N]\), one has \(m^\varepsilon\le N^\varepsilon\). Therefore any local \(m^\varepsilon\)-smooth run is also \(N^\varepsilon\)-smooth and remains in \([N/2,N+k]\). \(\square\)
C. Main unresolved point:
The hardest step is obtaining uniform quantitative abundance of short smooth runs (local variant) with exponents strong enough to control window location (near-top form). The literature gives infinitude mechanisms, but boundary-uniform placement remains open.
