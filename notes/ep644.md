# EP-644

## Problem Statement
Let $f(k,r)$ be minimal such that if $A_1,A_2,\ldots$ is a family of sets, all of size $k$, such that for every collection of $r$ of the $A_is$ there is some pair $\{x,y\}$ which intersects all of the $A_j$, then there is some set of size $f(k,r)$ which intersects all of the sets $A_i$. Is it true that\[f(k,7)=(1+o(1))\frac{3}{4}k?\]Is it true that for any $r\geq 3$ there exists some constant $c_r$ such that\[f(k,r)=(1+o(1))c_rk?\]

## Site Remarks
A problem of Erd\H{o}s, Fon-Der-Flaass, Kostochka, and Tuza \cite{EFKT92}, who proved that $f(k,3)=2k$ and $f(k,4)=\lfloor 3k/2\rfloor$ and $f(k,5)=\lfloor 5k/4\rfloor$, and further that $f(k,6)=k$.

## Site References

  For small fixed $r$, the functions $f(k,r)$ align with these following linear forms in $k$ that already appear in the OEIS:
  
  $f(k,3)=2k$ -> [A005843](https://oeis.org/A005843) (even numbers).
  
  $f(k,4)=\lfloor 3k/2 \rfloor$ ->[A032766](https://oeis.org/A032766) (numbers congruent to 0 or 1 mod 3, equivalently $\lfloor 3n/2\rfloor$).
  
  $f(k,5)=\lfloor 5k/4 \rfloor$ -> [A032769](https://oeis.org/A032769), essentially $\lfloor 5n/4\rfloor$ up to a periodic shift, so this is not a word for word match but I think a close match.
  
  $f(k,6)=k$ -> [A000027](https://oeis.org/A000027).
  
  These are possible connections rather than exact formulations of the extremal problem. I do think besides $r=5$ they could be exact (up to indexing). For $r=7$ and beyond, the conjectured asymptotic $(3/4+o(1))k$ does not yet appear to have a corresponding OEIS entry, or at least one that I could find.
  
  As a side note, from reading the OEIS links above it seems that the known values of $f(k,r)$ align with simple rational multiples of $k$ could suggest the general constants $c_r$ are rational and arise from clean modular set constructions.
