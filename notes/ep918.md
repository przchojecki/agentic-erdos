# EP-918

## Problem Statement
Is there a graph with $\aleph_2$ vertices and chromatic number $\aleph_2$ such that every subgraph on $\aleph_1$ vertices has chromatic number $\leq\aleph_0$?

Is there a graph with $\aleph_{\omega+1}$ vertices and chromatic number $\aleph_1$ such that every subgraph on $\aleph_\omega$ vertices has chromatic number $\leq\aleph_0$?

## Site Remarks
A question of Erd\H{o}s and Hajnal \cite{ErHa68b}, who proved that for every finite $k$ there is a graph with chromatic number $\aleph_1$ where each subgraph on less than $\aleph_k$ vertices has chromatic number $\leq \aleph_0$.

In \cite{Er69b} it is asked with chromatic number $=\aleph_0$, but in the comments louisd observes this is (assuming subgraph and not induced subgraph was intended) trivially impossible, and hence presumably the problem was intended as written here (which is how it is posed in \cite{ErHa68b}).

- 14:56 on 24 Oct 2025 - Salvatore Mercuri (reply depth 3):
  Even if “induced subgraph” is intended then a similar argument for a negative answer was discovered by AlphaProof as follows. Assume $(V, E)$ is such a graph. If $V’\subseteq V$ is any subset of vertices of size $\aleph_1$, then it has a coloring $c$ on $\aleph_0$ colors. By a pigeonhole principle argument, there’s a fiber $V_y = \{v \in V’ | c(v) = y\}$ of $c$ size $\aleph_1$. The induced subgraph $G[V_y]$ then has chromatic number $1$, but by assumption it has chromatic number $\aleph_0$. So indeed I think it must be $\leq\aleph_0$ in the statement.

## Local Computation
- Used finite proxy searches for global/local chromatic separation:
 - look for finite graphs that are globally not $k$-colorable,
 - while all medium-size induced subgraphs are $\ell$-colorable.
- Added one exhaustive regime (n=18, m=9) checking all $\binom{18}{9}$ subgraphs per trial, and one larger random-sampling regime (n=28, m=16).

- No finite proxy witnesses were found in these deep runs.
- In particular, the exhaustive proxy on n=18,m=9 found essentially no graphs forcing global chromatic jump beyond 4 under the tested densities, and none satisfying the full separation condition.
- This negative finite signal aligns with the intuition that strong global/local chromatic separation is delicate and structurally constrained.

## Local Proof Attempts
The finite proxy search tries to imitate the desired global/local chromatic separation with ordinary finite graphs. It found no convincing witnesses even in regimes with exhaustive medium-subgraph checks, which is negative evidence for naive constructions, but it does not address the actual infinite-cardinal problem.
