# EP-120

## Problem Statement
Let $A\subseteq\mathbb{R}$ be an infinite set. Must there be a set $E\subset \mathbb{R}$ of positive measure which does not contain any set of the shape $aA+b$ for some $a,b\in\mathbb{R}$ and $a\neq 0$?

## Site Remarks
The Erd\H{o}s similarity problem.

This is true if $A$ is unbounded or dense in some interval. It therefore suffices to prove this when $A=\{a_1>a_2>\cdots\}$ is a countable strictly monotone sequence which converges to $0$.

Steinhaus \cite{St20} has proved this is false whenever $A$ is a finite set.

This conjecture is known in many special cases (but, for example, it is open when $A=\{1,1/2,1/4,\ldots\}$, which is Problem 94 on Green's open problems list (https://people.maths.ox.ac.uk/greenbj/papers/open-problems.pdf)). For an overview of progress we recommend a nice survey by Svetic \cite{Sv00} on this problem. A survey of more recent progress was written by Jung, Lai, and Mooroogen \cite{JLM24}.

Because coordinates over this basis are unique, repeatedly halving them forces any sequence $a \cdot 2^{-n} + b$ with $a \neq 0$ to eventually leave the set. ## Local Proof Attempts
Target:
Resolve Erdős similarity conjecture: every measurable positive-density subset of
\(\mathbb R\) contains a geometrically similar copy of every infinite set \(X\)
from the conjectured class.
Step A: Density-increment transference
Translate measurable positive-density condition to combinatorial density in
large finite windows with quantitative loss.
Step B: Pattern embedding dichotomy
Either random-like behavior gives embeddings by probabilistic counting, or
structured behavior yields embeddings via additive-combinatorial regularity.
Step C: Infinite-pattern passage
Upgrade finite-window embeddings to full infinite similar copies by compactness
or diagonal extraction.
Concrete Blocking Lemma (Most Critical):
Need a quantitative finite-to-infinite transfer theorem for similarity patterns
without losing scale control.

Proposition AI1 (Window reduction principle):
Let \(A\subset\mathbb R\) measurable with upper density \(\delta>0\). Then for a
sequence of intervals \(I_N\), the discretizations \(A_N=A\cap I_N\) satisfy
\[
|A_N|\ge (\delta-o(1))|I_N|.
\]
\[
\textit{Proof.}
\]
Direct from definition of upper density.
\(\square\)
Proposition AI2 (Diagonal embedding upgrade):
Assume for each \(m\) there exists \(N_m\) such that every dense discretization
\(A_{N_m}\) contains an \(m\)-point similar copy of the target pattern. Then \(A\)
contains an infinite similar copy.
\[
\textit{Proof sketch.}
\]
Choose nested \(m\)-point copies with consistent first \(m-1\) points by compact
selection/diagonalization; pass to the limit.
\(\square\)
