# EP-1119

## Problem Statement
Let $\mathfrak{m}$ be an infinite cardinal with $\aleph_0<\mathfrak{m}<\mathfrak{c}=2^{\aleph_0}$. Let $\{f_\alpha\}$ be a family of entire functions such that, for every $z_0\in \mathbb{C}$, there are at most $\mathfrak{m}$ distinct values of $f_\alpha(z_0)$. Must $\{f_\alpha\}$ have cardinality at most $\mathfrak{m}$?

## Site Remarks
This is Problem 2.46 in \cite{Ha74}, where it is attributed to Erd\H{o}s.

Erd\H{o}s \cite{Er64g} proved (answering a question of Wetzel) that if there are only countably many distinct values for each $f_\alpha(z_0)$ then, if $\mathfrak{c}>\aleph_1$, the family $\{f_\alpha\}$ is itself countable, and also showed this is false if $\mathfrak{c}=\aleph_1$.

In \cite{Ha74} it is written that it is 'easy to see' the answer is yes if $\mathfrak{m}^+<\mathfrak{c}$, and also that it is possible that the question is undecidable.

Indeed, it has been shown that this is undecidable if $\mathfrak{m}^+=\mathfrak{c}$: Kumar and Shelah \cite{KuSh17} have shown that there is a model in which $\mathfrak{c}=\aleph_2$ such that the answer is yes (with $\mathfrak{m}=\aleph_1$), while Schilhan and Weinert \cite{ScWe24} have shown the answer can be no, in a different model with $\mathfrak{c}=\aleph_2$.

  For the maximal case $\mathfrak{m}^+ = \mathfrak{c}$, Theorem 2.1 of Kumar and Shelah's On a question about families of entire functions (2017) (https://shelah.logic.at/files/178945/1078.pdf) establishes that within the Cohen real model obtained by adding $\aleph_2$ Cohen reals to the constructible universe $L$ (so $\mathfrak{c} = \aleph_2$ there), every continuum-sized family of entire functions takes $\mathfrak{c}$ distinct values at some point $z$. Consequently, by the contrapositive, any family that takes at most $\mathfrak{m}$ distinct values at every point cannot be continuum-sized (as the theorem would require it to have $\mathfrak{c}$ values at some point); it must have cardinality $\leq \mathfrak{m}$. Therefore, the answer to Problem 1119 is "YES" for the maximal case $\mathfrak{m} = \aleph_1$ in this model. The authors note in Question 4.1 that a model where the answer is "NO" for the maximal case (e.g., $\mathfrak{c} = \aleph_2$) was an open question.
  
  However, Schilhan and Weinert in Wetzel families and the continuum (2024) (https://arxiv.org/abs/2310.19473) answered this open question asked by Kumar and Shelah, proving the answer can be "NO" in a different model where $\mathfrak{c}=\aleph_2$​.
  
  This resolves the problem completely: the answer is known to be "YES" for $\mathfrak{m}^+ < \mathfrak{c}$ and undecidable for $\mathfrak{m}^+ = \mathfrak{c}$.
  
  Also in the problem statement, $m$ should be replaced with $\mathfrak{m}$.
