# EP-168

## Problem Statement
Let $F(N)$ be the size of the largest subset of $\{1,\ldots,N\}$ which does not contain any set of the form $\{n,2n,3n\}$. What is\[ \lim_{N\to \infty}\frac{F(N)}{N}?\]Is this limit irrational?

## Site Remarks
This limit was proved to exist by Graham, Spencer, and Witsenhausen \cite{GSW77}, who showed it is equal to\[\frac{1}{3}\sum_{k\in K}\frac{1}{d_k},\]where $d_1<d_2<\cdots $are the $3$-smooth numbers and $K$ is the set of $k$ for which $f(k)>f(k-1)$, where $f$ counts the largest subset of $\{d_1,\ldots,d_k\}$ that avoids $\{n,2n,3n\}$.

Similar questions can be asked for the density or upper density of infinite sets without such configurations.

The limit can be estimated by elementary arguments (see the comments). Eberhard has used the formula of \cite{GSW77} mentioned above to calculate the value of the limit as\[0.800965\cdots.\]

## Site References
- [GSW77] Graham, R. and Spencer, J. and Witsenhausen, H., On Extremal Density Theorems for Linear Forms. Number Theory and Algebra (1977).

- 17:05 on 05 Sep 2025 - StijnC:
  The following elementary bounds can be proven easily:
  
  $$\frac 45 \le \lim_{ N \to \infty} \frac{F(n)}{N} \le \frac 56$$
  
  Take the complement of the integers in
  $$C=\cup_{i=1}^{\infty} ]N/6^i, 2N/6^i]$$
  then every set of the form $\{n,2n,3n\}$ where $1\le n \le \frac N3$ has exactly one element in $C$, since $2N/6^i<n<3n \le N/6^{i-1}$ is impossible (which would be the only way to avoid the elements in $C$).
  
  In the other direction, as an improvement on the upper bound;
  the sets $\{n,2n,3n\}$ for n in $B=\cup_{i=1}^{\infty} ]N/6^i, 2N/6^i]  \setminus \left( \cup_{i=1}^{\infty} ]N/6^i, 4N/(3*6^i)] \cap 2\mathbb Z \right)$ are disjoint.
  
  If two sets intersect, $\{n,2n,3n\} \cap \{n',2n',3n'\} \not= \emptyset$ for $n,n' \in B$, then $n,n' \in ]N/6^i, 2N/6^i]$ for some $i$ and $3n=2n'$, so $n$ is even and bounded by $2/3*2N/6^i.$
  So this could not happen, so we had approximately $N/6$ disjoint triples.

## Local Computation
I solved the exact finite optimization for small N as a 3-uniform independent
set problem on edges {n,2n,3n} with branch-and-bound plus propagation.

Exact values for 20 <= N <= 75 (step 5):
- Most sampled points gave exact ratio F(N)/N = 0.8.
- One sample (N=50) gave 41/50 = 0.82.

## Local Proof Attempts
Hard point:
This finite exact frontier is consistent with a stable density near 0.8,
but it does not determine the true limit or address irrationality.

Target:
Determine
\[
\lim_{N\to\infty}\frac{F(N)}{N}
\]
for sets avoiding \(\{n,2n,3n\}\), and decide rationality/irrationality.
Step A: Multiplicative-chain decomposition
Partition \(\mathbb N\) into chains \(m\cdot\{1,2,4,\dots\}\) and coupled
\((1,2,3)\)-constraints.
Step B: Periodic optimization on truncated systems
Solve finite-state density optimization for chain-coupled constraints and prove
subadditivity/superadditivity.
Step C: Limit identification
Extract limit density via ergodic/subadditive convergence and analyze algebraic
equation defining optimizer to test irrationality.
Concrete Blocking Lemma (Most Critical):
Need a transfer theorem from finite periodic optimizers to global integer
density with quantified boundary error.

Proposition BL1 (Subadditive envelope):
If \(F(N)\) is maximum feasible size under local forbidden triples, then
\[
F(N+M)\le F(N)+F(M)+O(1).
\]
\[
\textit{Proof sketch.}
\]
Concatenate optimal blocks with bounded interface correction for triples crossing
the join.
\(\square\)
Proposition BL2 (Limit existence reduction):
If BL1 and a matching superadditive lower envelope hold up to \(O(1)\), then
\[
\lim_{N\to\infty}\frac{F(N)}{N}
\]
exists (Fekete-type argument with bounded defects).
\[
\textit{Proof.}
\]
Apply generalized subadditive convergence theorem.
\(\square\)
