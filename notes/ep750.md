# EP-750

## Problem Statement
Let $f(m)$ be some function such that $f(m)\to \infty$ as $m\to \infty$. Does there exist a graph $G$ of infinite chromatic number such that every subgraph on $m$ vertices contains an independent set of size at least $\frac{m}{2}-f(m)$?

## Site Remarks
In \cite{Er69b} Erd\H{o}s conjectures this for $f(m)=\epsilon m$ for any fixed $\epsilon>0$. This follows from a result of Erd\H{o}s, Hajnal, and Szemer\'{e}di \cite{EHS82}, as described by msellke in the comments.

In \cite{ErHa67b} Erd\H{o}s and Hajnal prove this for $f(m)\geq cm$ for all $c>1/4$.

See also [75].

## Local Computation
- Built finite proxy tests on a high-chromatic triangle-free family (Mycielski level \(n=23\)).
- Sampled induced \(m\)-vertex subgraphs and measured deficit
\[
\Delta(m)=\frac m2-\alpha(H).
\]

- For sampled \(m=8,10,12,14,16\), worst observed deficits were small (0,1,1,1,2).
- Normalized deficits stayed modest (e.g. worst \(\Delta/\sqrt m\le 0.5\) in this range).
- This finite proxy is compatible with slowly growing defect, but does not address infinite-chromatic existence directly.

## Local Proof Attempts
The current evidence comes from a finite proxy inside a canonical high-chromatic triangle-free family, where one measures how far induced subgraphs fall below the trivial \(m/2\) independence threshold. The observed deficits stay small on the tested range, which is compatible with slowly growing \(f(m)\), but this does not produce an infinite-chromatic construction or settle the general existence question.
