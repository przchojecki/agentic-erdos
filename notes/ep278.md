# EP-278

## Problem Statement
Let $A=\{n_1<\cdots<n_r\}$ be a finite set of positive integers. What is the maximum density of integers covered by a suitable choice of congruences $a_i\pmod{n_i}$?

Is the minimum density achieved when all the $a_i$ are equal?

## Site Remarks
Simpson \cite{Si86} has observed that the density of integers covered is at least\[\sum_i \frac{1}{n_i}-\sum_{i<j}\frac{1}{[n_i,n_j]}+\sum_{i<j<k}\frac{1}{[n_i,n_j,n_k]}-\cdot\](where $[\cdots]$ denotes the least common multiple) which is achieved when all $a_i$ are equal, settling the second question.

## Site References

## Local Computation
For the structured family \(A=\{3\}\cup\{3p:p\in P\}\), full brute-force residue search was checked against the partition formula for \(P=\{5,7\}\), \(\{5,7,11\}\), and \(\{5,7,11,13\}\).
In each case the exact covered density agreed with
\[
1-\frac13\left(\prod_{p\in P_1}\Bigl(1-\frac1p\Bigr)+\prod_{p\in P_2}\Bigl(1-\frac1p\Bigr)\right),
\]
confirming the reduction on these finite test families.

## Local Proof Attempts
The background states that Simpson proved in 1986 that the minimum covered density is achieved when all residues \(a_i\) are equal, so the second subquestion is already settled.

For the first subquestion, the note gives a structured-family reduction. If
\[
A=\{3\}\cup\{3p:p\in P\}
\]
with distinct odd primes \(P\), then optimization of the covered density reduces to a partition problem. After translating so that \(a_0\equiv 0\pmod 3\), each residue class modulo \(3p\) is best placed in residue \(1\) or \(2\) modulo \(3\); choosing residue \(0\pmod 3\) is never helpful because it lies inside the already-covered class \(0\pmod 3\).

If \(P=P_1\sqcup P_2\) according to that choice, then the covered density is
\[
1-\frac13\left(\prod_{p\in P_1}\Bigl(1-\frac1p\Bigr)+\prod_{p\in P_2}\Bigl(1-\frac1p\Bigr)\right).
\]
So maximizing coverage is equivalent to minimizing
\[
\prod_{p\in P_1}\Bigl(1-\frac1p\Bigr)+\prod_{p\in P_2}\Bigl(1-\frac1p\Bigr).
\]
This gives an exact finite optimization for that family and exposes a direct partition structure in the first question.

The first question for arbitrary modulus sets \(A\) remains open.

Step B: Convex or extremal reduction

Lemma 1 (Density of union via one-period counting):
For finitely many congruence classes \(C_i\) modulo \(m_i\), define \(M=\mathrm{lcm}(m_i)\). Then the asymptotic density of \(\bigcup_i C_i\) equals
\[
\frac{1}{M}\#\Bigl(\bigcup_i C_i \cap [1,M]\Bigr).
\]
\[
\textit{Proof.}
\]
Each \(C_i\) is \(M\)-periodic, hence the union is \(M\)-periodic. Density of an \(M\)-periodic set is exactly period occupancy divided by \(M\).
\(\square\)
Lemma 2 (Structured family formula):
For \(A=\{3\}\cup\{3p:p\in P\}\), with \(a_0\equiv0\pmod3\), and partition \(P=P_1\sqcup P_2\) according to residues \(1\) or \(2\) modulo \(3\), the covered density is
\[
1-\frac13\left(\prod_{p\in P_1}\Bigl(1-\frac1p\Bigr)+
\prod_{p\in P_2}\Bigl(1-\frac1p\Bigr)\right).
\]
\[
\textit{Proof.}
\]
Numbers not covered must avoid the class \(0\pmod3\), so lie in residues \(1\pmod3\) or \(2\pmod3\). In residue \(1\pmod3\), the uncovered condition is simultaneously avoiding one class modulo each \(p\in P_1\), giving factor \(\prod_{p\in P_1}(1-1/p)\) by CRT independence. Similarly for residue \(2\pmod3\) with \(P_2\). Average over the two branches of density \(1/3\).
\(\square\)
Lemma 3 (Optimization reduction):
In the above family, maximizing coverage is equivalent to minimizing
\[
\Phi(P_1,P_2):=
\prod_{p\in P_1}\Bigl(1-\frac1p\Bigr)+
\prod_{p\in P_2}\Bigl(1-\frac1p\Bigr).
\]
\[
\textit{Proof.}
\]
Immediate from Lemma 2: covered density is \(1-\frac13\Phi\), affine-decreasing in \(\Phi\).
\(\square\)
