# EP-936

## Problem Statement
Are\[2^n\pm 1\]and\[n!\pm 1\]powerful (i.e. if $p\mid m$ then $p^2\mid m$) for only finitely many $n$?

## Site Remarks
Cushing and Pascoe \cite{CuPa16} have shown the answer to the second question is yes assuming the abc conjecture - in fact, for any fixed $k\geq 0$, there are only finitely many $n$ and powerful $x$ such that $\lvert x-n!\rvert \leq k$.

CrowdMath \cite{Cr20} has shown that the answer to the first question is yes, again assuming the abc conjecture.

## Local Computation
- Method: exact BigInt factorization (Miller-Rabin + Pollard Rho), then direct test that every prime exponent is at least \(2\).
- Run ranges: \(2\le n\le 110\) for \(2^n\pm1\), and \(3\le n\le 36\) for \(n!\pm1\); runtime \(\approx 42.87\)s.
- Powerful hits found:
 - \(2^n\pm1\): only \(2^3+1=9=3^2\).
 - \(n!\pm1\): only \(4!+1=25=5^2\), \(5!+1=121=11^2\), \(7!+1=5041=71^2\).
- No unresolved factorizations in this run.

At this depth, there are no new powerful values beyond the known tiny examples. This supports extreme sparsity, but does not by itself prove finiteness.

## Local Proof Attempts
Only the tiny known examples appear in the scanned range, namely \(2^3+1=9\) and \(4!+1=25\), \(5!+1=121\), \(7!+1=5041\). This supports a finiteness heuristic, but the hard point is ruling out isolated large sporadic powerful values in either family.
