# EP-601

## Problem Statement
For which limit ordinals $\alpha$ is it true that if $G$ is a graph with vertex set $\alpha$ then $G$ must have either an infinite path or independent set on a set of vertices with order type $\alpha$?

## Site Remarks
A problem of Erd\H{o}s, Hajnal, and Milner \cite{EHM70}, who proved this is true for $\alpha < \omega_1^{\omega+2}$.

In \cite{Er82e} Erd\H{o}s offers \$250 for showing what happens when $\alpha=\omega_1^{\omega+2}$ and \$500 for settling the general case.

Larson \cite{La90} proved this is true for all $\alpha<2^{\aleph_0}$ assuming Martin's axiom (https://en.wikipedia.org/wiki/Martin%27s_axiom).

 - estimate lower bounds for longest path ratio and independence ratio,
 - track \(\min\) sampled value of \(\max(\text{path ratio},\text{independence ratio})\).

- Across tested densities, sampled \(\max(\text{path ratio},\text{independence ratio})\) remains strongly bounded away from \(0\), often close to \(1\) due to long paths.
