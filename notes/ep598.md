# EP-598

## Problem Statement
Let $m$ be an infinite cardinal and $\kappa$ be the successor cardinal of $2^{\aleph_0}$. Can one colour the countable subsets of $m$ using $\kappa$ many colours so that every $X\subseteq m$ with $\lvert X\rvert=\kappa$ contains subsets of all possible colours?

- 02:30 on 15 Mar 2026 - Zeraoulia Rafik:
  I think the statement is true in the special case \(m=\kappa=(2^{\aleph_0})^+\).
  
  Indeed, let\[
  E^\kappa_\omega=\{\delta<\kappa:\operatorname{cf}(\delta)=\omega\}.
  \]Since \(\kappa\) is a regular uncountable cardinal, \(E^\kappa_\omega\) is stationary in \(\kappa\). Also, a stationary subset of a regular uncountable cardinal can be partitioned into \(\kappa\) many pairwise disjoint stationary sets. So fix a partition\[
  E^\kappa_\omega=\bigsqcup_{\xi<\kappa} S_\xi
  \]with each \(S_\xi\) stationary.
  
  Now define a colouring\[
  c:[\kappa]^{\aleph_0}\to\kappa
  \]by\[
  c(a)=\xi \iff \sup(a)\in S_\xi.
  \]Now let \(X\subseteq\kappa\) with \(|X|=\kappa\). Since \(\kappa\) is regular, \(X\) is unbounded in \(\kappa\). Hence the set of limit points of \(X\) is club in \(\kappa\). For any \(\xi<\kappa\), because \(S_\xi\) is stationary, there is some\[
  \delta\in S_\xi
  \]which is a limit point of \(X\). Since \(\operatorname{cf}(\delta)=\omega\), we can choose a countable subset \(a\subseteq X\cap\delta\) cofinal in \(\delta\). Then\[
  \sup(a)=\delta,
  \]so by definition of the colouring,\[
  c(a)=\xi.
  \]As \(\xi<\kappa\) was arbitrary, every \(X\in[\kappa]^\kappa\) contains countable subsets of all \(\kappa\) colours.
  
  Therefore the required property holds for \(m=\kappa=(2^{\aleph_0})^+\).
  
  Disclosure: the main idea of this argument, namely colouring a countable set by the stationary piece containing its supremum after partitioning \(E^\kappa_\omega\) into \(\kappa\) stationary sets, was suggested with the help of AI; I then wrote out the proof in this form.
