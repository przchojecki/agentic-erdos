# EP-727

## Problem Statement
Let $k\geq 2$. Does\[(n+k)!^2 \mid (2n)!\]for infinitely many $n$?

## Site Remarks
A conjecture of Erd\H{o}s, Graham, Ruzsa, and Straus \cite{EGRS75}. It is open even for $k=2$.

Balakran \cite{Ba29} proved this holds for $k=1$ - that is, $(n+1)^2\mid \binom{2n}{n}$ for infinitely many $n$. It is a classical fact that $(n+1)\mid \binom{2n}{n}$ for all $n$ (see Catalan numbers (https://en.wikipedia.org/wiki/Catalan_number)).

Erd\H{o}s, Graham, Ruzsa, and Straus observe that the method of Balakran can be further used to prove that there are infinitely many $n$ such that\[(n+k)!(n+1)! \mid (2n)!\](in fact this holds whenever $k<c \log n$ for some small constant $c>0$).

Erd\H{o}s \cite{Er68c} proved that if $a!b!\mid n!$ then $a+b\leq n+O(\log n)$.

  I've investigated a little whether the method in [728] can help here as well. It seems that it does allow you to handle up to moderately large primes, specifically if $n+1,\dots,n+k$ are $\exp(c \sqrt{\log n})$-smooth for some $c > 0$ it may work. Unfortunately, current techniques can only give consecutive integers that are roughly $n^\varepsilon$-smooth. Heuristically, one does expect the "$\exp(c \sqrt{\log n})$-smooth" to be true, but this seems far beyond current techniques. So probably [728] isn't helping all that much.

  The $k=2$ case is tantalizingly close to being within reach of current technology (in particular, the two-point logarithmically averaged Elliott and Chowla technology), which can provide a large number of $n$ with $n+1,n+2$ both somewhat smooth, which increases the odds of $(n+1)^2(n+2)^2$ dividing $\binom{2n}{n}$. Unfortunately the error terms in the current estimates are still somewhat weak (particularly in view of the relatively sparse nature of smooth numbers), and may not be enough to close this problem without additional effort.

## Local Computation
I used an exact prime-valuation recurrence scan (no floating approximations),
checking divisibility up to N=700000 for k=2..10.

Hit counts up to N=700000:
- k=2: 7803
- k=3: 631
- k=4: 45
- k=5: 3
- k=6..10: 0 in this range
So there is strong finite support for small k (especially k=2,3), but no
proof of infinitude yet.

## Local Proof Attempts
Hard point:
Finite hits, even many of them, do not imply infinitely many.
Need a structural or p-adic mechanism that produces infinitely many n for each
fixed k (or a disproof for some k).
