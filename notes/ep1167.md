# EP-1167

## Problem Statement
Let $r\geq 2$ be finite and $\lambda$ be an infinite cardinal. Let $\kappa_\alpha$ be cardinals for all $\alpha<\gamma$.

Is it true that\[2^\lambda \to (\kappa_\alpha+1)_{\alpha<\gamma}^{r+1}\]implies\[\lambda \to (\kappa_\alpha)_{\alpha<\gamma}^{r}?\]Here $+$ means cardinal addition, so that $\kappa_\alpha+1=\kappa_\alpha$ if $\kappa_\alpha$ is infinite.

  Thank you for the clarification and for pointing out the original conditions in the Erdős–Hajnal list.
  
  Even with the condition \(\gamma \ge 2\), however, a size obstruction can still occur:
  if some \(\kappa_\alpha > \lambda\), then the conclusion \(\lambda \to (\kappa_\alpha)^r_{\alpha<\gamma}\) would require a subset of \(\lambda\) of size \(\kappa_\alpha > \lambda\), which is impossible, while the hypothesis might still hold non-vacuously.
  
  Thus, to ensure the problem is nontrivial in ZFC, it seems necessary to also require \(\kappa_\alpha \le \lambda\) for all \(\alpha < \gamma\) (or at least for those \(\alpha\) that could correspond to the color of a large homogeneous set in the stepping-up coloring).
  
  In any case, the literal unrestricted statement — without any bound on \(\kappa_\alpha\) relative to \(\lambda\) — remains false, as my minimal counterexample shows. The intended formulation (with \(\gamma \ge 2\), \(r < \omega\), \(\kappa_\alpha > r\), and presumably \(\kappa_\alpha \le \lambda\)) is the interesting open problem.

- 18:40 on 31 Jan 2026 - Zeraoulia Rafik:
  I uploaded a short note pointing out that the \emph{literal} fully-quantified statement of Erdős--Hajnal--Rado Problem 1167 (as written in the book/problem list) is falsified by a simple size obstruction.
  
  If one allows some target $\kappa_\alpha>\lambda$, then the conclusion\[
  \lambda\to(\kappa_\alpha)^r_{\alpha<\gamma}
  \]is impossible, while the hypothesis can still hold. In fact, taking $\gamma=1$ and $\kappa_0=\lambda^+$, the premise\[
  2^\lambda\to(\kappa_0+1)^{r+1}_{<1}
  \]is automatic (a coloring into $<1$ colors is vacuous; equivalently it just requires $2^\lambda\ge \kappa_0+1$), but the conclusion would require a subset of $\lambda$ of size $\lambda^+$, contradiction.
  
  This suggests the intended nontrivial formulation should explicitly assume $\kappa_\alpha\le\lambda$ for all $\alpha<\gamma$; under this restriction the general heterogeneous implication still seems open (beyond the classical uniform stepping-up/stepping-down consequences for $r\ge3$).
  
  Any references, known partial results, or corrections to the intended statement of \#1167 would be very welcome.
