# EP-1022

## Problem Statement
Is there a constant $c_t$, where $c_t\to \infty$ as $t\to \infty$, such that if $\mathcal{F}$ is a finite family of finite sets, all of size at least $t$, and for every set $X$ there are $<c_t\lvert X\rvert$ many $A\in \mathcal{F}$ with $A\subseteq X$, then $\mathcal{F}$ has chromatic number $2$ (in other words, has property B)?

## Site Remarks
Erd\H{o}s originally conjectured, in this language, that $c_2=1$, which he reports in \cite{Er71} was proved by Lov\'{a}sz. He seems to refer to \cite{Lo68} for this, which does not contain this result, so presumably this is a miscitation and perhaps Lovasz reported the easy proof that $c_2=1$ (see e.g. the comment by Tao below) directly to Erd\H{o}s.

The condition on $c_t$ is a weaker form of the condition that the hypergraph is degenerate: a hypergraph is $d$-degenerate if every subhypergraph has a vertex contained in at most $d$ edges, which implies that for any $X$ there are at most $d\lvert X\rvert$ many edges contained in $X$.

This is false, and $c_t<2$ for all $t$: a counterexample is provided by Wood \cite{Wo13b}, who constructs, for any $r\geq 2$, a triangle-free $2$-degenerate $r$-uniform hypergraph with chromatic number $3$. A similar counterexample was found independently by KoishiChan in the comments.

- 05:13 on 04 Dec 2025 - KoishiChan:
  This problem seems to admit a trivial counterexample showing that $c_t < 2$ for every $t$. I use $F$ as the hypergraph, since $\mathcal{F}$ does not render on many computers.
  
  Let $\Gamma$ be a vertex set of size $3t$. For each pair of subsets $A, B \subset \Gamma$ of size $t$, add a new vertex $v_{A, B}$ and sets $A \cup \{v_{A, B}\}$ and $B \cup \{v_{A, B}\}$ to $F$. Let $V$ denote the set of $v_{A, B}$'s. Furthermore, for any $t$ element subset $Q$ of $\Gamma$ and $t$ element subset $R$ of $V$, add a new vertex $w_{Q, R}$ and sets $Q \cup \{w_{Q, R}\}$ and $R \cup \{w_{Q, R}\}$ to $F$. Thus, $X$ consists of $\Gamma$, $V$, and the vertices $w_{Q, R}$.
  
  Clearly, $F$ is $(t + 1)$-uniform. We now claim that $F$ cannot be two-chromatic. Suppose the contrary and study a blue-red-coloring of $F$. If $\Gamma$ has $t$ red vertices $A$ and $t$ blue vertices $B$, then at least one of $A \cup \{v_{A, B}\}$ and $B \cup \{v_{A, B}\}$ is monochromatic, contradiction. Otherwise, $\Gamma$ contains at least $2t$ vertices of the same color, say red. Let $Q$ denote these red vertices. For any partition $Q = A \sqcup B$ into two sets of size $t$, $v_{A, B}$ must be blue. Hence $V$ contains at least $\binom{2t}{t} \geq t$ blue vertices. Letting $R$ be any $t$ blue vertices in $V$, at least one of $Q \cup \{w_{Q, R}\}$ and $R \cup \{w_{Q, R}\}$ must be monochromatic, contradiction.
  
  Finally, there exists a $2$-to-$1$ matching from $F$ to $X$: let $\phi: F\to X$ map $A \cup \{v_{A, B}\}$ and $B \cup \{v_{A, B}\}$ to $v_{A, B}$, and $Q \cup \{w_{Q, R}\}$ and $R \cup \{w_{Q, R}\}$ to $w_{Q, R}$. Then each vertex of $X$ has at most $2$ pre-images. For each $Y \subset X$, we have
  $$\{S \in F: S \subset Y\} \subset \phi^{-1}(Y)$$
  thus $|\{S \in F: S \subset Y\}| \leq | \phi^{-1}(Y)| \leq 2|Y|$, as desired.

Firstly, the example of an $n$-cycle for large odd $n$, which is not $2$-colorable but has at most $k$ edges in any $k$-element subset, shows that $c_2$ cannot exceed $1$.    ∃ (c : α → Bool), ∀ A ∈ F, ∃ x y, x ∈ A ∧ y ∈ A ∧ c x ≠ c y

## Local Computation
I ran random search over non-property-B 3-uniform families on 9 vertices and measured
rho=max_X e(X)/|X|.
Best found non-property-B family had rho ~ 1.222.

This is finite lower-bound evidence on thresholds for small instances, not an
asymptotic determination of c_t.

## Local Proof Attempts
Exact threshold reformulation:
For a \(t\)-uniform hypergraph \(H=(V,E)\), define
\[
\rho(H):=\max_{\varnothing\ne X\subseteq V}\frac{e_H(X)}{|X|},
\]
where \(e_H(X)=\#\{A\in E:\ A\subseteq X\}\).
Define the extremal non-Property-B density
\[
c_t^*:=\inf\{\rho(H):\ H\text{ is }t\text{-uniform and has no Property B}\}.
\]
Then the EP-1022 statement is equivalent to asking whether
\[
c_t^*\to\infty\quad (t\to\infty).
\]
Reason:
- If \(c<c_t^*\), every \(t\)-uniform \(H\) with \(\rho(H)<c\) must have Property B.
- Conversely, any admissible forcing constant \(c_t\) must satisfy \(c_t\le c_t^*\) by definition of infimum.
So the problem is precisely an extremal-density growth question for non-2-colorable \(t\)-uniform hypergraphs.

Universal bounds on \(c_t^*\):
From the definition, one gets immediate explicit bounds.
Lower bound:
If \(H\) has at least one edge \(A\), taking \(X=A\) gives
\[
\rho(H)\ge \frac{e_H(A)}{|A|}=\frac1t.
\]
Hence
\[
c_t^*\ge \frac1t.
\]
Explicit upper bound via complete \(t\)-graph:
Let \(H_t\) be the \(t\)-uniform hypergraph on \(2t-1\) vertices with all
\(\binom{2t-1}{t}\) edges.
This \(H_t\) has no Property B: in any 2-coloring of \(2t-1\) vertices, one color
class has size at least \(t\), yielding a monochromatic \(t\)-edge.
For \(X=V(H_t)\),
\[
\rho(H_t)\ge \frac{|E(H_t)|}{|V(H_t)|}
\;=\;
\frac{\binom{2t-1}{t}}{2t-1}.
\]
Therefore
\[
c_t^*\le \rho(H_t)\le \frac{\binom{2t-1}{t}}{2t-1}.
\]
So currently we have
\[
\frac1t \le c_t^* \le \frac{\binom{2t-1}{t}}{2t-1},
\]
and EP-1022 asks whether \(c_t^*\to\infty\).

Target:
Show \(c_t^*\to\infty\), i.e. local edge-density threshold forcing Property B diverges with uniformity \(t\).
A. Concrete Blocking Lemma (Most Critical):
Prove a container-style statement: every \(t\)-uniform hypergraph with \(\rho(H)\le C\) (fixed \(C\)) admits a small family of sparse containers each 2-colorable when \(t\) is large enough.
B. Reduction Lemmas (with proofs):
Lemma B1 (forcing-threshold equivalence):
\[
c_t^*=\inf\{\rho(H): H\ \text{non-Property-B}\}
\]
is the sharp local-density forcing threshold.
Proof.
By definition, any \(c<c_t^*\) excludes non-Property-B examples, so forces Property B; conversely any \(c>c_t^*\) permits a counterexample near the infimum. \(\square\)
Lemma B2 (monotone inheritance):
If \(H'\subseteq H\), then \(\rho(H')\le \rho(H)\). Therefore sparse forbidden cores are the only obstructions.
Proof.
For each \(X\), \(e_{H'}(X)\le e_H(X)\); maximize over \(X\). \(\square\)
Lemma B3 (A implies divergence):
If A holds for every fixed \(C\) once \(t\) is large, then no non-Property-B hypergraph can satisfy \(\rho\le C\), so \(c_t^*>C\) eventually; since \(C\) is arbitrary, \(c_t^*\to\infty\).
Proof.
Direct quantifier unwinding. \(\square\)
C. Main unresolved point:
The bottleneck is proving that bounded local density alone (without additional pseudorandomness) controls global 2-colorability for large uniformity.
