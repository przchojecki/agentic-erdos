# EP-893

## Problem Statement
If $\tau(n)$ counts the divisors of $n$ then let\[f(n)=\sum_{1\leq k\leq n}\tau(2^k-1).\]Does $f(2n)/f(n)$ tend to a limit?

## Site Remarks
Erd\H{o}s \cite{Er98} says that 'probably there is no simple asymptotic formula for $f(n)$ since $f(n)$ increases too fast'.

Kova\v{c} and Luca \cite{KoLu25} (building on a heuristic independently found by Cambie (personal communication)) have shown that there is no finite limit, in that\[\limsup_{n\to \infty}\frac{f(2n)}{f(n)}=\infty,\]and provide both theoretical and numerical evidence that suggests $\lim \frac{f(2n)}{f(n)}=\infty$.

## Local Computation
- Ran exact finite-prefix computation using explicit factorization-by-trial-division for $\tau(2^k-1)$ up to $k\le 48$.
- Computed exact prefix sums $f(n)$ and ratio profile $f(2n)/f(n)$ for all $2\le n\le 24$.

- In tested range, ratio spans from $3$ up to about $8.08148$.
- Peak in this run appears at $n=18$.
- The finite data is consistent with highly non-stationary behavior and with an unbounded-limsup heuristic.

## Local Proof Attempts
The exact prefix computation makes the ratio \(f(2n)/f(n)\) fully explicit on a moderate range and shows that it fluctuates strongly rather than stabilizing. That aligns with the recent non-finite-limit picture, but it is still only finite evidence for the full asymptotic behavior.
