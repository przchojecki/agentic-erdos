# EP-1004

## Problem Statement
Let $c>0$. If $x$ is sufficiently large then does there exist $n\leq x$ such that the values of $\phi(n+k)$ are all distinct for $1\leq k\leq (\log x)^c$, where $\phi$ is the Euler totient function?

## Site Remarks
Erd\H{o}s, Pomerance, and S\'{a}rk\"{o}zy \cite{EPS87} proved that if $\phi(n+k)$ are all distinct for $1\leq k\leq K$ then\[K \leq \frac{n}{\exp(c(\log n)^{1/3})}\]for some constant $c>0$.

See [945] for the analogous problem with the divisor function.

  Gpt 5.5 pro found a partial result (https://drive.google.com/file/d/1qNREx0WwSBi3P4FYCglifN_D78p5zelH/view?usp=sharing)
  
  Let \(L=L(x)\) satisfy\[
   L\log(2L)=o((\log x)^2).
  \]Then for all but \(o(x)\) integers \(n\le x\), the values\[
   \varphi(n+1),\varphi(n+2),\ldots,\varphi(n+L)
  \]are pairwise distinct. In particular, this gives an affirmative answer to the problem for every fixed exponent \(c<2\), taking \(L=\lfloor(\log x)^c\rfloor\). It also gives, for example,\[
   L=\frac{(\log x)^2}{(\log\log x)^{1+\varepsilon}}
  \]for any fixed \(\varepsilon>0\).
  
  The broad idea is to count bad starting points. If \(n\) is bad, then for some \(1\le i<j\le L\),\[
   \varphi(n+i)=\varphi(n+j).
  \]Writing \(h=j-i\) and \(m=n+i\), this gives a shifted equal-totient equation\[
   \varphi(m)=\varphi(m+h).
  \]Thus the number of bad starts is bounded by\[
   \sum_{h<L}(L-h)P(x+L;h),
  \]where\[
   P(X;h)=\#\{m\le X:\varphi(m)=\varphi(m+h)\}.
  \]The note uses the Graham--Holt--Pomerance / Pollack--Pomerance--Treviño decomposition (references in note)\[
   P(X;h)=P_0(X;h)+P_1(X;h).
  \]The exceptional part \(P_1\) is exponentially small uniformly for polylogarithmic \(h\). The structured part satisfies\[
   P_0(X;h)\ll c(h)\frac{X}{(\log X)^2}.
  \]The extra observation in the note is that the structured constants have enough average saving:\[
   \sum_{h\le L} c(h)\ll \log L.
  \]Combining these gives\[
  \begin{aligned}
  \#\{\text{bad }n\le x\}
  &\ll
  \frac{x}{(\log x)^2}
  \sum_{h<L}(L-h)c(h)
  +
  o(x) \\
  &\ll
  x\frac{L\log L}{(\log x)^2}+o(x).
  \end{aligned}
  \]This is \(o(x)\) whenever\[
   L\log L=o((\log x)^2).
  \]So this does not solve the full problem for arbitrary fixed \(c>0\), but it does give a rigorous almost-all result up to essentially the \((\log x)^2\) scale.

  A slightly stronger statement follows from the usual shifted-collision estimates for the totient function. Let \(c>0\) be fixed and put \(L=\lfloor(\log x)^c\rfloor\). I will use the following standard consequence of the Erdős--Pomerance--Sárközy/Graham--Holt--Pomerance primitive-set method: for every \(A,B>0\), uniformly for \(1\le h\le(\log X)^B\), one has\[
  R_h(X):=\#\{m\le X:\varphi(m)=\varphi(m+h)\}\ll_{A,B}\frac{X}{(\log X)^A}.
  \]This is unconditional. Call \(n\le x-L\) bad if the values \(\varphi(n+1),\ldots,\varphi(n+L)\) are not all distinct. If \(n\) is bad, then there exist \(1\le i<j\le L\) such that \(\varphi(n+i)=\varphi(n+j)\). Writing \(h=j-i\) and \(m=n+i\), this gives \(\varphi(m)=\varphi(m+h)\), with \(1\le h\le L\) and \(m\le x+L\). For fixed \(h\), there are at most \(L-h\le L\) possible values of \(i\). Hence the number of bad \(n\le x-L\) is at most\[
  \sum_{h=1}^{L-1}(L-h)R_h(x+L)\le L\sum_{h=1}^{L}R_h(x+L).
  \]Taking \(B>c\) in the shifted-collision estimate gives, for every \(A>0\),\[
  R_h(x+L)\ll_{A,c}\frac{x}{(\log x)^A}
  \]uniformly for \(1\le h\le L\). Therefore\[
  \#\{n\le x-L:n\text{ is bad}\}\ll_{A,c}L^2\frac{x}{(\log x)^A}\ll_{A,c}x(\log x)^{2c-A}.
  \]Choosing \(A>2c+1\), this is \(o(x)\). Consequently almost every \(n\le x\) has the property that \(\varphi(n+1),\ldots,\varphi(n+\lfloor(\log x)^c\rfloor)\) are pairwise distinct. In particular, for all sufficiently large \(x\), there exists some \(n\le x\) such that the values \(\varphi(n+k)\), \(1\le k\le(\log x)^c\), are all distinct.

Route:
Scanned consecutive windows of totient values to find long runs where
phi(n+1),...,phi(n+K) are all distinct.

## Local Proof Attempts
Hard point:
The problem asks existence for every fixed c>0 asymptotically; finite scans for selected c do not prove the full statement.

Collision-count identity for totient windows:
For an interval \(I=[m+1,m+K]\), let
\[
C_I:=\#\{(a,b)\in I^2:\ a<b,\ \varphi(a)=\varphi(b)\}.
\]
Then
\[
\varphi(m+1),\dots,\varphi(m+K)\ \text{all distinct}
\iff
C_I=0.
\]
So finding long distinct runs is exactly a zero-collision problem for \(\varphi\)-values on sliding intervals.
Counting-function reformulation:
Define
\[
L(X):=\max\{K:\exists\,m\le X,\ \varphi(m+1),\dots,\varphi(m+K)\ \text{pairwise distinct}\}.
\]
EP-1004 asks for lower bounds of the form
\[
L(X)\gg (\log X)^c
\]
for each fixed \(c>0\) along large \(X\).
Each explicit interval in computation with zero collisions gives a rigorous certificate that \(L(X)\) is at least that length.
Basic lower bound:
For all \(X\ge1\),
\[
L(X)\ge 1.
\]
This is immediate from a one-term window.
Monotonicity:
\[
L(X+1)\ge L(X).
\]
Proof: any interval witnessing \(L(X)\) is still admissible at level \(X+1\).
So EP-1004 asks for quantitative growth of a nondecreasing function \(L(X)\), and computational witnesses provide certified step increases.
Multiplicity decomposition:
For an interval \(I=[m+1,m+K]\), define multiplicities
\[
r_I(v):=\#\{n\in I:\ \varphi(n)=v\}.
\]
Then
\[
\sum_v r_I(v)=K,\qquad
C_I=\sum_v \binom{r_I(v)}{2}.
\]
Hence
\[
C_I=0 \iff r_I(v)\in\{0,1\}\ \forall v
\]
(equivalently all \(\varphi\)-values in the window are distinct).
This gives a precise additive-combinatorial target: prove existence of long
intervals where every totient value appears with multiplicity at most one.

Target:
Show for every fixed \(c>0\), there exist arbitrarily large \(X\) with
\[
L(X)\gg (\log X)^c.
\]
A. Concrete Blocking Lemma (Most Critical):
Prove a sparse-collision theorem: for many intervals \(I=[m+1,m+K]\) with
\(K\le (\log m)^C\), one has
\[
\sum_v \binom{r_I(v)}{2}=o(1),
\]
hence zero collisions for infinitely many such intervals.
B. Reduction Lemmas (with proofs):
Lemma B1 (collision equivalence):
\[
C_I=0 \iff \varphi(m+1),\dots,\varphi(m+K)\ \text{are pairwise distinct}.
\]
Proof.
By definition, \(C_I\) counts equal-value pairs in the window. \(\square\)
Lemma B2 (multiplicity decomposition):
\[
C_I=\sum_v \binom{r_I(v)}{2}.
\]
Proof.
For each value \(v\), choose unordered pairs among \(r_I(v)\) occurrences. Summing over \(v\) counts all equal-value pairs exactly once. \(\square\)
Lemma B3 (A implies polylog lower bounds):
If A holds for \(K=(\log m)^c\), then \(L(m)\ge K\) for infinitely many \(m\).
Proof.
A gives infinitely many windows with \(C_I=0\); by Lemma B1 each provides a distinct-run witness of length \(K\). \(\square\)
C. Main unresolved point:
The key gap is obtaining sufficiently strong short-interval control on repeated totient values to force collision-free windows at polylogarithmic lengths.
