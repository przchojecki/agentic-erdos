# EP-1101

## Problem Statement
If $u=\{u_1<u_2<\cdots\}$ is a sequence of integers such that $(u_i,u_j)=1$ for all $i\neq j$ and $\sum \frac{1}{u_i}<\infty$ then let $\{a_1<a_2<\cdots\}$ be the sequence of integers which are not divisible by any of the $u_i$. For any $x$ define $t_x$ by\[u_1\cdots u_{t_x}\leq x< u_1\cdots u_{t_x}u_{t_x+1}.\]We call such a sequence $u_i$ good if, for all $\epsilon>0$, if $x$ is sufficiently large then\[\max_{a_k<x} (a_{k+1}-a_k) < (1+\epsilon)t_x \prod_{i}\left(1-\frac{1}{u_i}\right)^{-1}.\]Is there a good sequence such that $u_n< n^{O(1)}$? Is there a good sequence such that $u_n\leq e^{o(n)}$?

## Site Remarks
Erd\H{o}s \cite{Er81h} believed the answer to the first question is no and the second question is yes. He proved the existence of some good sequence (in which all the $u_i$ are primes).

An easy sieve argument proves that we always have, for any sequence $u$ with those properties,\[\max_{a_k<x} (a_{k+1}-a_k)> (1+o(1))t_x \prod_{i}\left(1-\frac{1}{u_i}\right)^{-1}.\]The strong form of [208] is asking whether if $u_i=p_i^2$, the sequence of prime squares, is good.

## Local Computation
- reports finite-window ratios
 max_gap / (t_x * prod(1-1/u_i)^(-1)) above 1 for all tested families.
- This is compatible with the known lower-barrier shape and does not validate a "good" sequence criterion in tested windows.

## Local Proof Attempts
Route:
Tested candidate u_i families (prime squares/cubes and alternating exponents) by direct sieve simulation of allowed integers and normalized maximum-gap ratios.

Hard point:
The definition is asymptotic and quantified for all sufficiently large x; finite scans cannot certify eventual upper control.

Target:
Characterize "good" sequences \((u_i)\) controlling maximal gaps in the sifted set \(\{n:\ u_i\nmid n\ \forall i\}\).
A. Concrete Blocking Lemma (Most Critical):
Establish a sharp discrepancy theorem:
\[
\max_{t\le x}\frac{\text{gap at }t}{\,t\prod_{u_i\le t}(1-1/u_i)^{-1}}
\]
is bounded iff a quantitative pseudo-independence condition on residue classes modulo \((u_i)\) holds.
B. Reduction Lemmas (with proofs):
Lemma B1 (density heuristic normalization):
If local divisibility events behaved independently, expected survivor density up to \(t\) is
\[
\prod_{u_i\le t}\left(1-\frac1{u_i}\right).
\]
Proof.
Under independence, multiply survival probabilities over excluded moduli. \(\square\)
Lemma B2 (gap-to-discrepancy translation):
A long gap in survivors implies a large discrepancy of survivor counts from the normalized density in an interval of comparable length.
Proof.
If an interval has no survivors, observed count is \(0\), while expected count under normalization is positive unless interval is much shorter than the reciprocal density scale. \(\square\)
Lemma B3 (A implies asymptotic goodness criterion):
If the discrepancy bound in A holds uniformly for large \(t\), then the sequence is good in the Erdős sense.
Proof.
Uniform discrepancy control bounds maximal empty intervals by a constant multiple of the normalized scale in Lemma B1. \(\square\)
C. Main unresolved point:
The missing ingredient is a uniform correlation estimate for overlapping divisibility constraints when \(u_i\) are sparse but highly arithmetic.
