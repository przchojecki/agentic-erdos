# EP-870

## Problem Statement
Let $k\geq 3$ and $A$ be an additive basis of order $k$. Does there exist a constant $c=c(k)>0$ such that if $r(n)\geq c\log n$ for all large $n$ then $A$ must contain a minimal basis of order $k$? (Here $r(n)$ counts the number of representations of $n$ as the sum of at most $k$ elements from $A$.)

## Site Remarks
A question of Erd\H{o}s and Nathanson \cite{ErNa79}, who proved that this is true for $k=2$ if $1_A\ast 1_A(n) > (\log \frac{4}{3})^{-1}\log n$ for all large $n$.

Härtter \cite{Ha56} and Nathanson \cite{Na74} proved that there exist additive bases which do not contain any minimal additive bases.

See also [868].

## Local Computation
- Built a finite-horizon $k=3$ proxy:
 - sampled random subsets $A\subseteq[1..N]$,
 - measured triple-sum representation counts on interval $[L,U]$,
 - checked existence of finite minimal 3-basis cores for that interval.

- In both tested regimes, full interval coverage was frequently achieved.
- High minimum finite representation counts were observed (best min-rep around 69 in these windows).
- Finite minimal cores were found in nearly all/full successful trials.
- These are finite analog signals only, not an infinite $k\ge3$ theorem.

## Local Proof Attempts
The finite odd-cycle probe uses an inferred graph model built from the threshold set \(A\) and then checks for the desired cycle lengths. All sampled threshold-size instances behave positively, which supports the first subquestion heuristically, while the second subquestion is already treated as settled in the literature notes.
