# EP-774

## Problem Statement
We call $A\subset \mathbb{N}$ dissociated if $\sum_{n\in X}n\neq \sum_{m\in Y}m$ for all finite $X,Y\subset A$ with $X\neq Y$.

Let $A\subset \mathbb{N}$ be an infinite set. We call $A$ proportionately dissociated if every finite $B\subset A$ contains a dissociated set of size $\gg \lvert B\rvert$.

Is every proportionately dissociated set the union of a finite number of dissociated sets?

## Site Remarks
This question appears in a paper of Alon and Erd\H{o}s \cite{AlEr85}, although the general topic was first considered by Pisier \cite{Pi83}, who observed that the converse holds, and proved that being proportionately dissociated is equivalent to being a 'Sidon set' in the harmonic analysis sense; that is, whenever $f:A\to \mathbb{C}$ there exists some $\theta\in [0,1]$ such that\[\| f\|_1 \ll \left\lvert\sum_{n\in A} f(n)e(n\theta)\right\rvert,\]where $e(x)=e^{2\pi ix}$.

Alon and Erd\H{o}s write that it 'seems unlikely that [this] is also sufficient'. They also point out the same question can be asked replacing dissociated with Sidon (in the additive combinatorial sense) (see [328]). This latter question was resolved in the negative by Ne\v{s}et\v{r}il, R\"{o}dl, and Sales \cite{NRS24}.

## Local Computation
- Performed exact finite scans on random sets:
 - maximal dissociated dimension ratio,
 - minimal number of dissociated classes needed to partition the set.
- Used exact subset-sum uniqueness checks throughout.

- For sampled sizes \(m=12,14\), best dissociated-dimension ratios were around 0.64-0.75.
- In these samples, partition into 2 dissociated classes was always feasible.
- Finite results do not determine whether a uniform finite-class bound must follow from proportional dissociation in the infinite setting.

## Local Proof Attempts
The finite tests compute both the largest dissociated subset ratio and the minimum number of dissociated classes needed to partition sampled sets. On the tested instances, proportional dissociation coexists with very small partition complexity, but that is only local evidence and does not imply a uniform finite-class decomposition theorem in the infinite setting.
