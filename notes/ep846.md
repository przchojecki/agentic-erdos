# EP-846

## Problem Statement
Let $A\subset \mathbb{R}^2$ be an infinite set for which there exists some $\epsilon>0$ such that in any subset of $A$ of size $n$ there are always at least $\epsilon n$ with no three on a line.

Is it true that $A$ is the union of a finite number of sets where no three are on a line?

- 15:10 on 25 Feb 2026 - GTsoukalas (reply depth 1):
  Here is a summary of the proof, written by Adam Zsolt Wagner:
  
  1. Label the vertices of the infinite complete graph with numbers $x_1, x_2, \dots$. These $x_i$ will be chosen to be a sequence that grows very quickly, to avoid accidental clashes in the following embedding.
  2. We define the point set in $\mathbb{R}^2$ as follows. For every edge $(x_i, x_j)$ of this infinite complete graph, we include the point $(x_i + x_j, x_i^2 + x_i \cdot x_j + x_j^2)$.
  3. This embedding has the property that three edges form a triangle if and only if the corresponding points are collinear.
  4. The resulting point set satisfies the condition of the problem with $\epsilon = 1/2$. Indeed, given $n$ points, they correspond to a graph with n edges. Every graph with n edges has a bipartite subgraph with at least $n/2$ edges. Such a subgraph is triangle-free, so it corresponds to at least $n/2$ points with no three on a line.
  5. A subset of our points with no three on a line corresponds to a triangle-free subgraph of the infinite complete graph. By infinite Ramsey, whenever the edges of the infinite complete graph are finitely colored, one of the color classes contains a triangle. So we cannot cover our point set with finitely many sets with no three on a line.

## Local Computation
- Built finite analog via 3-uniform collinearity hypergraph on selected point configurations.
- Computed exactly:
 - $\alpha_3$: largest no-three-collinear subset;
 - $\chi_3$: minimum number of classes partitioning points so each class is no-three-collinear.

- Structured line-rich examples (e.g. $5\times3$ grid / union of 3 lines) show $\alpha_3/n\approx 0.4$ with $\chi_3=3$.
- A generic curved example (parabola points) gives $\alpha_3=n$ and $\chi_3=1$.
- Finite data supports that local linear extraction can coexist with small finite partition number, but does not settle the infinite statement.

## Local Proof Attempts
The finite work here only supplies lower bounds: build large 3-sunflower-free families greedily and compare their sizes with the standard exponential benchmark. This confirms the expected exponential scale on small \(n\), but it does not pin down the asymptotic constant in the weak sunflower problem.
