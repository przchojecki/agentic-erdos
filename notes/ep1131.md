# EP-1131

## Problem Statement
For $x_1,\ldots,x_n\in [-1,1]$ let\[l_k(x)=\frac{\prod_{i\neq k}(x-x_i)}{\prod_{i\neq k}(x_k-x_i)},\]which are such that $l_k(x_k)=1$ and $l_k(x_i)=0$ for $i\neq k$.

What is the minimal value of\[I(x_1,\ldots,x_n)=\int_{-1}^1 \sum_k \lvert l_k(x)\rvert^2\mathrm{d}x?\]In particular, is it true that\[\min I =2-(1+o(1))\frac{1}{n}?\]

## Site Remarks
Erd\H{o}s first conjectured this minimum was achieved by taking the $x_i$ to be the roots of the integral of the Legendre polynomial, since Fejer \cite{Fe32} had earlier shown these to be minimisers of\[\max_{x\in [-1,1]}\sum_k \lvert l_k(x)\rvert^2.\]This was disproved by Szabados \cite{Sz66} for every $n>3$.

Erd\H{o}s, Szabados, Varma, and V\'{e}rtesi \cite{ESVV94} proved that\[2-O\left(\frac{(\log n)^2}{n}\right)\leq \min I\leq 2-\frac{2}{2n-1}\]where the upper bound is witnessed by the roots of the integral of the Legendre polynomial as above.

## Local Computation
- deep numeric minimization:
 - barycentric evaluation of $\sum_k \ell_k(x)^2$,
 - Simpson quadrature on dense grids,
 - long-budget local node optimization for each $n$.

Deep run (DEPTH=4) with
- $n\in\{8,12,16,20,24,28,32\}$,
- 14s optimization budget per $n$,
- grid size 1600 for numerical integration.
Found values satisfy:
- $I$ very close to 2 from below,
- $n(2-I)$ stays around 1 in this range (roughly $0.98$ to $1.11$),
- profiles are numerically consistent with the conjectural $2-c/n$ scale and with $c$ near 1.
Recovered near-optimal nodes are close to classical Chebyshev-like distributions for larger $n$.
Caveat: this is numerical optimization and does not prove global minimizers.

## Local Proof Attempts
Target:
Prove asymptotic
\[
\min I = 2-\frac{1+o(1)}{n}.
\]
Step A: Sharp Lower Bound Improvement
Upgrade
\[
2-O\!\left(\frac{(\log n)^2}{n}\right)
\]
to
\[
2-\frac{C_1+o(1)}{n}
\]
with explicit \(C_1\).
Step B: Matching Constructive Upper Bound
Construct node sets with
\[
I\le 2-\frac{C_2+o(1)}{n}
\]
and \(C_2\) matching Step A constant.
Step C: Stability/Uniqueness at First Order
Show near-optimal families are \(o(1)\)-close (after normalization) to the
extremal node distribution, fixing the first-order constant.
Concrete Blocking Lemma (Most Critical):
Need a first-order expansion theorem for
\[
\int_{-1}^1\sum_k |\ell_k(x)|^2\,dx
\]
under perturbations of near-Chebyshev nodes, with error \(o(1/n)\).

Lemma B1 (quadratic-basis identity):
For any nodes,
\[
I=\int_{-1}^1\sum_{k=1}^n \ell_k(x)^2\,dx
\]
since \(\ell_k(x)\in\mathbb R\) on \([-1,1]\), so \(|\ell_k|^2=\ell_k^2\).
Proof.
All quantities are real-valued on the real interval; absolute-square equals square. \(\square\)
Lemma B2 (partition identity):
\[
\sum_{k=1}^n \ell_k(x)=1\quad\text{for all }x,
\]
hence \(I\ge \int_{-1}^1 \frac1n\,dx = \frac{2}{n}\) by Cauchy at each \(x\).
Proof.
Lagrange basis reproduces constants. Then
\[
1=\left(\sum_k \ell_k\right)^2\le n\sum_k \ell_k^2,
\]
so \(\sum_k\ell_k^2\ge 1/n\); integrate over \([-1,1]\). \(\square\)
Lemma B3 (first-order sensitivity transfer):
If node perturbations of size \(O(n^{-2})\) change \(I\) by at most \(o(1/n)\), then any near-Chebyshev family yields the same first-order constant in \(2-I\).
Proof.
Write \(I=I_\star+\Delta\) with \(\Delta=o(1/n)\). Multiplying by \(n\), \(n(2-I)=n(2-I_\star)+o(1)\), so first-order constants match. \(\square\)
