# EP-145

## Problem Statement
Let $s_1<s_2<\cdots$ be the sequence of squarefree numbers. Is it true that, for any $\alpha \geq 0$,\[\lim_{x\to \infty}\frac{1}{x}\sum_{s_n\leq x}(s_{n+1}-s_n)^\alpha\]exists?

## Site Remarks
Erd\H{o}s \cite{Er51} proved this for all $0\leq \alpha \leq 2$, and Hooley \cite{Ho73} extended this to all $\alpha \leq 3$.

Greaves, Harman, and Huxley showed (in Chapter 11 of \cite{GHH97}) that this is true for $\alpha \leq 11/3$. Chan \cite{Ch23c} has extended this to $\alpha \leq 3.75$.

Granville \cite{Gr98} proved that this follows (for all $\alpha \geq 0$) from the ABC conjecture (https://en.wikipedia.org/wiki/Abc_conjecture).

See also [208].

Proposition AW1 (Moment convergence criterion):
If \(M_\alpha(X)\) satisfies
\[
M_\alpha(X)=C_\alpha+E_\alpha(X),\qquad E_\alpha(X)\to 0,
\]
then \(\lim_{X\to\infty}M_\alpha(X)=C_\alpha\).
\[
\textit{Proof.}
\]
Immediate from the definition of limit.
\(\square\)
Proposition AW2 (Interpolation reduction):
Suppose convergence is proved for integer \(\alpha\) in an interval and
\(\alpha\mapsto M_\alpha(X)\) is uniformly Hölder/Lipschitz with modulus
independent of \(X\). Then convergence extends to all real \(\alpha\) in that
interval.
\[
\textit{Proof sketch.}
\]
Approximate real \(\alpha\) by nearby proved points and pass \(X\to\infty\) using
uniform continuity.
\(\square\)
