# EP-159

## Problem Statement
There exists some constant $c>0$ such that

$$R(C_4,K_n) \ll n^{2-c}.$$

## Site Remarks
The prize of \$100 is offered in \cite{Er78} for a proof or disproof. The current bounds are\[ \frac{n^{3/2}}{(\log n)^{3/2}}\ll R(C_4,K_n)\ll \frac{n^2}{(\log n)^2}.\]The upper bound is due to Szemer\'{e}di (mentioned in \cite{EFRS78}), and the lower bound is due to Spencer \cite{Sp77}.

This problem is #17 in Ramsey Theory (https://mathweb.ucsd.edu/~erdosproblems/erdos/newproblems/RamseyC4.html) in the graphs problem collection.

## Local Computation
Current cited bounds remain:
- lower: R(C_4,K_n) >> n^{3/2} / (log n)^{3/2}
- upper: R(C_4,K_n) << n^2 / (log n)^2
So the known upper bound has logarithmic savings but not a polynomial power-saving
n^{2-c}.

- explicit numeric scaling diagnostics for the known n^{3/2}/(\log n)^{3/2} lower and n^2/(\log n)^2 upper templates.
- Finite profile confirms a large exponent gap persists in practical ranges, and coarse upper surrogates remain far from any n^{2-c} power-saving statement.
- Obstacle: the EP requires a true exponent drop; current methods in this only quantify how far existing template bounds are from that target.

## Local Proof Attempts
I reviewed the quantitative frontier from the background and aligned it with the
 conjectured power-saving target.

Hard point:
Converting the logarithmic improvement into a true exponent drop requires stronger
global structural control in C_4-free graph constructions.

Target:
Prove existence of \(c>0\) such that
\[
R(C_4,K_n)\ll n^{2-c}.
\]
Step A: Refined \(C_4\)-free structure
Establish stronger pseudorandom/spectral control for near-extremal \(C_4\)-free
graphs at Ramsey threshold scale.
Step B: Independence amplification
Convert structure into larger guaranteed independent sets than current
\((\log n)^2\)-based bounds.
Step C: Ramsey inversion
Translate amplified independence into a polynomial exponent drop in \(R(C_4,K_n)\).
Concrete Blocking Lemma (Most Critical):
Need an improved independence lower bound for \(C_4\)-free graphs of given order
and average degree that beats the current logarithmic barrier.

Proposition BG1 (Ramsey reformulation):
\(R(C_4,K_n)>N\) iff there exists a \(C_4\)-free graph \(G\) on \(N\) vertices
with \(\alpha(G)<n\).
\[
\textit{Proof.}
\]
Standard two-color edge interpretation: red graph \(G\), blue complement.
\(\square\)
Proposition BG2 (Exponent-drop reduction):
If every \(C_4\)-free \(N\)-vertex graph satisfies
\[
\alpha(G)\ge N^{\varepsilon}
\]
for some fixed \(\varepsilon>0\) and large \(N\), then
\[
R(C_4,K_n)\ll n^{1/\varepsilon}=n^{2-c}
\]
for \(c=2-1/\varepsilon\) whenever \(1/\varepsilon<2\).
\[
\textit{Proof.}
\]
By BG1, if \(R(C_4,K_n)>N\), then \(n>\alpha(G)\ge N^\varepsilon\), so
\(N<n^{1/\varepsilon}\). Rearrangement gives the bound.
\(\square\)
