# EP-757

## Problem Statement
Let $A\subset \mathbb{R}$ be a set of size $n$ such that every subset $B\subseteq A$ with $\lvert B\rvert =4$ has $\lvert B-B\rvert\geq 11$. Find the best constant $c>0$ such that $A$ must always contain a Sidon set of size $\geq cn$.

## Site Remarks
For comparison, note that if $B$ were a Sidon set then $\lvert B-B\rvert=13$, so this condition is saying that at most one difference is 'missing' from $B-B$. Equivalently, one can view $A$ as a set such that every four points determine at least five distinct distances, and ask for a subset with all distances distinct.

Without loss of generality, one can assume $A\subset \mathbb{N}$.

Erd\H{o}s and S\'{o}s proved that $c\geq 1/2$. Gy\'{a}rf\'{a}s and Lehel \cite{GyLe95} proved\[\frac{1}{2}+\frac{1}{141\cdot 76}\leq c\leq\frac{3}{5}.\](The example proving the upper bound is the set of the first $n$ Fibonacci numbers.)
Ma and Tang \cite{MaTa26} have improved these bounds to\[\frac{9}{17}\leq c\leq \frac{4}{7}.\]

## Local Computation
- Built finite sampling + exact search framework:
 - sample \(n\)-sets in a wide interval,
 - keep only sets satisfying the local 4-point difference condition,
 - compute exact maximum Sidon subset size by branch-and-bound.

- With ambient range width 3000, accepted samples for \(n=10,12,14\) had very high Sidon ratios (average about 0.99; worst around 0.86-0.92).
- This indicates that in very spread-out finite models, the local condition strongly biases toward near-Sidon behavior.
- These finite results do not identify the asymptotic extremal constant; they likely overestimate typical ratios for adversarial constructions.

## Local Proof Attempts
The finite method samples sets obeying the local \(|B-B|\ge 11\) condition and then computes the exact largest Sidon subset by branch-and-bound. These experiments suggest that very spread-out examples are almost Sidon already, but that likely reflects the sampling model rather than the true extremal behavior. The optimal constant \(c\) remains open.
