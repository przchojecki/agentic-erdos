# EP-650

## Problem Statement
Let $f(m)$ be such that if $A\subseteq \{1,\ldots,N\}$ has $\lvert A\rvert=m$ then every interval in $[1,\infty)$ of length $2N$ contains $\geq f(m)$ many distinct integers $b_1,\ldots,b_r$ where each $b_i$ is divisible by some $a_i\in A$, where $a_1,\ldots,a_r$ are distinct.

Estimate $f(m)$. In particular is it true that $f(m)\leq \sqrt{m}$?

## Site Remarks
Erd\H{o}s and Sur\'{a}nyi \cite{ErSu59} proved that $f(m)\geq\sqrt{m}$. Erd\H{o}s and Selfridge proved (see \cite{Er78} and \cite{Er86c}) that $f(m^2)\leq 2m$, which implies $f(m)\leq 2\lceil \sqrt{m}\rceil$ for all $m$. It is unclear exactly what bound he was asking for in \cite{Er95c}, but in general some improvement of this bound.

GPT 5.4 Pro (prompted by He, Li, and Tang) proved $f(m)\leq \lceil 2\sqrt{m}\rceil$. A corresponding lower bound was given by GPT 5.4 Pro and Aristotle; it is now known (see the paper of van Doorn, Li, and Tang \cite{VLT26}) that\[f(m) = \min(m, \lceil 2\sqrt{m}\rceil)\]for all $m$.

  I think the argument checks out (and my GPT call confirmed this formula (https://chatgpt.com/share/69ac5e58-f49c-800e-8518-9dba9d95154a) for $4 \leq m \leq 9$, with $f(m)=m$ for $m=1,2,3$). To review the upper bound $f(st) \leq s+t$: this gives $f(k^2) \leq 2k$ and $f(k(k+1)) \leq 2k+1$ which implies $f(m) \leq \lceil 2 \sqrt{m} \rceil$ for all $m$. This is by using the Chinese remainder theorem to produce a tuple $a_{i,j} = a_0 + jD - i$ of moduli for $i=1,\dots,s$, $j=1,\dots,t$ and an interval $B$ such that each $a_{i,j}$ has exactly two multiples in $B$, one at $a_0+i$ and one at $a_0+jD$, leaving only $s+t$ multiples in all.
  
  For the lower bound, one needs to show that for a set $A$ of $m$ elements and an interval $B$ of length $2N$, one can match at least $\lceil 2\sqrt{m} \rceil$ elements of $A$ to distinct multiples in $B$; for $m \geq 4$ this quantity is less than or equal to $m$. By the Hall marriage theorem and a standard trick of adding some dummy vertices, it suffices to show that for every subset $S$ of elements of $A$, the set of multiples of $S$ in $B$ has size at least $|S| + \lceil 2\sqrt{m} \rceil - m$.
  
  Ignoring a technical case when $B$ starts with a multiple of $N$, one can split $B$ into a left half $B_-$ and a right half $B_+$. One can match each element $a$ of $A$ with the largest multiple $b^-_a$ of $a$ in $B_-$ and the smallest multiple $b^+_a$ of $a$ in $B_+$. Since $b^+_a-b^-_a=a$, these two quantities determine $a$. From this and the AM-GM inequality we can show that the neighborhood of $S$ in the divisibility graph is at least $2 \sqrt{|S|}$, and this and some basic algebra gives the required Hall marriage criterion.
  
  The AlphaEvolve run struggled to beat the trivial bound $f(m) \leq m$ (although it did do so in a few cases); this is consistent with my experience that it has some difficulty with number-theoretic constructions (using for instance the Chinese remainder theorem) which seem challenging to hillclimb on.

  Nice! The proof of the lower bound looks good to me. I didn't check the exact accounting, but at least the idea that delivers $f(m)\geq 2\sqrt{m}-O(1)$ is quite simple and elegant; I'll reproduce it here without the GPT inflation: let $I$ be an interval of length $2N$ and consider the bipartite graph on $A\times I$ where we have $a\sim n$ if $a\mid n$. We want to find as large a matching as possible inside this graph.
  
  If $\Gamma_-(S)$ is the neighbourhood of $S\subseteq A$ in the bottom half of $I$ and $\Gamma_+(S)$ is the neighbourhood in the top half of $I$, then the key observation is that, if $c_a$ is the largest multiple of $a$ in the bottom half of $I$, then\[a\mapsto (c_a,c_a+a)\]is an injective map which proves, for any $S\subseteq A$,\[\lvert S\rvert \leq \lvert \Gamma_-(S)\rvert \lvert \Gamma_+(S)\rvert.\]In particular, by the AM-GM inequality, if $\Gamma=\Gamma_-\cup \Gamma_+$ is the full neighbourhood, $\lvert S\rvert \leq \lvert \Gamma(S)\rvert^2/4$, so $\lvert \Gamma(S)\rvert \geq 2\lvert S\rvert^{1/2}$.
  
  Via a standard defect form of Hall's matching theorem this implies that there is matching on at least $2\lvert A\rvert^{1/2}$ elements of $A$.
  
  This is the proof; the remainder is some tedious accounting to check edge cases (e.g. if $a=N$), which hopefully GPT did correctly, but even if not, the proof above does at least always give $\geq 2m^{1/2}-O(1)$.

  Perhaps the intended question is then to ask whether $f(n) \leq \lceil \sqrt{n}\rceil$) (rather than $f(n) \ll \sqrt{n}$) for all sufficiently large $n$? We now have $f(n) \leq 2 \lceil \sqrt{n} \rceil$ but there is the factor of 2. (The ceiling function here is natural since $f(n)$ is obviously an integer.) The argument in [Er78] gives $f(k^2) \leq 2k$ which also recovers $f(n) \leq 2 \lceil \sqrt{n} \rceil$ by monotonicity. (An equivalent formulation of the problem is then to obtain the upper bound $f(k^2) \leq k$ for all large $k$.)
  
  For completeness, here is the Erdos-Sarányi argument that gives $f(n) \geq \lceil\sqrt{n}\rceil$ (using this Gemini translation (https://gemini.google.com/share/378e8a1490e5) of the original Hungarian text). Let $A$ be $m$ elements in $\{1,\dots,N\}$ and let $I$ be an interval of length $2N$. Using the greedy algorithm one can find $r$ numbers $b_1,\dots,b_r$ in $I$, each of which divisible by a distinct element of $A$, such that no further elements can be added; this implies that the $b_1,\dots,b_r$, between them, contain all the elements of $A$ as factors. In particular, by the pigeonhole priciple, one of these, say $b_i$, must have at least $m/r$ factors in $A$; call then $a_1,\dots,a_{r'}$ for some $r' \geq m/r$. If $b_i$ lies in the right half of $I$, then $b_i - a_1,\dots,b_i - a_{r'}$ will then each be divisible by distinct elements $a_1,\dots,a_{r'}$, so we get a solution to the problem with at least $\max(r,r') \geq \max(r,n/r) \geq \lceil\sqrt{n}\rceil$ factors. If instead $b_i$ lies in the left half, we use $b_i + a_1,\dots,b_i+a_{r'}$ instead.
  
  I can imagine a computer search (with or without AI assistance) should be able to compute $f(n)$ exactly for the first few $n$, which would create an OEIS sequence and also give some numerical evidence for this conjecture. The values when $n$ is a perfect square would be particularly interesting.
