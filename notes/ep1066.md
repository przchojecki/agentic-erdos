# EP-1066

## Problem Statement
Let $G$ be a graph given by $n$ points in $\mathbb{R}^2$, where any two distinct points are at least distance $1$ apart, and we draw an edge between two points if they are distance $1$ apart.

Let $g(n)$ be maximal such that any such graph always has an independent set on at least $g(n)$ vertices. Estimate $g(n)$, or perhaps $\lim \frac{g(n)}{n}$.

## Site Remarks
Such graphs are always planar. Erd\H{o}s initially thought that $g(n)=n/3$, but Chung and Graham, and independently Pach, gave a construction that shows $g(n)\leq \frac{6}{19}n$. Pach and Toth \cite{PaTo96} improved this to $g(n)\leq \frac{5}{16}n$.

Pollack \cite{Po85} noted that the Four colour theorem (https://en.wikipedia.org/wiki/four_color_theorem) implies $g(n)\geq n/4$, since the graph is planar. Pollack reports that Pach observed that this in for unit distance graphs the four colour theorem can be proved by a simple induction.

This lower bound has been improved to $\frac{9}{35}n$ by Csizmadia \cite{Cs98} and then $\frac{8}{31}n$ by Swanepoel \cite{Sw02}. The current record bounds are therefore\[\frac{8}{31}n \approx 0.258n \leq g(n) \leq 0.3125n=\frac{5}{16}n.\]Pollack \cite{Po85} also reports a letter from Erd\H{o}s which poses the more general problem of, given $n$ points in $\mathbb{R}^d$ with minimum distance $1$, let $g_d(n)$ be maximal such that there always exist at least $g_d(n)$ many points which have minimum distance $>1$. Is it true that $g_d(n) \gg n/d$ in general? The upper bound $g_d(n) \ll n/d$ is trivial, considering widely spaced unit simplices.

See [1070] for the general estimate of independence number of unit distance graphs.

## Local Computation
- deeper exact MIS pipeline:
 - large triangular-lattice patch model ($14\times14$),
 - many random induced subgraphs,
 - exact maximum independent set computation on each sampled graph,
 - distributional profile over sample set.
- Deep run size:
 - $n\in\{24,30,36,42\}$,
 - $480$ exact samples per $n$.

- Minimum sampled ratios in this induced-subgraph model were around:
 - $0.625$ for $n=24$,
 - $0.567$ for $n=30$,
 - $0.556$ for $n=36$,
 - $0.548$ for $n=42$.
- Means decrease with $n$ in this finite model but stay far above the sharpest known lower-bound constants for worst-case unit-distance graphs.

## Local Proof Attempts
The triangular-lattice induced-subgraph model still has independence ratios well above the best known worst-case lower bounds, so it is only a proxy for the true extremal problem. The open task is to narrow the linear-scale constant for general unit-distance graphs, not just for this structured family.
