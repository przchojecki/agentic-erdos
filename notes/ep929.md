# EP-929

## Problem Statement
Let $k\geq 2$ be large and let $S(k)$ be the minimal $x$ such that there is a positive density set of $n$ where\[n+1,n+2,\ldots,n+k\]are all divisible by primes $\leq x$.

Estimate $S(k)$ - in particular, is it true that $S(k)\geq k^{1-o(1)}$?

## Site Remarks
It follows from Rosser's sieve that $S(k)> k^{1/2-o(1)}$.

It is trivial that $S(k)\leq k+1$ since, for example, one can take $n\equiv 1\pmod{(k+1)!}$. The best bound on large gaps between primes due to Ford, Green, Konyagin, Maynard, and Tao \cite{FGKMT18} (see [4]) implies\[S(k) \ll k \frac{\log\log\log k}{\log\log k\log\log\log\log k}.\]

## Local Computation
- deep finite-density proxy using sliding-window maxima of largest prime factors.
- Parameters in this run:
 - $N=20{,}000{,}000$ start points,
 - $k\in\{6,8,10,12,16,20,24,28,32,40,48,56,64\}$,
 - threshold scan up to $x=120$,
 - multiple density thresholds $\varepsilon\in\{10^{-5},5\cdot 10^{-5},10^{-4},2\cdot10^{-4}\}$.

- Finite minimal $x$ with any occurrence increases roughly linearly with $k$ in tested range:
 - e.g. $x_{\mathrm{any}}(16)=17$, $x_{\mathrm{any}}(32)=31$, $x_{\mathrm{any}}(64)=61$.
- In this range and at this $N$, no tested pair reached density thresholds $10^{-4}$ or $2\cdot10^{-4}$.
- Signal is consistent with nontrivial growth of effective smoothness threshold as block length grows.

## Local Proof Attempts
The finite proxy replaces the positive-density definition by explicit occurrence and small-density thresholds on a very large initial range. It suggests that the smoothness threshold grows roughly linearly with block length in accessible data, which is compatible with a substantial lower bound on \(S(k)\), but still far from a proof.
