# EP-761

## Problem Statement
The cochromatic number of $G$, denoted by $\zeta(G)$, is the minimum number of colours needed to colour the vertices of $G$ such that each colour class induces either a complete graph or empty graph. The dichromatic number of $G$, denoted by $\delta(G)$, is the minimum number $k$ of colours required such that, in any orientation of the edges of $G$, there is a $k$-colouring of the vertices of $G$ such that there are no monochromatic oriented cycles.

Must a graph with large chromatic number have large dichromatic number? Must a graph with large cochromatic number contain a graph with large dichromatic number?

## Site Remarks
The first question is due to Erd\H{o}s and Neumann-Lara. The second question is due to Erd\H{o}s and Gimbel. A positive answer to the second question implies a positive answer to the first via the bound mentioned in [760].

## Forum Comments
- 00:28 on 26 Apr 2026 - AronBhalla:
  I think we can go further than just saying a positive answer to the second question implies a positive one to the first. In fact, the two questions are equivalent.
  
  For the converse: $\zeta(G)\le \chi(G)$ for every graph $G$, since any proper colouring is a cochromatic colouring using only independent colour classes. Hence, if large chromatic number always forces large dichromatic number, then large cochromatic number also forces large dichromatic number. Indeed, if $\zeta(G)$ is large, then $\chi(G)$ is large, and so $G$ itself has large dichromatic number. Thus $G$ contains a subgraph with large dichromatic number, namely $G$ itself.

## Local Computation
- Built finite proxy scans on small random graphs:
 - exact chromatic number,
 - exact dichromatic number for random orientations,
 - greedy cochromatic proxy.
- Used this to compare how quickly these parameters grow together in finite samples.

- For \(n=7,8,9\), average chromatic values are around 3.1 to 3.5, while average dichromatic values of random orientations stay around 1.6 to 1.9.
- In these samples, dichromatic number \(\ge 3\) did not occur, despite many graphs having chromatic number \(\ge 4\).
- Finite evidence suggests a substantial gap between chromatic and typical oriented dichromatic complexity at small scales.

## Local Proof Attempts
The present approach is only comparative: compute chromatic, dichromatic, and cochromatic proxies on the same small random graphs and see how tightly they track one another. In the tested regime, dichromatic complexity lags well behind chromatic complexity, which is informative negative finite evidence, but it does not resolve either implication question.
