# EP-714

## Problem Statement
Is it true that\[\mathrm{ex}(n; K_{r,r}) \gg n^{2-1/r}?\]

## Site Remarks
K\"{o}v\'{a}ri, S\'{o}s, and Tur\'{a}n \cite{KST54} proved\[\mathrm{ex}(n; K_{r,r}) \ll n^{2-1/r}\]for all $r\geq 2$. Brown \cite{Br66} and, independently, Erd\H{o}s, R\'{e}nyi, and S\'{o}s \cite{ERS66}, proved the conjectured lower bound when $r=3$.

When $r=2$ it is known that\[\mathrm{ex}(n;K_{2,2})=\left(\frac{1}{2}+o(1)\right)n^{3/2}\](see [768], since $K_{2,2}=C_4$).

See also [147]. The generalisation to hypergraphs is [1158].

## Local Computation
- Built standalone random-greedy constructions of bipartite \(K_{r,r}\)-free graphs for \(r=2,3\).
- Measured best edge counts versus the scale \(n^{2-1/r}\) across several \(n\)-values.

- Deep run (
\(r=2,3\), \(n=20,30,40,50,60\), 40 trials each) produced edge counts with
\[
\frac{e}{n^{2-1/r}}
\]
roughly in the range 0.31-0.39.
- Ratios are stable and positive across the tested sizes, consistent with the target exponent scale in finite experiments.

## Local Proof Attempts
The current attack is to build explicit finite \(K_{r,r}\)-free graphs by random-greedy methods and test whether the normalized edge count stays bounded away from zero on the \(n^{2-1/r}\) scale. This gives supportive evidence for the target lower-bound exponent in the cases \(r=2,3\), but it does not provide a general construction or proof for fixed arbitrary \(r\).
