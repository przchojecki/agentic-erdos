# EP-155

## Problem Statement
Let $F(N)$ be the size of the largest Sidon subset of $\{1,\ldots,N\}$. Is it true that for every $k\geq 1$ we have\[F(N+k)\leq F(N)+1\]for all sufficiently large $N$?

- 10:07 on 29 Aug 2025 - DesmondWeisenberg:
  The behavior of $F$ is the subject of [30]. It's trivial that $F(N + k) \leq F(N) + F(k)$ for all $N$ and $k$.
  
  Let $g(N)$ be maximal such that there exist Sidon sets $A, B \subseteq \{1,...,N\}$ such that $(A - A) \cap (B - B) = \{0\}$ and $g(N) \leq |A|, |B|$. Clearly, $g(N) \leq F(N)$ for all $N$; I don't know if Erdős ever asked about the behavior of $g$, but two related problems are [42] and [43]. (EDIT: Also [331].)
  
  One nice partial result on this problem is that if $N + 1 \geq k$, then $F(N + k) \leq F(N) + g(k)$. To prove this, let $A \subseteq \{1,..., N + k\}$ be a maximum-size Sidon set. By definition of $g$, the set $A$ has at most $g(k)$-many elements in $\{1,...,k\}$ or it has at most $g(k)$-many elements in $\{N+1,..., N+k\}$ (or both). By removing this interval, we then get a Sidon set of size at least $|A| - g(k) = F(N + k) - g(k)$ on an interval of length $N$, which completes the proof.

## Local Computation
An exact profile for \(F(N)\), the largest Sidon size in \([1,N]\), was computed through \(N=72\), using previously exact values up to \(60\) and exact backtracking beyond that. In this range,
- \(F(N+1)-F(N)\in\{0,1\}\), so there is no counterexample to the \(k=1\) case.
- The same remains true for shifts \(k=2,3\).
- For larger shifts, the maximum observed increments are \(2\) for \(k=4,5,6,8\) and \(3\) for \(k=10\).
Thus the finite data is consistent with eventual \(F(N+k)\le F(N)+1\) for small fixed \(k\), but still far from proving it.

## Local Proof Attempts
The exact profile was extended to \(N=76\), with \(F(74)=F(75)=F(76)=11\). For shifts \(k=1,2,3\), all observed increments still lie in \(\{0,1\}\), so the finite evidence for the small-shift \(+1\) law remains intact. The open issue is to prove a genuine local-collision obstruction showing that once \(N\) is large, a short interval \((N,N+k]\) cannot contribute more than one new Sidon element to an extremal set.
