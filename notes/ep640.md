# EP-640

## Problem Statement
Let $k\geq 3$. Does there exist some $f(k)$ such that if a graph $G$ has chromatic number $\geq f(k)$ then $G$ must contain some odd cycle whose vertices span a graph of chromatic number $\geq k$?

## Site Remarks
A problem of Erd\H{o}s and Hajnal.

This is trivial when $k=3$, since any non-bipartite graph contains an odd cycle, and all odd cycles have chromatic number $3$.

Steiner has observed in the comments that this is equivalent to the problem in which we replace 'odd cycle' with 'path'.

- 09:55 on 10 Aug 2025 - RaphaelSteiner:
  Observation: This problem is equivalent to the seemingly weaker problem when we look for a path whose vertices span a graph of chromatic number $\ge k$.
  
  To see this, suppose there exists a function $g(k)$ such that every graph of chromatic number at least $g(k)$ contains a path spanning a subgraph of chromatic number at least $k$. Now consider any graph of chromatic number at least $2g(k+1)-1$. W.l.o.g. the graph is connected. Doing a BFS layering from some vertex v, and using alternatingly two disjoint color sets to color the layers, we can see that one layer must induce a subgraph of chromatic number at least $g(k+1)$. So it contains a path inducing a subgraph of chromatic number at least $k+1$. Possibly after removing an end of this path, we find that there is a path in the layer of chromatic number $k$ of odd length. Now, linking the two ends of the path back to $v$ using shortest paths and cutting at the first layer where these shortest paths meet, we obtain an odd cycle spanning a subgraph of chromatic number at least $k$.
