# EP-348

## Problem Statement
For what values of $0\leq m<n$ is there a complete sequence $A=\{a_1\leq a_2\leq \cdots\}$ of integers such that
{UL}
{LI} $A$ remains complete after removing any $m$ elements, but {/LI}
{LI} $A$ is not complete after removing any $n$ elements? {/LI}
{/UL}

## Site Remarks
The Fibonacci sequence $1,1,2,3,5,\ldots$ shows that $m=1$ and $n=2$ is possible. The sequence of powers of $2$ shows that $m=0$ and $n=1$ is possible. The case $m=2$ and $n=3$ is not known.

van Doorn has shown (https://github.com/Woett/Mathematical-shorts/blob/main/Any%20multiset%20which%20is%20complete%20after%20removing%20any%20two%20elements%20remains%20complete%20after%20removing%20a%20specific%20infinite%20set.pdf) that no such sequence exists for $2\leq m<n$ if we interpret complete in the strong sense that\[\left\{ \sum_{n\in B}n : \textrm{ for all finite }B\subset A\right\}=\mathbb{N}.\]Erd\H{o}s and Graham most likely meant the weaker notion of completeness which allows finitely many exceptions, however.

## Forum Comments
- 22:21 on 06 Sep 2025 - Woett:
  If I understand correctly, the way this is formalised in Lean requires the multiset $A$ to have the property that the set
  $$P(A) = \left \{\sum_{n \in B} B \subseteq A \text{ finite} \right\}$$ contains all positive integers, and a lot of texts define completeness this way. In the book by Graham and Erdős however, it is only required that $P(A)$ contains all sufficiently large integers, which is also often taken as a definition of completeness. For what it is worth, with the former interpretation that is used in the Lean formalisation I can fully settle this problem, and show that no such multiset exists for any $m, n$ with $2 \le m < n$.
  
  Assume $A = \{a_1, a_2 \ldots, \}$ is such that $P(A \setminus \{a_i, a_j \}) = \mathbb{N}$ holds for all indices $i, j$. Set $s_1 = a_1$ and, for any $j \ge 2$, $s_j = a_i$ where $i$ is such that $a_{i-1} > s_1 + \ldots + s_{j-1}$. With the infinite set $S$ equal to $\{s_1, s_2, \ldots \}$, one can then check that $P(A \setminus S) = \mathbb{N}$ holds as well.
  
  For a complete write-up, see here (https://github.com/Woett/Mathematical-shorts/blob/main/Any%20multiset%20which%20is%20complete%20after%20removing%20any%20two%20elements%20remains%20complete%20after%20removing%20a%20specific%20infinite%20set.pdf). Perhaps the argument can be adapted to settle the second (intended) interpretation as well.
  
  EDIT: Come to think of it, I don't think this argument can be easily adapted to the intended interpreation, because the sequence $a_n = F_n + (-1)^n$ with $F_n$ the $n$-th Fibonacci number has the property that $P(A \setminus \{a_i, a_j\})$ contains all large enough integers for all $i, j$, but no infinite subset $S$ exists for which $P(A \setminus S)$ contains all large enough integers. See #346 (https://www.erdosproblems.com/346) and references for more information.

## Local Computation
A randomized search with exhaustive \(2\)- and \(3\)-deletion checks on finalists produced candidates with reasonable average robustness, but no finite witness of strict \((2,3)\)-type separation under the tested model.
In the strongest candidates, some \(2\)-deletions already destroyed coverage badly while certain \(3\)-deletions still left heavy coverage.
The data suggests that any positive weak-sense \((2,3)\) construction would need deliberately engineered redundancy rather than generic near-geometric examples.

## Local Proof Attempts
Background gives concrete realizable pairs:
- (m,n)=(0,1) via powers of two.
- (m,n)=(1,2) via Fibonacci-type example.
Background also records a negative theorem for a stronger completeness notion:
for that stronger notion, no such sequence exists when 2<=m<n.

Under the intended weaker completeness notion (allowing finitely many exceptions),
cases such as (m,n)=(2,3) remain open.

Target:
Classify all \((m,n)\) for which there exists a sequence complete after any
\(m\)-deletion but not after any \(n\)-deletion.
Step A: Robustness profile function
Define \(R_t(A)\): worst-case completeness after deleting \(t\) terms, and study
its monotonicity in \(t\).
Step B: Separation construction/obstruction
Build sequences with \(R_m=1\), \(R_n=0\), or prove impossible for given pair.
Step C: Full parameter classification
Characterize feasible \((m,n)\) in weak completeness sense.
Concrete Blocking Lemma (Most Critical):
Need a compositional robustness lemma: combining blocks with known robustness
profiles yields predictable profile of the union.

Lemma 1 (Monotonicity in deletion count):
If a sequence remains complete after deleting any \(t\) terms, then it remains
complete after deleting any \(s\le t\) terms.
\[
\textit{Proof.}
\]
Any \(s\)-deletion is a special case of \(t\)-deletion after adding \(t-s\)
arbitrary deleted indices.
\(\square\)
Lemma 2 (Immediate infeasibility condition):
If a pair \((m,n)\) is feasible, necessarily \(m<n\).
\[
\textit{Proof.}
\]
If \(m\ge n\), by Lemma 1 completeness after all \(m\)-deletions implies
completeness after all \(n\)-deletions, contradicting failure requirement.
\(\square\)
Lemma 3 (Reduction to boundary cases):
To classify all feasible \((m,n)\), it suffices to settle adjacent pairs
\((t,t+1)\): closure under Lemma 1 then determines all larger gaps.
\[
\textit{Proof sketch.}
\]
If \((t,t+1)\) realizable with profile control, block/product constructions can
amplify to \((m,n)\) for \(m\le t<n\) once monotonicity constraints are met.
\(\square\)
