# EP-704

## Problem Statement
Let $G_n$ be the unit distance graph in $\mathbb{R}^n$, with two vertices joined by an edge if and only if the distance between them is $1$.

Estimate the chromatic number $\chi(G_n)$. Does it grow exponentially in $n$? Does\[\lim_{n\to \infty}\chi(G_n)^{1/n}\]exist?

## Site Remarks
A generalisation of the Hadwiger-Nelson problem (https://en.wikipedia.org/wiki/Hadwiger%E2%80%93Nelson_problem) (which addresses $n=2$). Frankl and Wilson \cite{FrWi81} proved exponential growth:\[\chi(G_n) \geq (1+o(1))1.2^n.\]This was improved to\[\chi(G_n)\geq (1.239\cdots+o(1))^n\]by Raigorodsky \cite{Ra00}. The trivial colouring (by tiling with cubes) gives\[\chi(G_n) \leq (2+\sqrt{n})^n.\]Larman and Rogers \cite{LaRo72} improved this to\[\chi(G_n) \leq (3+o(1))^n,\]and conjecture the truth may be $(2^{3/2}+o(1))^n$. (Note that $2^{3/2}\approx 2.828$.) Prosanov \cite{Pr20} has given an alternative proof of this upper bound.

See also [508], [705], and [706].

## Local Computation
- Built a finite random geometric proxy model for each dimension: sample points on the unit sphere, connect pairs with distance in a narrow unit window \(|\|x-y\|-1|\le\varepsilon\).
- Computed for each finite sample graph:
 - clique-based lower bound,
 - greedy coloring upper bound.

- Deep run used 260 sampled points, \(\varepsilon=0.02\), dimensions 2 through 9.
- Observed finite-slice bounds were typically in a narrow range (clique lower 2-4, greedy upper 3-6).
- These are heuristic finite-model indicators only, not rigorous bounds for the full infinite graph \(G_n\).

## Local Proof Attempts
The only progress here is heuristic: replace the infinite unit-distance graph by finite random geometric proxies in each dimension, then compare clique lower bounds with coloring upper bounds. That gives a rough dimensional trend in finite samples, but it does not control the true infinite graph \(G_n\), so neither exponential growth nor existence of \(\lim \chi(G_n)^{1/n}\) is resolved.
