# EP-359

## Problem Statement
Let $a_1<a_2<\cdots$ be an infinite sequence of integers such that $a_1=n$ and $a_{i+1}$ is the least integer which is not a sum of consecutive earlier $a_j$s. What can be said about the density of this sequence?

In particular, in the case $n=1$, can one prove that $a_k/k\to \infty$ and $a_k/k^{1+c}\to 0$ for any $c>0$?

## Site Remarks
A problem of MacMahon, studied by Andrews \cite{An75}. When $n=1$ this sequence begins\[1,2,4,5,8,10,14,15,\ldots.\]This sequence is A002048 (https://oeis.org/A002048) in the OEIS. Andrews conjectures\[a_k\sim \frac{k\log k}{\log\log k}.\]Porubsky \cite{Po77} proved that, for any $\epsilon>0$, there are infinitely many $k$ such that\[a_k < (\log k)^\epsilon \frac{k\log k}{\log\log k},\]and also that if $A(x)$ counts the number of $a_i\leq x$ then\[\limsup \frac{A(x)}{\pi(x)}\geq \frac{1}{\log 2}\]where $\pi(x)$ counts the number of primes $\leq x$.

See also [839].

## Local Proof Attempts
Result (n=1 case):
- a_2400 = 8378, so a_k/k ~= 3.49 at k=2400 (clearly growing above 1).
- Ratio to Andrews model k log k / log log k stays around 0.88 to 0.92
 across high checkpoints.
- a_k / k^(1+c) is small for tested c (0.02, 0.05) and decreases slowly.

Hard point:
Finite data is consistent with near-k log k / log log k scale, but asymptotic
proofs for the two requested limits remain open.

Target:
Prove asymptotic growth for \(a_k\) (seed \(n=1\)) and establish the two limits in
EP-359.
Step A: Forbidden-sum frontier analysis
At step \(k\), characterize representable consecutive sums and the first gap.
Step B: Differential growth inequality
Bound \(a_{k+1}-a_k\) using density of representable intervals.
Step C: Asymptotic integration
Solve resulting recurrence/inequality to obtain \(a_k\sim C\,k\log k/\log\log k\)
or comparable scale.
Concrete Blocking Lemma (Most Critical):
Need a precise estimate for length and location of first nonrepresentable block as
function of current terms.

Lemma 1 (Greedy minimality equation):
If \(R_k\) is the set of representable sums from consecutive earlier terms, then
\[
a_{k+1}=\min\{m>a_k:\ m\notin R_k\}.
\]
\[
\textit{Proof.}
\]
This is exactly the defining greedy rule.
\(\square\)
Lemma 2 (Monotone growth):
\[
a_{k+1}>a_k,\quad\text{hence }a_k\to\infty.
\]
\[
\textit{Proof.}
\]
By Lemma 1, \(a_{k+1}\) is chosen strictly above \(a_k\); strictly increasing
integer sequence diverges.
\(\square\)
Lemma 3 (Scale reduction):
If one proves constants \(c_1,c_2>0\) such that for large \(k\),
\[
c_1\frac{k\log k}{\log\log k}\le a_k\le c_2\frac{k\log k}{\log\log k},
\]
then both requested limit statements reduce to identifying exact constants and
second-order terms.
\[
\textit{Proof.}
\]
These inequalities pin principal scale; remaining task is sharpened asymptotics.
\(\square\)
