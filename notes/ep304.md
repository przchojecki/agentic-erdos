# EP-304

## Problem Statement
For integers $1\leq a<b$ let $N(a,b)$ denote the minimal $k$ such that there exist integers $1<n_1<\cdots<n_k$ with\[\frac{a}{b}=\frac{1}{n_1}+\cdots+\frac{1}{n_k}.\]Estimate $N(b)=\max_{1\leq a<b}N(a,b)$. Is it true that $N(b) \ll \log\log b$?

## Site Remarks
Erd\H{o}s \cite{Er50c} proved that\[\log\log b \ll N(b) \ll \frac{\log b}{\log\log b}.\]The upper bound was improved by Vose \cite{Vo85} to\[N(b) \ll \sqrt{\log b}.\]One can also investigate the average of $N(a,b)$ for fixed $b$, and it is known that\[\frac{1}{b}\sum_{1\leq a<b}N(a,b) \gg \log\log b.\]Related to [18]. There is also a close connection to [293] (particularly with $N(b-1,b)$), as elucidated by van Doorn and Tang \cite{vDTa25b}.

This problem has been formalised in Lean (https://github.com/google-deepmind/formal-conjectures/blob/main/FormalConjectures/ErdosProblems/304.lean) as part of the Google DeepMind Formal Conjectures project (https://google-deepmind.github.io/formal-conjectures/).

Lemma 1 (Greedy upper bound baseline):
For any reduced \(a/b\in(0,1)\), the standard greedy Egyptian algorithm
terminates in finitely many steps.
\[
\textit{Proof.}
\]
At step \(x/y\), choose \(q=\lceil y/x\rceil\). New numerator is
\(x' = xq-y\), satisfying \(0\le x'<x\). Numerator decreases in
\(\mathbb N\), hence termination.
\(\square\)
Lemma 2 (Length minimization monotonicity):
If \(\mathcal D_1\subseteq \mathcal D_2\) are allowed denominator sets, then
minimum decomposition length satisfies
\[
L_{\mathcal D_2}(a/b)\le L_{\mathcal D_1}(a/b).
\]
\[
\textit{Proof.}
\]
Any decomposition using \(\mathcal D_1\) is admissible for \(\mathcal D_2\).
\(\square\)
Lemma 3 (Reduction to hardest numerator):
For fixed \(b\), define
\[
N(b):=\max_{1\le a<b,\ \gcd(a,b)=1} L(a/b).
\]
If one proves \(L(a/b)\le F(b)\) uniformly in \(a\), then \(N(b)\le F(b)\).
\[
\textit{Proof.}
\]
Take maximum over \(a\).
\(\square\)
Lemma 4 (Asymptotic reduction):
If Step B gives a recursion decreasing complexity \(C(b)\) by a fixed factor:
\[
C(b_{j+1})\le C(b_j)^\theta,\quad 0<\theta<1,
\]
with \(O(1)\) term increase each stage, then total length is
\(O(\log\log b)\).
\[
\textit{Proof.}
\]
Number of stages to reduce \(C(b)\) below constant is \(O(\log\log C(b))\), each
costing \(O(1)\) terms.
\(\square\)
