# EP-864

## Problem Statement
Let $A\subseteq \{1,\ldots N\}$ be a set such that there exists at most one $n$ with more than one solution to $n=a+b$ (with $a\leq b\in A$). Estimate the maximal possible size of $\lvert A\rvert$ - in particular, is it true that\[\lvert A\rvert \leq (1+o(1))\frac{2}{\sqrt{3}}N^{1/2}?\]

## Site Remarks
A problem of Erd\H{o}s and Freud, who prove that\[\lvert A\rvert \geq (1+o(1))\frac{2}{\sqrt{3}}N^{1/2}.\]This is shown by taking a genuine Sidon set $B\subset [1,N/3]$ of size $\sim N^{1/2}/\sqrt{3}$ and taking the union with $\{N-b : b\in B\}$.

For the analogous question with $n=a-b$ they prove that $\lvert A\rvert\sim N^{1/2}$.

This is a weaker form of [840].

- 22:34 on 11 Aug 2025 - DesmondWeisenberg:
  Call such a set Sidon with at most one exception (very original name, I know), and let $F(N)$ be the largest size of such a set within $\{1,...,N\}$. Of course, Erdős and Freud have shown that $(\frac{2}{\sqrt{3}} + o(1))N^{1/2} \leq F(N)$.
  
  I have a nice argument which shows that $F(N) \leq (\sqrt{2} + o(1))N^{1/2}$. If $A$ is Sidon with at most one exception, and $n$ is the unique number that can be represented as a sum in more than one way, then the sets $A \cap [1, n/2]$ and $A \cap (n/2, n]$ are individually Sidon. That is, if $A$ is Sidon with at most one exception, then $A$ can be split into two intervals on which it is Sidon. If we let $h(N)$ be the size of the largest Sidon set in $\{1,...,N\}$, then we therefore have
  \begin{equation*}
  F(N) \leq \max_k h(k) + h(N - k).
  \end{equation*}
  It is known (see [30]) that $h(N) = N^{1/2} + o(N^{1/2})$. Using calculus, you can see that for fixed $N$, the value $k^{1/2} + (N - k)^{1/2}$ is never greater than $\sqrt{2}(N^{1/2})$. It follows that $F(N) \leq (\sqrt{2} + o(1))N^{1/2}$.

## Local Computation
- Implemented finite random-greedy search under the one-exception multiplicity rule.
- Measured best and average sizes over many trials for $N=60,100,160,240,320$.

- Best normalized size $|A|/\sqrt N$ decreases across tested range (about $1.55$ at $N=60$ to about $1.01$ at $N=320$).
- Relative to $(2/\sqrt3)\sqrt N$, best found ratio approaches and then dips below 1 in larger tested $N$ windows.
- Finite greedy results are noisy and do not determine the asymptotic constant, but remain in the expected scale.
