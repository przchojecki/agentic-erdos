# EP-789

## Problem Statement
Let $h(n)$ be maximal such that if $A\subseteq \mathbb{Z}$ with $\lvert A\rvert=n$ then there is $B\subseteq A$ with $\lvert B\rvert \geq h(n)$ such that if $a_1+\cdots+a_r=b_1+\cdots+b_s$ with $a_i,b_i\in B$ then $r=s$.

Estimate $h(n)$.

## Site Remarks
Erd\H{o}s \cite{Er62c} proved $h(n) \ll n^{5/6}$. Straus \cite{St66} proved $h(n) \ll n^{1/2}$. Erd\H{o}s noted the bound $h(n)\gg n^{1/3}$, taking\[B=\{ a: \{ \alpha a\} \in n^{-1/3}+\tfrac{1}{2} (-n^{-2/3},n^{-2/3})\}\]for a random $\alpha\in [0,1]$. \cite{Er62c} and Choi \cite{Ch74b} improved this to $h(n) \gg (n\log n)^{1/3}$.

See also [186] and [874].

## Local Computation
Exact finite model in this attempt:
I solved an interval-restricted model exactly:
for all A subset [0,M] with |A|=n, minimize the largest valid |B|.
Results:
- n=5, M=14: bound <=3
- n=6, M=16: bound <=3
- n=7, M=18: bound <=4
- n=8, M=20: bound <=4

These are exact finite upper bounds for the restricted interval model, not the full unrestricted
integer problem.

## Local Proof Attempts
The exact finite model only treats interval-restricted sets \(A\subset[0,M]\), where one can brute-force the largest subset with the required sum-equality rigidity. Those results give rigorous small upper bounds in that restricted model, but they do not transfer directly to the unrestricted integer problem.
