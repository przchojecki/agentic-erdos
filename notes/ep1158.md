# EP-1158

## Problem Statement
Let $K_{t}(r)$ be the complete $t$-partite $t$-uniform hypergraph with $r$ vertices in each class.

Is it true that\[\mathrm{ex}_t(n,K_t(r)) \geq n^{t-r^{1-t}-o(1)}\]for all $t,r$?

## Site Remarks
Erd\H{o}s \cite{Er64f} proved that\[n^{t-O(r^{1-t})}\leq \mathrm{ex}_t(n,K_t(r)) \ll n^{t-r^{1-t}}.\]This is only known when $t=2$ and $2\leq r\leq 3$. The case $t=2$ is [714].

## Site References
