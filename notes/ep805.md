# EP-805

## Problem Statement
For which functions $g(n)$ with $n>g(n)\geq (\log n)^2$ is there a graph on $n$ vertices in which every induced subgraph on $g(n)$ vertices contains a clique of size $\geq \log n$ and an independent set of size $\geq \log n$?

In particular, is there such a graph for $g(n)=(\log n)^3$?

## Site Remarks
A problem of Erd\H{o}s and Hajnal, who thought that there is no such graph for $g(n)=(\log n)^3$. Alon and Sudakov \cite{AlSu07} proved that there is no such graph with\[g(n)=\frac{c}{\log\log n}(\log n)^3\]for some constant $c>0$.

Alon, Buci\'{c}, and Sudakov \cite{ABS21} construct such a graph with\[g(n)\leq 2^{2^{(\log\log n)^{1/2+o(1)}}}.\]See also [804].

## Local Computation
- Ran deeper induced-subgraph local-Ramsey scans on random graphs.
- For each \((n,g)\), sampled many host graphs and many induced \(g\)-subsets, testing both clique and independent-set thresholds exactly on the sampled subsets.

- Clear finite transition is visible:
 - at small \(g\), pass fraction is near 0,
 - over a narrow \(g\)-window, pass fraction jumps toward 1.
- The transition window shifts upward as \(n\) increases (e.g. around \(g\sim 48\to72\) for \(n=192,256\)).

## Local Proof Attempts
The finite scans look for a local Ramsey threshold by sampling many induced \(g\)-vertex subsets inside random host graphs and checking both clique and independent-set requirements. A sharp transition window appears in the sampled data, which is informative about plausible threshold behavior, but it does not determine whether one can really take \(g(n)=(\log n)^3\).
