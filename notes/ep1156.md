# EP-1156

## Problem Statement
Let $G$ be a random graph on $n$ vertices, in which every edge is included independently with probability $1/2$.

Is there some constant $C$ such that that chromatic number $\chi(G)$ is, almost surely, concentrated on at most $C$ values?

Is it true that, if $\omega(n)\to \infty$ sufficiently slowly, then for every function $f(n)$\[\mathbb{P}(\lvert\chi(G)-f(n)\rvert<\omega(n))<1/2\]if $n$ is sufficiently large?

## Site Remarks
Bollob\'{a}s \cite{Bo88} proved that $\chi(G) \sim \frac{n}{2\log_2n}$ with high probability.

Shamir and Spencer \cite{ShSp87} proved that, for any function $\omega(n)$ such that $\omega(n)/\sqrt{n}\to \infty$, there is a function $f(n)$ such that\[\mathbb{P}(\lvert\chi(G)-f(n)\rvert<\omega(n))\to 1\]as $n\to \infty$. This is proved with $\omega(n)\frac{\log n}{\sqrt{n}}\to \infty$ in Exercise 3 of Section 7.9 of Alon and Spencer \cite{AlSp16} (a proof is also given by Scott \cite{Sc17}).

Heckel \cite{He21} proved that if $f$ and $\omega$ are such that\[\mathbb{P}(\lvert\chi(G)-f(n)\rvert<\omega(n))\to 1\]as $n\to \infty$ then, for any $c<1/4$, there are infinitely many $n$ such that $\omega(n)>n^c$. This was improved to any $c<1/2$ by Heckel and Riordan \cite{HeRi23}.

## Forum Comments
- 10:33 on 26 Jan 2026 - Woett:
  Since the results by Heckel and Riordan seem so close to resolving this problem, I sent Annika Heckel an e-mail to ask about the limits of their methods, and she kindly responded to me. Some interesting things I learned (where whp stands for 'with high probability', i.e. with probability tending to $1$):
  
  1) In [HeRe23] (https://arxiv.org/pdf/2103.14014) they prove that there are infinitely many $n$ for which the smallest interval on which $\chi(G)$ is concentrated whp has length at least $\frac{c\sqrt{n} \log \log n}{\log^3 n}$, for some absolute constant $c$. They conjecture that this is the correct order of growth, up to the value of $c$.
  
  2) It is furthermore conjectured that there are infinitely many $n$ for which $\chi(G)$ is whp concentrated on an interval of length $\frac{C n^{1/4}}{\log^{7/4} n}$, for some absolute constant $C$ .
  
  3) Combining the first two points, the length of the concentration interval is thought to fluctuate between $n^{1/4 + o(1)}$ and $n^{1/2 + o(1)}$. See Figure $2$ and Conjectures $10, 11, 12$ in [HeRe23] (https://arxiv.org/pdf/2103.14014) for more details.
  
  4) The following crazy scenario has not been excluded: for almost all $n$, $\chi(G)$ is one-point concentrated whp. In particular, the second question remains open. Note that this does not contradict the first point above, as only the existence of infinitely many $n$ for which the concentration interval is large can be guaranteed.
  
  5) The following equally crazy scenario has also not been excluded: for all $n$, $\chi(G)$ is two-point concentrated whp. In particular, the first question also remains open. Note that this also does not contradict the first point above, as it is theoretically possible that, even for those $n$ for which the concentration interval is large, $\chi(G)$ is concentrated on two points that are far apart. Often the question is stated with $C$ consecutive values, in which case we do know the answer by [He21] (https://arxiv.org/pdf/1906.11808).
  
  6) Heckel has given various nice lectures on this topic which are available online. See here (https://www.youtube.com/watch?v=YDuQOSDRu5Y) for one example.
