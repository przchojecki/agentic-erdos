# EP-978

## Problem Statement
Let $f\in \mathbb{Z}[x]$ be an irreducible polynomial of degree $k>2$ (and suppose that $k\neq 2^l$ for any $l\geq 1$) such that the leading coefficient of $f$ is positive.

Does the set of integers $n\geq 1$ for which $f(n)$ is $(k-1)$-power-free have positive density?

If $k>3$, and for all primes $p$ there exists $n$ such that $p^{k-2}\nmid f(n)$, then are there infinitely many $n$ for which $f(n)$ is $(k-2)$-power-free?

In particular, does\[n^4+2\]represent infinitely many squarefree numbers?

## Site Remarks
Erd\H{o}s \cite{Er53} proved there are infinitely many $n$ for which $f(n)$ is $(k-1)$-power-free, except when $k=2^l$ and $2^{k-1}\mid f(n)$ for all $n$. This latter exception is possible, for example if\[f(x)=k!\left(\binom{x}{k}+1\right).\]Hooley \cite{Ho67} settled the first question, in fact providing a precise asymptotic for the number of such $n\leq x$.

Heath-Brown \cite{He06} proved the answer to the second question is yes when $k\geq 10$, and Browning \cite{Br11} extended this to $k\geq 9$ (in fact establishing an asymptotic formula for the number of such $n$). (This is under the assumption that there does not exist a prime $p$ such that $p^{k-2}\mid f(n)$ for all $n$, which Erd\H{o}s did not state explicitly, but is an obvious necessary condition, and is discussed explicitly in \cite{He06} and \cite{Br11}.)

In \cite{Er65b} Erd\H{o}s mentions the question of whether $2^n\pm 1$ represents infinitely many $k$th power-free integers, or $n!\pm 1$, but that these are 'intractable at present'. (See also [936].)

- 11:25 on 31 Mar 2026 - Moritz Firsching:
  The DeepMind prover agent has formally verified that the answer to the second part of the question is 'False' by constructing an explicit counterexample polynomial (assuming our formalisation (https://google-deepmind.github.io/formal-conjectures/theorem/?name=Erdos978.erdos_978.parts.ii)) of the question is correct).
  
  The polynomial $f(X) = X^6 + 33X^5 + 21X^4 + 63X^3 + 18X^2 + 24X + 48$ satisfies all the hypotheses (irreducible, degree $> 3$, degree not a power of $2$, positive leading coefficient, no fixed $p^5$ divisor) yet $f(n)$ is never $4$-powerfree. Irreducibility follows from Eisenstein's criterion at $p = 3$, since $3$ divides all non-leading coefficients but $3^2 = 9 \nmid 48$, the constant coefficient. The key observation is that $f(X) \equiv X(X-1)(X-2)(X-3)(X-4)(X-5) \pmod{16}$, and the product of $6$ consecutive integers is always divisible by $6! = 720$, which is divisible by $16 = 2^4$. So $2^4 \mid f(n)$ for all $n$, meaning $f(n)$ is never $4$-powerfree - contradicting the conclusion that infinitely many values should be. The full formal proof in Lean 4 is available here (https://github.com/mo271/formal-conjectures/blob/47d9e68df4323b995bb9875b6d5199a4f7026bfb/FormalConjectures/ErdosProblems/978.lean#L62)).

## Local Computation
- deep two-layer computation for $n^4+2$:
 1. Exact squarefreeness by 64-bit Pollard-Rho factorization for $n\le 7000$.
 2. Large-$N$ proxy up to $n\le 10^6$ by filtering divisibility by $p^2$ for all primes $p\le 2000$.

- Exact layer (up to $7000$): squarefree density stays near $0.756$-$0.759$.
- Proxy layer (up to $10^6$): survivor density is extremely stable near $0.75672$.
- Finite data strongly supports a positive-density heuristic, but is not a proof of infinitude.

## Local Proof Attempts
The squarefree-survival density for \(n^4+2\) is remarkably stable across both the exact and proxy layers, which strongly supports a positive-density heuristic. That still falls short of proving infinitude, because one must rule out subtle large-prime square obstructions beyond the finite and truncated checks.
