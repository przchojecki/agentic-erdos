# EP-885

## Problem Statement
For integer $n\geq 1$ we define the factor difference set of $n$ by\[D(n) = \{\lvert a-b\rvert : n=ab\}.\]Is it true that, for every $k\geq 1$, there exist integers $N_1<\cdots<N_k$ such that\[\lvert \cap_i D(N_i)\rvert \geq k?\]

## Site Remarks
A question of Erd\H{o}s and Rosenfeld \cite{ErRo97}, who proved this is true for $k=2$. Jim\'{e}nez-Urroz \cite{Ji99} proved this for $k=3$ and Bremner \cite{Br19} proved this for $k=4$.

## Local Computation
- Ran deeper finite search up to $N=120000$.
- Built support sets of differences and searched for $k$-tuples of differences with intersection size at least $k$ via bounded-depth intersection DFS.

- Found explicit witnesses for $k=2,3$ in the searched range.
- Did not find witnesses for $k=4,5,6$ under this bounded candidate strategy.
- Non-findings are inconclusive and compatible with known positive theorem for $k=4$.

## Local Proof Attempts
The bounded-depth intersection search tries to witness the common-difference phenomenon directly by intersecting the sets \(D(N_i)\). It recovers the small solved cases in range, but non-findings at higher \(k\) are inconclusive because the search itself is heavily truncated.
